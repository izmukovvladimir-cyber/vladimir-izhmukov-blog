# OpenCode: ИИ-агент для кода в терминале

OpenCode это открытый ИИ-агент для программирования: он работает с вашим проектом, пишет и правит код, выполняет команды и подключается к моделям разных провайдеров. На macOS и Linux его ставят командой `curl -fsSL https://opencode.ai/v2/install | bash` и запускают командой `opencode` в папке проекта. Сам OpenCode бесплатен, в его каталоге есть модели, доступные без оплаты на ограниченное время, платные модели можно оплачивать по расходу с баланса в OpenCode Console (старая ссылка OpenCode Zen ведёт в этот раздел) или подпиской OpenCode Go от $10 в месяц в пределах её лимита, а можно подключить ключ своего провайдера и платить ему по его условиям.

## Что такое OpenCode

OpenCode это агент для кода с открытым исходником под лицензией MIT, его делает команда Anomaly. Вы пишете задачу словами, а агент работает с файлами проекта, правит код и выполняет команды. OpenCode при этом подключается к моделям разных компаний: сайт заявляет больше 200 провайдеров моделей через Models.dev, включая локальные модели, а также вход по подписке ChatGPT Plus или Pro и GitHub Copilot.

| Где работает | Что это |
|---|---|
| Терминал | текстовый интерфейс в любой оболочке, редакторе или на удалённом сервере |
| Десктоп | приложение для macOS, Windows и Linux с сессиями, вкладками, диффами и встроенным браузером |
| Телефон | мобильное приложение, чтобы запускать, направлять и подтверждать сессии |
| SDK | управление агентом из своего кода |

### Встроенные агенты

По документации OpenCode, внутри есть два основных агента и два подагента:

- **Build** это агент по умолчанию для работы с кодом, чтение чувствительных файлов окружения он согласует с вами;
- **Plan** исследует и планирует без правок обычных файлов проекта, команды оболочки остаются под контролем разрешений;
- **General** это подагент для поиска и многошаговой работы с широким доступом к инструментам;
- **Explore** это подагент, который ищет и читает код и веб-источники, не меняя файлы.

## Что такое OpenCode Zen и что с ним сейчас

OpenCode Zen был шлюзом OpenCode с каталогом проверенных моделей, запросы к которому оплачивались по расходу. На 28 ноября 2026 года отдельного продукта с таким названием в документации больше нет: адрес opencode.ai/docs/zen перенаправляет на каталог моделей в OpenCode Console. Console это сервис OpenCode для моделей, аккаунтов провайдеров и рабочих пространств, и оплата моделей по расходу сейчас живёт в её каталоге моделей.

Как это работает сейчас:

1. Вы входите в консоль на opencode.ai/console, указываете способ оплаты и пополняете баланс кредитов.
2. К каждому пополнению добавляется комиссия 4,6% + $0,31, дальше стоимость запросов к платным моделям списывается с баланса, бесплатные модели баланс не тратят. Можно включить автопополнение и задать бюджет.
3. В консоли копируете API-ключ.
4. В OpenCode вводите `/connect`, выбираете провайдера OpenCode с оплатой по расходу и вставляете ключ, затем командой `/models` выбираете модель.

Если вы искали «OpenCode Zen», вам нужен каталог моделей в OpenCode Console с оплатой по расходу. Подписка с фиксированной ценой называется OpenCode Go, о ней ниже.

## Как установить OpenCode CLI

OpenCode CLI (интерфейс командной строки) для macOS и Linux можно установить официальным скриптом: откройте терминал и выполните `curl -fsSL https://opencode.ai/v2/install | bash`. Другие способы с сайта OpenCode:

1. Через npm: `npm install -g @opencode/cli`.
2. Через bun: `bun install -g --trust @opencode/cli`.
3. Через Homebrew: `brew install anomalyco/tap/opencode-v2`.
4. На Arch Linux через paru: `paru -S opencode-beta`.
5. Через pnpm: `pnpm add -g --allow-build=@opencode/cli @opencode/cli`, через yarn: `yarn global add @opencode/cli`.
6. Через mise: `mise use -g opencode`. Документация предупреждает, что mise старее версии 2026.10.9 поставит первую версию OpenCode.
7. Десктоп: приложение для macOS, Windows (x64 и ARM64) и Linux (.deb, .rpm, AppImage) лежит на странице продукта opencode.ai.

| Команда | Где работает |
|---|---|
| `curl -fsSL https://opencode.ai/v2/install \| bash` | macOS и Linux, официальный скрипт |
| `npm install -g @opencode/cli` | macOS и Linux с установленным Node.js |
| `brew install anomalyco/tap/opencode-v2` | macOS и Linux с Homebrew |
| `paru -S opencode-beta` | Arch Linux |

Команда со скриптом скачивает установщик с opencode.ai и сразу запускает его с правами текущего пользователя, поэтому перед запуском проверьте, что адрес набран точно.

### Как установить OpenCode CLI v2 на Windows

Команда `opencode` во второй версии на Windows ставится из ZIP-архива с файлом `opencode.exe`: документация v2 прямо пишет, что менеджеры пакетов Windows не поддерживаются. Советы про WSL, Chocolatey и Scoop, которые встречаются в сети, взяты из документации первой версии OpenCode. Порядок для v2:

1. Откройте документацию OpenCode, раздел установки, и скачайте архив CLI под свой процессор: ARM64, x64 или x64 baseline для старых процессоров. Файл приходит в формате .zip.
2. Распакуйте архив и положите `opencode.exe` в папку из переменной PATH, тогда команда `opencode` будет находиться по имени. Иначе запускайте файл по полному пути.
3. В терминале перейдите в папку проекта и запустите `opencode`.

Отдельный вариант для работы в окне с вкладками и диффами это десктоп-приложение для Windows со страницы продукта. Чтобы установить отдельную команду `opencode` по инструкции v2, скачайте ZIP для своей архитектуры, как в шагах выше.

После установки зайдите в папку проекта и наберите `opencode`. Откроется интерфейс агента, где задача пишется обычным текстом. По [журналу изменений](https://opencode.ai/changelog), 26 ноября 2026 года вышла версия 2.4.2. Репозиторий проекта теперь github.com/anomalyco/opencode, старый адрес sst/opencode перенаправляет туда.

## Оплата по расходу (вместо Zen) и OpenCode Go: в чём разница

В OpenCode Console, сервисе для моделей, аккаунтов провайдеров и рабочих пространств, есть два способа оплаты моделей: оплату по расходу с баланса (раньше так оплачивались запросы через шлюз OpenCode Zen, в `/connect` это провайдер OpenCode с оплатой по расходу) и подписку OpenCode Go, месячную подписку на каталог моделей для программирования, в том числе открытых. Можно также подключить своего провайдера или войти по уже оплаченной подписке. Сравнение по документации OpenCode:

| | Оплата по расходу | Go | Go Plus | Go Teams |
|---|---|---|---|---|
| Как платите | пополняете баланс и платите за токены | подписка | подписка | подписка на участника |
| Цена | по факту расхода, комиссия за пополнение 4,6% + $0,31 | $10 в месяц | $40 в месяц | $20 за участника в месяц, минимум 2 участника |
| Что даёт | модели, проверенные командой OpenCode, платные и бесплатные | каталог моделей Go для программирования в пределах лимита | каталог Go, лимиты выше | у каждого участника свои лимиты |

### Как подключить OpenCode Go

Подписка Go оформляется в консоли OpenCode. После оплаты скопируйте в консоли API-ключ, в OpenCode введите `/connect`, выберите провайдера OpenCode Go, вставьте ключ и командой `/models` возьмите модель из каталога Go. У участника Go Teams лимиты по каждой модели на $5 в месяц выше, чем у обычного Go.

### Как устроены лимиты Go

Все платные модели в Go тратят один общий месячный лимит. Лимит на 5 часов это 20% месячного, окно начинается с первого использования. Недельный лимит это 50% месячного, он сбрасывается в понедельник в 00:00 UTC. Месячный лимит обновляется с новым оплаченным периодом.

Если лимит кончился, можно перейти на бесплатную модель или включить Extra Usage: тогда дальше расходуются кредиты Console, у Go Teams эта опция включена изначально. Сколько запросов за 5 часов примерно даёт модель, показывает страница Go в консоли OpenCode. По документации, настройки Go по умолчанию разрешают обработку запросов в Европе и США.

## Как подключить модель

В терминальном интерфейсе OpenCode команда `/connect` подключает провайдера, а `/models` выбирает модель.

1. Запустите opencode и введите команду /connect.
2. Выберите провайдера: OpenCode с оплатой по расходу, OpenCode Go или другого.
3. Если провайдер работает по ключу, вставьте ключ из его консоли.
4. Командой /models выберите модель для работы.

Подписку ChatGPT Plus, Pro или GitHub Copilot, по данным сайта OpenCode, можно подключить входом вместо отдельного ключа.

## Как пользоваться OpenCode: основные команды

Команда `opencode` открывает интерфейс агента в текущем проекте, а `opencode run "…"` выполняет разовую задачу без интерфейса. Основные команды по документации OpenCode:

| Команда | Что делает |
|---|---|
| `opencode` | Открывает полноэкранный интерфейс агента в текущей папке |
| `opencode ~/code/my-project` | Открывает агента в другой папке проекта |
| `opencode run "Explain this repository"` | Выполняет задачу без интерфейса, для скриптов и CI |
| `opencode mini` | Запускает упрощённый интерактивный интерфейс |
| `opencode debug paths` | Показывает, где лежат база, конфиг, кэш и логи |
| `opencode uninstall --dry-run` | Показывает, что удалится, без удаления |

Все локальные клиенты OpenCode по умолчанию подключаются к одному общему фоновому сервису вашей учётной записи. Если нужен отдельный сервер, есть флаг `--standalone`.

## Как добавить MCP в OpenCode

MCP (Model Context Protocol) это протокол, через который MCP-сервер даёт агенту дополнительные инструменты и ресурсы. Удалённый MCP-сервер в OpenCode добавляется одной командой из папки проекта:

1. Выполните `opencode mcp add context7 --url https://mcp.context7.com/mcp`, где context7 это имя сервера, а дальше его адрес.
2. Проверьте подключение командой `opencode mcp list`: у подключённого сервера стоит отметка connected.
3. Чтобы сервер работал во всех проектах, добавьте флаг `--global`.

Вручную сервер прописывается в файле opencode.jsonc в разделе `mcp.servers`: у локального сервера `"type": "local"` и обязательное поле `"command"` с командой запуска, у удалённого `"type": "remote"` и полный адрес в `"url"`. Во второй версии имена серверов кладутся внутрь `servers`, прямо в `mcp` их класть нельзя. Удалённые серверы по умолчанию используют вход через OAuth. Документация предупреждает, что инструменты MCP расходуют контекст модели, поэтому подключайте только нужные серверы.

## OpenCode skills

Skills в OpenCode это файлы с инструкциями: агент видит их описание из поля description, а полный текст получает, когда вызывает инструмент skill. По документации, skill кладут файлом SKILL.md в папку с его именем, а OpenCode версии 2 принимает и отдельный файл `<имя>.md` в папке skills. OpenCode сам ищет skills в папках `~/.config/opencode/skills` и `.opencode/skills`, а для совместимости ещё в `~/.claude/skills` и `.claude/skills`. Значит, skills из этих папок Claude Code OpenCode тоже найдёт, если их формат совместим.

## Как удалить OpenCode

OpenCode удаляется командой `opencode uninstall`: при установке через менеджер пакетов она удаляет его этим же менеджером, а при установке скриптом через `curl` сам исполняемый файл не удаляет и печатает команду, чтобы удалить его вручную.

1. Посмотрите, что удалится: `opencode uninstall --dry-run`.
2. Удалите: `opencode uninstall`, команда попросит подтверждение. Флаг `--force` пропускает подтверждение.
3. Если ставили через `curl`, выполните команду удаления файла, которую покажет `opencode uninstall`.

По документации CLI, сессии, настройки и состояние при удалении сохраняются.

## Частые вопросы

**Что такое OpenCode?**
OpenCode это открытый ИИ-агент для программирования, который работает в терминале, на десктопе и в телефоне с моделями многих провайдеров.

**OpenCode бесплатный?**
Сам агент бесплатный, в каталоге есть бесплатные на время модели. Платные модели оплачиваются по расходу с баланса OpenCode Console, подпиской Go от $10 в месяц в пределах лимита или напрямую провайдеру, если подключить свой ключ.

**Как установить OpenCode CLI?**
На macOS и Linux одной командой из официального скрипта на opencode.ai или через npm пакетом @opencode/cli, на Windows скачать архив и распаковать opencode.exe, затем команда opencode в папке проекта.

**Что такое OpenCode Zen?**
Так назывался шлюз OpenCode с каталогом проверенных моделей, за запросы к нему платили по расходу. Сейчас оплата по расходу живёт в каталоге моделей OpenCode Console: пополняете баланс с комиссией 4,6% + $0,31 и тратите его на запросы, адрес /docs/zen ведёт туда же.

**Как установить OpenCode на Windows?**
Для CLI v2 скачать архив .zip под свой процессор, распаковать `opencode.exe` и положить его в папку из PATH, либо поставить десктоп-приложение. Менеджеры пакетов Windows документация v2 не поддерживает.

**Как подключить OpenCode Go?**
Оформить подписку в консоли, скопировать API-ключ, в OpenCode ввести `/connect`, выбрать OpenCode Go, вставить ключ и выбрать модель командой `/models`.

**Сколько стоит OpenCode Go?**
$10 в месяц, Go Plus $40, Go Teams $20 за участника при минимуме из двух. Лимит общий на все платные модели.

**Работает ли OpenCode с MCP?**
Да, поддерживаются локальные и удалённые MCP-серверы, для удалённых по умолчанию вход через OAuth.

**Как добавить MCP в OpenCode?**
Командой `opencode mcp add <имя> --url <адрес>` из папки проекта, с флагом `--global` для всех проектов. Проверка: `opencode mcp list`.

**Как удалить OpenCode?**
Командой `opencode uninstall`, а `opencode uninstall --dry-run` сначала покажет, что удалится. При установке через `curl` исполняемый файл удаляется отдельной командой, которую напечатает uninstall. Настройки и сессии сохраняются.
