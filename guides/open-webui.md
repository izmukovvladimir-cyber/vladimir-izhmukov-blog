# Open WebUI: свой ChatGPT на компьютере или сервере

Open WebUI это бесплатный веб-интерфейс для нейросетей, внешне похожий на ChatGPT, который вы ставите на свой компьютер или сервер. К нему подключаются локальные модели через Ollama и любые сервисы с API, совместимым с OpenAI: OpenRouter, Groq, Mistral, LM Studio и другие. Внутри есть работа с документами (RAG), поиск в интернете, генерация картинок, голосовые звонки, память, агенты и управление пользователями. У проекта около 158 тыс. звёзд на GitHub, последняя версия на момент проверки v0.13.3 от 9 ноября 2026 года. Ниже разберу функции, установку и подключение моделей.

## Что умеет Open WebUI

| Функция | Что даёт |
|---|---|
| Любые модели | локальные через Ollama и облачные через API, совместимые с OpenAI |
| Работа с документами | RAG на 9 векторных базах, гибридный поиск, распознавание PDF |
| Поиск в интернете | десятки поисковых провайдеров, страницы подтягиваются командой # и адресом |
| Агенты | модель плюс инструкции, инструменты и база знаний |
| Плагины и MCP | фильтры, действия, инструменты, скиллы, подключение MCP-серверов |
| Память | факты о вас переносятся из чата в чат |
| Картинки | генерация и правка через DALL·E, Gemini, ComfyUI и AUTOMATIC1111 |
| Голос и видео | звонки с распознаванием речи и озвучкой |
| Команда | роли, группы, права доступа, общие каналы, аналитика расходов |
| Календарь и автоматизации | запуск запросов по расписанию |

Open WebUI работает и на телефоне как веб-приложение, его можно добавить на главный экран.

## Зачем ставить Open WebUI

- Пользоваться локальными моделями в удобном окне вместо командной строки.
- Собрать в одном интерфейсе несколько провайдеров и сравнивать ответы моделей рядом.
- Дать команде общий чат с нейросетями и контролем расходов.
- Задавать вопросы по своим документам без загрузки их в чужое облако, если модель локальная.

## Как установить Open WebUI

### Через Python pip

1. Поставьте Python 3.12: эту версию сейчас указывает README проекта, с более старыми возможны ошибки установки.
2. В терминале выполните `pip install open-webui`.
3. Запустите сервер командой `open-webui serve`.
4. Откройте в браузере адрес localhost:8080 и создайте первый аккаунт, он станет администратором.

### Через uv одной командой

На macOS и Linux с установленным менеджером uv Open WebUI запускается без отдельной установки Python: команда `uvx --python 3.12 open-webui@latest serve` сама скачает нужную версию и поднимет сервер. Данные лучше сразу направить в постоянную папку переменной DATA_DIR, как показано в README, иначе чаты окажутся во временном каталоге.

### Через Docker

Основной вариант из README: контейнер `ghcr.io/open-webui/open-webui:main`, который публикуется на порт 3000 с томом `open-webui:/app/backend/data`. Том обязателен: в нём хранятся чаты и настройки, без него данные пропадут при пересоздании контейнера. Какой образ выбрать:

| Тег образа | Что внутри |
|---|---|
| `:main` | стандартный образ с локальными зависимостями для поиска по документам и голоса. |
| `:slim` | облегчённый образ, эмбеддинги, распознавание документов и голос берутся у внешних сервисов. |
| `:cuda` | ускорение на видеокартах NVIDIA. |
| `:ollama` | Open WebUI и Ollama вместе в одном контейнере. |

### Open WebUI на Windows

1. Самый простой путь: установите Docker Desktop и запустите контейнер из README.
2. Второй путь: поставьте Python 3.12, затем установите через pip и запустите `open-webui serve` в PowerShell.
3. Если Ollama уже стоит на Windows, Open WebUI в Docker находит её через адрес host.docker.internal, параметр для этого есть в команде запуска в README.

## Как обновить Open WebUI

Новые версии выходят часто, иногда несколько раз в месяц, поэтому обновление стоит освоить сразу.

1. **Установка через pip.** Выполните `pip install --upgrade open-webui` и перезапустите `open-webui serve`.
2. **Установка через Docker.** Скачайте свежий образ командой `docker pull ghcr.io/open-webui/open-webui:main`, остановите и удалите старый контейнер, затем запустите его заново той же командой из README. Чаты и настройки сохранятся, потому что лежат в томе `open-webui`.
3. **Перед крупным обновлением** сделайте копию тома или папки с данными. Если новая версия поведёт себя странно, вы вернётесь назад за минуту.

Подробный порядок для разных способов установки есть в [официальной инструкции по обновлению](https://docs.openwebui.com/getting-started/updating).

## Как включить русский язык

Интерфейс Open WebUI переведён на русский. Откройте настройки пользователя, раздел «Общие», и выберите русский в списке языков. Перевод делают участники сообщества, поэтому отдельные свежие пункты меню могут оставаться на английском.

## Как подключить модели

### Ollama

Если Ollama работает на том же компьютере, Open WebUI подхватит её автоматически. Если Ollama на другом сервере, укажите её адрес в переменной OLLAMA_BASE_URL при запуске. Как поставить Ollama и выбрать модель, я писал в статье [Ollama](/guides/ollama/), а про похожую программу с окном в статье [LM Studio](/guides/lm-studio/).

### Облачные модели

1. Откройте настройки администратора, раздел подключений.
2. Добавьте адрес API и ключ провайдера.
3. Для доступа ко многим моделям по одному ключу удобен [OpenRouter](/guides/openrouter/).
4. Модели появятся в выпадающем списке чата.

## Как работать с документами (RAG)

1. Загрузите файлы в раздел знаний и создайте коллекцию.
2. Привяжите коллекцию к модели или прикрепляйте её в чате через символ #.
3. Задавайте вопросы: ответ строится по фрагментам ваших документов.
4. Для сканов включите один из движков распознавания, например Docling или Mistral OCR.

Качество ответа по документам сильно зависит от модели. Маленькая локальная модель может пропускать детали, поэтому важные выводы проверяйте по первоисточнику.

## Лицензия Open WebUI

Код распространяется под собственной лицензией Open WebUI License. Пользоваться и разворачивать его можно бесплатно, но есть важное условие: убирать или заменять брендинг Open WebUI запрещено, если у вашей установки больше 50 пользователей за 30 дней и нет письменного разрешения или корпоративной лицензии. Для личного использования и небольшой команды это ограничение не мешает.

## Минусы Open WebUI

- Нужен свой компьютер или сервер и базовые навыки работы с терминалом или Docker.
- Локальные модели требуют мощной видеокарты для быстрых ответов.
- Лицензия ограничивает смену брендинга для установок больше 50 пользователей.
- Функций много, и первая настройка занимает время.

## Частые вопросы

### Что такое Open WebUI?

Это бесплатный веб-интерфейс в стиле ChatGPT для локальных и облачных нейросетей, который ставится на свой компьютер или сервер.

### Open WebUI бесплатный?

Да, проект бесплатный. Платить нужно только за облачные модели, если вы их подключаете.

### Как установить Open WebUI на Windows?

Через Docker Desktop командой из README или через Python 3.12 командами `pip install open-webui` и `open-webui serve`.

### Где скачать Open WebUI?

Код и инструкции лежат в репозитории open-webui на GitHub, образы Docker публикуются в ghcr.io.

### Как подключить Ollama к Open WebUI?

Если Ollama на том же компьютере, она подключится сама. Для удалённой укажите адрес в переменной OLLAMA_BASE_URL.

### Есть ли в Open WebUI RAG?

Да, можно загрузить документы в базу знаний и задавать по ним вопросы, поддерживаются 9 векторных баз и гибридный поиск.

### Как обновить Open WebUI?

Через pip командой `pip install --upgrade open-webui`, в Docker скачайте свежий образ и пересоздайте контейнер с тем же томом, данные сохранятся.

### Есть ли Open WebUI на русском?

Да, русский язык выбирается в настройках пользователя, раздел «Общие».
