Whisper нейросеть: как перевести аудио в текст бесплатно, модели и установка в 2026

AI RealshiftВладимир Ижмуков

Whisper от OpenAI по шагам: расшифровка аудио и видео в текст, русский язык, какую модель выбрать, сколько нужно видеопамяти, установка на компьютер и транскрибация через API.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Whisper это открытая нейросеть OpenAI для распознавания речи: она переводит аудио и видео в текст и умеет переводить речь с других языков на английский. Код и веса модели выложены под лицензией MIT, поэтому Whisper можно бесплатно поставить на свой компьютер. Русский язык поддерживается мультиязычными моделями. Если ставить ничего не хочется, та же задача решается через API OpenAI, там Whisper доступен как модель whisper-1.

Какую модель Whisper выбрать

Turbo это ускоренная версия large-v3, в командной строке Whisper она стоит по умолчанию. Для русской речи берите мультиязычные модели: версии с окончанием .en знают только английский. Переводить речь на английский turbo не обучена, для перевода нужна medium или large.

Как выбрать под свой компьютер

  • Видеокарта на 6 ГБ и больше: turbo, это лучший баланс скорости и точности.
  • Слабый компьютер: small или base, точности хватит для черновой расшифровки.
  • Важна каждая фраза, например интервью: large и время на ожидание.

Как установить Whisper на компьютер

  1. Установите Python версии от 3.8 до 3.11.
  2. Установите ffmpeg, он нужен для чтения аудио и видео.
  3. В терминале выполните pip install -U openai-whisper.
  4. Запустите расшифровку командой whisper audio.mp3 --model turbo --language Russian.
  5. Рядом с файлом появятся текст и субтитры.

Флаг --language Russian подсказывает модели язык, так она реже ошибается на первых секундах.

Как расшифровать аудио через API без установки

  1. Получите ключ API в кабинете разработчика OpenAI.
  2. Отправьте файл на адрес /v1/audio/transcriptions.
  3. Выберите модель: для обычной расшифровки документация сейчас рекомендует gpt-transcribe, для разметки по спикерам gpt-4o-transcribe-diarize, для таймкодов и субтитров whisper-1.
  4. Получите текст в ответе.

Длинную запись режьте на куски меньше 25 МБ. Цену за минуту страница тарифов OpenAI на дату проверки не открыла, её показывает кабинет разработчика.

Где Whisper пригодится блогеру

  • Расшифровать свой голосовой поток мыслей и превратить его в пост.
  • Сделать субтитры к ролику: Whisper сразу выдаёт файл субтитров.
  • Вытащить текст из чужого интервью, чтобы разобрать структуру.

Если хочется без терминала и сразу в браузере, посмотрите TurboScribe, он построен на распознавании речи. Субтитры к роликам разобраны в статье нейросеть для субтитров, озвучка текста в материале озвучка нейросетью.

Частые вопросы

Whisper бесплатный? Да, модель открытая, лицензия MIT. Платно только использование через API OpenAI.

Понимает ли Whisper русский язык? Да, мультиязычные модели понимают русский, флаг --language Russian повышает точность.

Какая модель Whisper лучшая? По точности large, по балансу скорости и точности turbo.

Нужна ли видеокарта? Требования растут с размером модели: tiny и base занимают около 1 ГБ видеопамяти, turbo около 6 ГБ, large около 10 ГБ.

Какой максимальный файл в API? 25 МБ.

Официальные страницы и источники: Whisper на GitHub, документация OpenAI для разработчиков, раздел Speech to text.

Что делать дальше

Расшифруйте свою следующую голосовую заметку и сделайте из неё текст под ролик. Свой голос в тексте читается лучше любого сгенерированного.
