GitHub Copilot: цены 2026, бесплатный план Free, Copilot для студентов, CLI и доступ из России

AI RealshiftВладимир Ижмуков

GitHub Copilot это ИИ-помощник для кода от GitHub. Разбираю тарифы после перехода на AI-кредиты в июне 2026, что даёт бесплатный план Free, как получить Copilot Student, что такое Copilot CLI и как обстоят дела с оплатой из России.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

GitHub Copilot это ИИ-помощник программиста от GitHub: он дописывает код прямо в редакторе, отвечает в чате, сам готовит pull request по задаче и работает агентом в терминале через Copilot CLI. Есть бесплатный план Free с 2 000 автодополнений в месяц, платные Pro за $10, Pro+ за $39 и Max за $100 в месяц. С 1 июня 2026 года все планы считают расход в AI-кредитах. Россия по правилам GitHub входит в список стран, куда Copilot не продаётся, это главное, что нужно знать до оплаты.

Сразу разведу два продукта с похожим названием. Microsoft Copilot это помощник в Windows и Office, про него у меня отдельный разбор. Эта статья целиком про GitHub Copilot для кода.

Что такое GitHub Copilot

Copilot делает компания GitHub, она принадлежит Microsoft. Помощник живёт в нескольких местах сразу:

  • в редакторе кода: VS Code, JetBrains и другие IDE;
  • на сайте github.com и в мобильном приложении GitHub;
  • в терминале, это Copilot CLI;
  • в отдельном приложении Copilot.

По документации GitHub, Copilot CLI и приложение входят во все планы, включая бесплатный.

Сколько стоит GitHub Copilot в 2026 году

С 1 июня 2026 года GitHub перевёл все планы на оплату по расходу. Вместо прежних «премиум-запросов» теперь AI-кредиты, один кредит стоит $0,01. Тяжёлые модели и длинные агентные сессии съедают кредиты быстрее, поэтому старые статьи про «300 премиум-запросов в месяц» уже не актуальны.

Copilot бесплатно: что даёт Free

Бесплатный план даёт 2 000 автодополнений в месяц, чат и агента в рамках небольшого лимита кредитов и Copilot CLI. Облачного агента и ручного выбора модели во Free нет. Чтобы понять, нужен ли вам Copilot вообще, этого хватает: за неделю обычной работы станет ясно, экономит он время или мешает.

Copilot для студентов и преподавателей

С 13 марта 2026 года студенты, подтвердившие статус в GitHub Education, получают отдельный бесплатный план Copilot Student. Модель там тоже выбирается автоматически. Преподаватели через GitHub Education и мейнтейнеры популярных open-source проектов могут получить Pro бесплатно, право GitHub пересматривает каждый месяц.

Как начать пользоваться GitHub Copilot

  1. Зарегистрируйтесь на github.com или войдите в свой аккаунт.
  2. Включите Copilot Free в настройках аккаунта или оформите платный план.
  3. В VS Code установите расширение GitHub Copilot и войдите через тот же аккаунт GitHub.
  4. Начните печатать код: серые подсказки принимаются клавишей Tab.
  5. Откройте чат Copilot и попросите объяснить чужой файл или написать тесты к функции.
  6. Для работы в терминале поставьте Copilot CLI по инструкции из документации GitHub.

Как получить от Copilot больше

  • Пишите в чате задачу целиком: что сделать, в каком файле, какие ограничения.
  • Просите сначала план изменений и только потом код.
  • Заведите файл с инструкциями для проекта, Copilot читает его в каждом запросе.
  • Проверяйте каждую правку агента перед коммитом, особенно в чужом коде.

Писать задачи можно по-русски, модели отвечают на русском. Интерфейс GitHub и плагинов на английском, документация docs.github.com есть на русском языке.

GitHub Copilot в России

В правилах GitHub о торговых ограничениях прямо сказано, что Copilot нельзя продавать и экспортировать в страны из списка ограничений, и Россия в этом списке есть вместе с Кубой, Ираном, Северной Кореей и Беларусью. Сам GitHub с бесплатными репозиториями из России работает. Пускает ли бесплатный план Copilot пользователей с российским адресом, GitHub отдельно не пишет, и с российского IP я это не проверял.

С оплатой ситуация такая. По обзорам, российские карты GitHub не принимает. Виртуальные карты посредников он тоже иногда блокирует по номеру. Главный риск в другом: оплата через посредника не отменяет правило о торговых ограничениях, и аккаунт может попасть под ограничение. Для меня это аргумент не держать рабочие репозитории на аккаунте с серой оплатой.

Покупать «готовые аккаунты Copilot» на биржах не советую. Чужой или общий аккаунт может слететь вместе с доступом к вашим репозиториям.

Минусы GitHub Copilot

  • Россия в списке стран, куда Copilot не продаётся.
  • В Free и Student нельзя выбрать модель вручную.
  • Расход в кредитах сложно предсказать: агентная сессия на тяжёлой модели съедает лимит за вечер.
  • Code review тратит ещё и минуты GitHub Actions.
  • Объём бесплатного лимита кредитов GitHub не публикует.

Частые вопросы

GitHub Copilot бесплатный или нет? Есть бесплатный план Free: 2 000 автодополнений в месяц, чат и агент в рамках небольшого лимита. Платные планы стоят $10, $39 и $100 в месяц.

Сколько стоит GitHub Copilot Pro? $10 в месяц, внутри 1 500 AI-кредитов. Кредиты сверх лимита стоят $0,01 за штуку.

Как получить GitHub Copilot для студентов? Подтвердите статус студента в GitHub Education, после этого доступен бесплатный план Copilot Student.

Работает ли GitHub Copilot в России? По правилам GitHub Copilot не продаётся в Россию. Сам GitHub работает, доступ к бесплатному Copilot с российским адресом GitHub отдельно не описывает.

Как оплатить GitHub Copilot из России? Российские карты по обзорам не проходят. Платят зарубежной картой или через посредников, и это риск для аккаунта из-за торговых ограничений.

Что такое GitHub Copilot CLI? Это агент Copilot в терминале. Он входит во все планы, включая бесплатный.

Чем GitHub Copilot отличается от Microsoft Copilot? GitHub Copilot помогает писать код, Microsoft Copilot работает в Windows и Office. Это разные продукты с разными подписками.
