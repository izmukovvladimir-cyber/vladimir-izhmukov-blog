Cline это открытый ИИ-агент для программирования, который сам правит файлы проекта и запускает команды в терминале. Расширение для VS Code ставится из магазина расширений, а консольная версия командой npm install -g cline. Открытая версия бесплатна, вы платите за модель своим ключом, через провайдера Cline по факту или подпиской ClinePass за $9,99 в месяц.

Кроме VS Code, Cline работает как плагин для JetBrains, консольная программа Cline CLI, приложение Cline Desktop и облачные агенты в браузере. Код открытого репозитория опубликован под лицензией Apache-2.0. Ниже разберу установку, настройку и цены.

Что умеет Cline

Cline ведёт задачу от плана изменений до запуска тестов. В расширении для редактора правки файлов и команды по умолчанию идут вам на подтверждение, а в консольной версии запуск с задачей по умолчанию работает с автоподтверждением всех действий. Возможности ниже относятся к локальному Cline: в облачных сессиях правила, skills, MCP и коннекторы пока не подгружаются.

Что нового в Cline к ноябрю 2026

К ноябрю 2026 года у Cline появились приложение Cline Desktop, облачные агенты Cline Cloud Agents, пакет Cline SDK для разработчиков и доска задач Kanban.

  • Cline Desktop (бета). Отдельное приложение без редактора: параллельные сессии, задачи по расписанию и импорт переписки из Claude Code и Codex. Последняя версия 0.0.49 вышла 26 октября 2026 года.
  • Cline Cloud Agents. Агент работает в облачной песочнице прямо из браузера: вы подключаете GitHub, выбираете репозиторий и ветку, агент коммитит в свою ветку cline/, а когда задача готова, вы просите его открыть pull request.
  • Cline SDK. Пакет @cline/sdk, чтобы собрать своего агента на том же движке.
  • Kanban (превью). Доска задач для нескольких агентов сразу, кроме Cline на ней можно запускать Claude Code, Codex и OpenCode.
  • Бесплатные модели. Время от времени Cline даёт владельцам аккаунта Cline попробовать отдельные модели бесплатно в пределах квоты, список меняется.

Свежие версии на 26 октября 2026 года: расширение 4.1.26 и CLI 3.0.74, обе вышли в один день с десктопом.

Как выбрать модель для Cline

  1. Свой ключ (BYOK): Anthropic, OpenAI, Gemini, DeepSeek, Groq, Cerebras, AWS Bedrock, GCP Vertex, Vercel AI Gateway.
  2. Один ключ ко многим моделям: OpenRouter.
  3. Без оплаты облачного API: локальные модели на своём компьютере через Ollama или LM Studio, если хватает мощности железа.
  4. Без отдельных ключей: ClinePass или провайдер Cline с оплатой по факту.

Доступ и оплата каждого провайдера зависят от его собственных условий, из России я эти варианты не проверял.

Как установить Cline

Cline ставится из магазина расширений редактора, из JetBrains Marketplace, командой npm для CLI или установщиком Cline Desktop, ниже шаги по официальной инструкции.

В VS Code, Cursor или Windsurf

  1. Откройте панель расширений сочетанием Ctrl/Cmd + Shift + X.
  2. Найдите «Cline» и нажмите Install.
  3. Откройте значок Cline на боковой панели.
  4. В настройках Cline выберите провайдера: Cline с оплатой по факту, ClinePass или свой ключ.

Windsurf и VSCodium берут расширение из Open VSX, порядок тот же. В списке поддерживаемых редакторов ещё VSCodium и Antigravity.

В JetBrains

  1. Откройте Settings, раздел Plugins, вкладку Marketplace.
  2. Найдите «Cline» и установите плагин.
  3. Перезапустите IDE и откройте Cline через View, Tool Windows.

Код плагина для JetBrains, в отличие от остального Cline, не открыт.

Cline CLI

Нужен Node.js версии 20 или новее, рекомендован 22. Установка командой npm install -g cline, затем вход командой cline auth, после этого агент запускается командой cline или сразу с задачей: cline "ваша задача".

Cline Desktop

Отдельное приложение скачивается с cline.bot/desktop. На странице загрузки сейчас есть сборки для macOS (Apple Silicon и Intel), Windows и Linux, всё приложение в статусе беты.

Как настроить Cline под проект

Настройка Cline под проект сводится к трём вещам: правилам проекта, режиму Plan и осторожному автоподтверждению. В режиме Plan агент изучает код и составляет план. Автоподтверждение разрешает ему выполнять выбранные действия без отдельного запроса.

  1. Создайте в корне проекта папку .clinerules и положите в неё Markdown-файл, например project.md, со стеком, стилем кода и запретами.
  2. Начинайте задачу в режиме Plan: агент изучит код, задаст вопросы и покажет, что собирается сделать.
  3. Переключайтесь в Act, когда план вас устраивает.
  4. Автоподтверждение действий включайте только для безопасных операций вроде чтения файлов. В консольной версии запуск cline "задача" по умолчанию подтверждает всё сам, ручное подтверждение включается флагом --auto-approve false.
  5. Перед большими правками делайте коммит в git, тогда изменения в файлах можно откатить к этому коммиту, плюс у Cline есть свои чекпоинты.

Как не тратить лишние деньги на токены

  • Давайте агенту конкретную задачу с файлами, где искать.
  • Для простых правок берите дешёвую модель, сильную оставляйте для архитектуры.
  • Длинные сессии начинайте заново: цена запроса зависит от того, сколько контекста реально ушло в модель, от длины ответа, тарифа, кэша и сжатия истории, а длинная переписка обычно увеличивает контекст.

Частые вопросы

Cline это бесплатный открытый агент для кода, а ответы на частые вопросы о нём ниже.

Что такое Cline? Это открытый ИИ-агент для программирования, который правит файлы проекта и запускает команды в терминале.

Cline бесплатный? Да, для индивидуальных разработчиков расширение и CLI бесплатны. Платить нужно только за модель или за подписку ClinePass.

Как скачать Cline? Через магазин расширений VS Code или JetBrains, командой npm install -g cline для CLI или установщиком с cline.bot/desktop.

Что такое ClinePass? Подписка за $9,99 в месяц после промо-периода с доступом к 15 моделям с открытыми весами без отдельных ключей.

Есть ли в Cline бесплатные модели? Да, Cline периодически открывает отдельные модели бесплатно в пределах квоты для всех, у кого есть аккаунт Cline, их помечают тегом FREE в списке моделей. Набор меняется.

Как настроить Cline в VS Code? Установите расширение, выберите провайдера модели, вставьте ключ или войдите в аккаунт Cline, положите правила проекта в папку .clinerules.

Чем Cline отличается от Cursor? Cline работает внутри вашего редактора и подключает модели разных провайдеров, Cursor это отдельный редактор со своими тарифами.

Что делать дальше

Режим Plan в Cline показывает план до правок, поэтому первую задачу удобно дать маленькую, например добавить проверку формы или написать тест. Поставьте Cline в свой редактор, подключите модель, прочитайте план, переключитесь в режим Act и сравните результат с тем, как сделали бы сами.

Агенты вроде Cline помогают с правками, командами и тестами, а результат всё равно нужно проверять. Как я веду контент через нейросети, я разобрал на своём примере: как вести Reels с ChatGPT.
