# Gemini CLI: агент Google в терминале и что с ним стало в 2026

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Gemini CLI это открытый ИИ-агент Google, который работает в терминале: читает большие проекты, пишет и правит код, отлаживает ошибки по описанию и автоматизирует рутину вроде пулл-реквестов. Главное, что нужно знать в 2026 году: 19 мая Google объявил переход на Antigravity CLI, и с 18 июня 2026 года Gemini CLI перестал обслуживать бесплатных пользователей и подписчиков Google AI Pro и Ultra. Доступ сохранили организации с лицензией Gemini Code Assist Standard или Enterprise и те, кто работает по платному API-ключу. Старые инструкции про 1 000 бесплатных запросов в день через Google-аккаунт больше не работают. Ниже разберу, что осталось, как установить и чем заменить.

## Что такое Gemini CLI

| Что | Как устроено |
|---|---|
| Разработчик | Google |
| Лицензия | Apache-2.0, код открыт на GitHub |
| Популярность | около 107,6 тыс. звёзд на GitHub |
| Что делает | работает с кодовой базой, генерирует приложения из PDF и набросков, отлаживает, автоматизирует |
| Подключения | MCP-серверы, неинтерактивный режим с выводом в JSON |
| Вход | Google OAuth, ключ GEMINI_API_KEY или Vertex AI |

В README репозитория прямо написано, что для бесплатных пользователей и подписчиков Google One Gemini CLI заменён Antigravity CLI и что под новейшие модели он не оптимизирован.

## Что изменилось с 18 июня 2026 года

1. 19 мая 2026 года Google объявил, что Gemini CLI переходит в Antigravity CLI.
2. С 18 июня Gemini CLI и расширения Gemini Code Assist перестали работать для бесплатных индивидуальных аккаунтов и подписок Google AI Pro и Ultra.
3. Доступ остался у организаций с лицензиями Code Assist Standard и Enterprise.
4. Работа по платным API-ключам Gemini и через Gemini Enterprise Agent Platform продолжается.
5. Скиллы, хуки, субагенты и расширения по обзорам переносятся в Antigravity как плагины.

## Gemini CLI limits: лимиты запросов

Страница квот geminicli.com сама помечена как относящаяся к старой схеме, но числа на ней такие:

| Способ входа | Лимит в сутки |
|---|---|
| Google-аккаунт бесплатно | 1 000 запросов, для личных аккаунтов после 18.06.2026 не действует |
| API-ключ Gemini без оплаты | 250 запросов, только модели Flash |
| Google AI Pro, Code Assist Standard | 1 500 запросов |
| Google AI Ultra, Code Assist Enterprise | 2 000 запросов |
| Оплата по токенам через API или Vertex | по расходу |

Кроме суточных есть лимиты в минуту, их число страница не называет. Для новых пользователей Vertex AI Express Mode даёт 90 дней без привязки биллинга.

## Как установить Gemini CLI

Варианты из README репозитория:

1. Запуск без установки: `npx @google/gemini-cli`.
2. Глобальная установка через npm: `npm install -g @google/gemini-cli`.
3. macOS и Linux через Homebrew: `brew install gemini-cli`.
4. macOS через MacPorts: `sudo port install gemini-cli`.

### Gemini CLI install на Windows

Отдельной команды для Windows в README нет. Рабочий путь через npm: поставьте Node.js с официального сайта, откройте PowerShell и выполните команду глобальной установки из пункта 2. После установки запустите `gemini` и выберите способ входа. С личным бесплатным аккаунтом вход после июня 2026 года не сработает, понадобится платный API-ключ или корпоративная лицензия.

## Gemini CLI из России

По странице Google о регионах Gemini API и Google AI Studio доступны только в перечисленных странах, и России в списке нет. Работу CLI из России я не проверял.

## Чем заменить Gemini CLI

| Вариант | Кому подойдёт |
|---|---|
| Antigravity CLI | официальная замена от Google, скачивается на antigravity.google/download |
| [Claude Code](/guides/claude-code/) | агент Anthropic в терминале |
| [Codex](/guides/codex/) | агент OpenAI |
| [Cline](/guides/cline/) | открытый агент для VS Code с любой моделью |
| [Cursor](/guides/cursor-ai/), [Windsurf](/guides/windsurf/) | редакторы со встроенным агентом |

Antigravity CLI по обзорам не открыт и пока не повторяет все функции Gemini CLI, у Google есть отдельная инструкция по переезду. Если нужен доступ к моделям Gemini без привязки к одному инструменту, посмотрите [OpenRouter](/guides/openrouter/), а для работы без интернета локальные модели через [Ollama](/guides/ollama/).

### Как переехать без потерь

1. Сохраните свои файлы инструкций, MCP-конфигурацию и расширения.
2. Установите Antigravity CLI и пройдите шаги из официального руководства по миграции.
3. Проверьте на маленькой задаче, что подключения работают.
4. Если чего-то не хватает, держите для этих задач Cline или Claude Code.

## Минусы Gemini CLI сейчас

- Для личных бесплатных и Pro-аккаунтов закрыт с 18 июня 2026 года.
- Не оптимизирован под новейшие модели Google.
- Официальной инструкции для Windows в README нет.
- Gemini API официально недоступен в России.

## Частые вопросы

**Что такое Gemini CLI?**
Это открытый ИИ-агент Google для терминала, который работает с кодом, отлаживает ошибки и автоматизирует задачи разработчика.

**Gemini CLI ещё работает?**
Да, для организаций с лицензией Code Assist Standard или Enterprise и по платным API-ключам. Бесплатные и Pro-пользователи с 18 июня 2026 года переведены на Antigravity CLI.

**Какие лимиты у Gemini CLI?**
От 250 запросов в сутки по бесплатному API-ключу с моделями Flash до 2 000 на тарифах Ultra и Enterprise.

**Как установить Gemini CLI?**
Командой `npm install -g @google/gemini-cli`, через Homebrew на macOS и Linux или запуском `npx @google/gemini-cli` без установки.

**Как установить Gemini CLI на Windows?**
Поставьте Node.js и выполните установку через npm в PowerShell. Отдельного установщика для Windows нет.

**Что такое Antigravity CLI?**
Это новый терминальный агент Google, который заменил Gemini CLI для бесплатных и Pro-пользователей.
