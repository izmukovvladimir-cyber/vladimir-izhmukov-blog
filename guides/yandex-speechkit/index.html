Yandex SpeechKit: озвучка текста, голоса, Playground, цены 2026, бесплатно ли и распознавание речи

AI RealshiftВладимир Ижмуков

Yandex SpeechKit это облачный сервис Яндекса для синтеза и распознавания речи. Разбираю, как озвучить текст в Playground без программирования, какие есть голоса и амплуа, сколько стоит синтез и транскрибация в 2026 году, есть ли бесплатный грант и как подключить API.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Yandex SpeechKit это облачный сервис Яндекса, который озвучивает текст голосом нейросети и превращает аудио в текст. Пользоваться им можно без программирования через веб-Playground в консоли Yandex AI Studio или подключить к своему продукту по API. В синтезе 34 голоса, из них 24 русских, у части голосов есть эмоции. Бесплатного тарифа и стартового гранта для новых клиентов сейчас нет, но тест стоит копейки: 0,1626 ₽ за фразу до 250 символов. Сервис российский, VPN не нужен, оплата российской картой или через СБП.

Что такое Yandex SpeechKit

SpeechKit входит в Yandex Cloud, а в 2026 году его документация и Playground переехали в Yandex AI Studio. Старые адреса вида yandex.cloud/ru/docs/speechkit теперь перенаправляют на aistudio.yandex.ru.

Сервис решает две задачи:

  • синтез речи: озвучка коротких фраз и длинных текстов, голосовые ассистенты, автоответчики, озвучка роликов;
  • распознавание речи: расшифровка звонков, встреч, лекций и голосовых сообщений в реальном времени или из файлов.

Скачать SpeechKit как программу нельзя: это облачный сервис. Из Playground скачивается готовый аудиофайл, а в свой продукт SpeechKit подключается по API.

Амплуа: эмоции голоса

У части голосов есть амплуа, то есть манера речи. У Джейн нейтральное, радостное и раздражённое, у Маши радостное, строгое и дружелюбное. У Ирины из новой линейки LiveTTS есть формальное, поддерживающее, амплуа рассказчика и продающее. Для озвучки рекламного ролика я бы начинал с продающего амплуа Ирины.

Разметка: ударения и паузы

Чтобы голос читал правильно, текст размечают. Можно поставить ударение, паузу тегом sil длиной до 7 000 мс, задать произношение слова или использовать SSML. Темп меняется от 0,1 до 3,0.

Как озвучить текст в Yandex SpeechKit без программирования

  1. Войдите в консоль Yandex AI Studio через Яндекс ID.
  2. Создайте платёжный аккаунт: для физлица подходит «Личный аккаунт».
  3. Выберите каталог, где у вас есть роли ai.playground.user и ai.datasets.editor или выше.
  4. Откройте раздел AI Speech и Playground синтеза.
  5. Вставьте текст до 5 000 символов, выберите язык, голос, амплуа, скорость и формат файла.
  6. Нажмите синтез, послушайте результат и скачайте файл.

Кнопка просмотра кода в Playground показывает тот же запрос для API, это удобный способ разобраться, как подключить синтез к своему сервису. Длинный текст больше 5 000 символов придётся резать на части.

Распознавание речи и транскрибация

Распознавание работает в четырёх режимах:

РежимДля чего
Потоковоеречь в реальном времени, звонки, голосовые ассистенты
Синхронноекороткие файлы
Асинхронноедлинные записи до 4 часов через API
Отложенное асинхронноето же, но результат не срочно и в 4 раза дешевле

В Playground распознавание поддерживает 16 языков с автоопределением и файлы до 60 МБ, числа и даты приводятся к нормальному виду. Для расшифровки встреч и лекций выгоднее асинхронный режим, а если результат нужен не прямо сейчас, отложенный.

Сколько стоит озвучить ролик

Сценарий рилса на 60 секунд это примерно 900 символов. Через API v3 с голосом general это 4 блока по 250 символов, то есть около 0,65 ₽. Озвучка целой книги на 1 млн символов выйдет примерно в 650 ₽ через API v3 и 1 342 ₽ через API v1.

Свой голос: Brand Voice

Для компаний есть Brand Voice, голос под бренд. Тариф Lite с 10 октября 2026 года отключён из-за инцидента. Для Premium хостинг голоса считается по запросу.

Yandex SpeechKit бесплатно

Бесплатного тарифа у SpeechKit нет, бесплатные объёмы на странице цен не указаны. В документации Yandex Cloud прямо сказано, что пробный период и стартовый грант для новых клиентов сейчас недоступны. Старые статьи про грант на 4 000 ₽ устарели.

Тарифицируется ли синтез в самом Playground, официальные страницы прямо не говорят. Без платёжного аккаунта зайти в Playground нельзя. На практике тест нескольких фраз стоит несколько копеек.

Yandex SpeechKit в России

Сервис российский, VPN не нужен. Физлица платят банковской картой или через СБП с «Личного аккаунта», организации переводом по договору или картой. Юрлицо для работы не обязательно.

Можно ли использовать синтезированную озвучку в рекламе и на YouTube, в FAQ SpeechKit прямого ответа нет. Перед коммерческим использованием проверьте условия в оферте Yandex Cloud.

Подводные камни

  • В API v3 короткая фраза на 20 символов стоит как блок на 250.
  • Синхронное и потоковое распознавание округляют каждый отрезок вверх до 15 секунд, поэтому много коротких реплик выходит дороже одного длинного файла.
  • В Playground максимум 5 000 символов за раз.
  • Новые голоса LiveTTS работают только в API v3 и Realtime API.

Частые вопросы

Что такое Yandex SpeechKit? Облачный сервис Яндекса для синтеза и распознавания речи с API и веб-Playground.

Как озвучить текст в Yandex SpeechKit? В консоли AI Studio откройте AI Speech и Playground синтеза, вставьте текст до 5 000 символов, выберите голос и скачайте файл.

Yandex SpeechKit бесплатный? Нет, бесплатного тарифа и стартового гранта для новых клиентов сейчас нет. Тест стоит копейки.

Сколько стоит Yandex SpeechKit? Синтез 0,1626 ₽ за фразу до 250 символов в API v3 или 1 342 ₽ за 1 млн символов в API v1. Распознавание от 0,0381 ₽ за 15 секунд.

Есть ли у SpeechKit демо или Playground? Да, Playground синтеза и распознавания есть в консоли AI Studio, нужен платёжный аккаунт.

Можно ли скачать Yandex SpeechKit? Программы для установки нет, скачивается только готовый аудиофайл.

Подходит ли SpeechKit для транскрибации? Да, асинхронное распознавание принимает записи до 4 часов, это около 36 ₽ за час, в отложенном режиме около 9 ₽.

Есть ли у SpeechKit API? Да, API v1, API v3, Realtime API и SDK для Python.
