# Google AI Studio: как пользоваться бесплатно Gemini, создавать приложения и ключ API в 2026

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Google AI Studio это бесплатная веб-площадка Google для работы с моделями Gemini. В ней можно общаться с моделью и загружать файлы, видео и аудио, генерировать картинки и ролики, собирать приложения по текстовому описанию в режиме Build и получать API-ключ для своих ботов и сервисов. Для входа нужен только аккаунт Google, карту привязывать не надо. Сам интерфейс бесплатный, у API есть бесплатный уровень с ограничениями по числу запросов.

Блогеру AI Studio полезен тем, что даёт сильные модели Gemini без подписки и позволяет расшифровать видео, разобрать длинный документ или собрать простой сервис без программиста.

## Что умеет Google AI Studio

| Раздел | Что делает | Где пригодится |
|---|---|---|
| Chat | диалог с Gemini, загрузка файлов | тексты, разбор документов |
| Работа с видео и аудио | понимает ролики и записи | расшифровка, конспект |
| Генерация картинок | создаёт изображения по описанию | обложки, визуал |
| Генерация видео | модели Veo, часть функций платная | короткие ролики |
| Build | собирает приложение по описанию | калькулятор, бот, мини-сервис |
| API-ключ | доступ к Gemini из своих программ | автоматизация |

## Как пользоваться Google AI Studio по шагам

1. Откройте aistudio.google.com и войдите через аккаунт Google.
2. Выберите модель Gemini в правой панели. Для быстрых задач подходит Flash, для сложных Pro.
3. Напишите запрос в поле внизу или перетащите файл: PDF, картинку, видео, аудио.
4. Включите поиск Google в настройках, если нужны свежие данные со ссылками.
5. Сохраните удачный запрос, чтобы вернуться к нему позже.

### Как собрать приложение в режиме Build

1. Откройте вкладку Build.
2. Опишите приложение словами: «калькулятор стоимости съёмки рилса с выбором количества роликов и отправкой заявки».
3. Дождитесь, пока AI Studio соберёт интерфейс и код.
4. Поправьте детали голосом или текстом, можно указать на нужную часть экрана.
5. Опубликуйте приложение или скачайте код.

### Как получить API-ключ

1. Нажмите Get API key в меню AI Studio.
2. Создайте ключ в новом или существующем проекте Google Cloud.
3. Скопируйте ключ и храните его как пароль, не публикуйте в открытых местах.

## Сколько стоит Google AI Studio

| Что | Цена | Ограничения |
|---|---|---|
| Интерфейс AI Studio | бесплатно | лимиты на число запросов к моделям |
| Бесплатный уровень API | бесплатно | несколько запросов в минуту и дневной лимит, у Pro он ниже, чем у Flash |
| Платный уровень API | оплата за токены | высокие лимиты, данные не идут на обучение |
| Veo через API | только платно | генерация видео |

На бесплатном уровне Google может использовать ваши запросы для улучшения моделей. Точные лимиты меняются и зависят от модели, сверяйте их на странице тарифов Gemini API.

## Google AI Studio на русском и из России

Модели Gemini понимают русский и отвечают на нём. Интерфейс AI Studio на английском. Из России сервис официально недоступен, для входа нужен VPN с сервером в поддерживаемой стране. Платный уровень API подключается через Google Cloud с зарубежной картой.

## Частые вопросы

**Google AI Studio бесплатный?** Да, интерфейс бесплатный, у API есть бесплатный уровень с лимитами.

**Чем AI Studio отличается от приложения Gemini?** Приложение Gemini это чат для всех. AI Studio даёт больше настроек моделей, режим Build для приложений и API-ключ.

**Нужна ли карта для AI Studio?** Нет, для бесплатного использования достаточно аккаунта Google.

**Работает ли AI Studio из России?** Официально нет, нужен VPN.

**Используются ли мои данные для обучения?** На бесплатном уровне Google может использовать запросы для улучшения моделей. На платном уровне нет.
