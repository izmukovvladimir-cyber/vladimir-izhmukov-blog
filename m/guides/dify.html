Dify: что это, как пользоваться, Dify Cloud и установка через Docker на свой сервер, цены и лицензия в 2026

AI RealshiftВладимир Ижмуков

Dify это open-source платформа, где ИИ-агентов, чат-ботов и базы знаний собирают в визуальном редакторе. Разбираю Dify Cloud и его тарифы, установку на свой сервер через Docker, лицензию, русский интерфейс и доступ из России.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Dify это open-source платформа от американской компании LangGenius, на которой ИИ-приложения, чат-боты, базы знаний и агентные сценарии собирают в визуальном редакторе из блоков. Работает в двух вариантах: облако Dify Cloud с бесплатным тарифом Sandbox и платными от $59 в месяц, и бесплатная версия на своём сервере через Docker. Интерфейс есть на русском. Актуальная версия 1.18.0 вышла 23 октября 2026 года.

Что такое Dify

Репозиторий Dify появился на GitHub в апреле 2023 года и сейчас собрал около 159 тысяч звёзд, это один из самых популярных open-source проектов про ИИ-агентов. В марте 2026 года компания привлекла $30 млн и заявила, что Dify работает на 1,4 млн машин и у неё 280 корпоративных клиентов.

Простыми словами, Dify нужен тем, кто хочет собрать своего ИИ-помощника без программирования с нуля: подключить модель, дать ей документы компании, нарисовать логику ответа и выдать результат как чат на сайте или API.

Что умеет Dify

  • Визуальный редактор с блоками: модель, условие, код, HTTP-запрос, агент, база знаний.
  • База знаний (RAG): загружаете документы, и бот отвечает по ним, опираясь на ваши тексты.
  • Подключение моделей через плагины: OpenAI, Anthropic и множество других провайдеров, включая локальные модели.
  • Триггеры: воркфлоу умеет запускаться по событию, даже без сообщения в чате.
  • API для каждого приложения, плюс с версии 1.18.0 OpenAPI и консольная утилита difyctl.
  • Переносимые пакеты: приложение переезжает на другой сервер вместе со своими ресурсами.

В версии 1.18.0 агент научился сам выбирать ветку воркфлоу, а у агента появилась собственная база знаний.

Цены считаются за одно рабочее пространство, налоги добавляются сверху. При оплате за год выходит примерно на 17% дешевле.

Что даёт бесплатная версия

Бесплатных вариантов два:

  1. Sandbox в облаке: 200 кредитов, 5 приложений, один участник. Хватает, чтобы попробовать и собрать прототип, для живого бота мало.
  2. Community на своём сервере: сама платформа бесплатна и без лимитов от Dify, вы платите только за сервер и за API моделей.

Как поставить Dify на свой сервер

Официальный минимум для установки через Docker Compose: 2 ядра процессора и 4 ГБ оперативной памяти, Docker 19.03 или новее и Docker Compose 2.24.0 или новее. На Windows Dify ставится через WSL 2, на macOS Docker Desktop лучше выделить не меньше 2 ядер и 8 ГБ.

Шаги по официальной документации:

  1. Скачайте свежий релиз из репозитория: git clone с GitHub, ветка последнего релиза.
  2. Перейдите в папку dify/docker и скопируйте файл настроек: cp .env.example .env.
  3. Сгенерируйте токен командой openssl rand -base64 32 и впишите его в .env в строку DIFY_AGENT_LOCAL_SANDBOX_AUTH_TOKEN. С версии 1.18.0 без этого токена агентная песочница не стартует.
  4. Запустите сервисы: docker compose up -d, проверьте статус командой docker compose ps.
  5. Откройте в браузере адрес сервера с путём /install и создайте администратора. Дальше вход по адресу сервера.

Docker поднимает сразу несколько контейнеров: API, веб-интерфейс, бэкенд агентов, песочницу для кода, сервис плагинов и векторную базу (Weaviate, Qdrant, Chroma, Elasticsearch или другую на выбор).

Что учесть при установке

  • 2 ядра и 4 ГБ это минимум. С Elasticsearch и несколькими приложениями памяти нужно больше.
  • По умолчанию Dify открывается по обычному HTTP. Для боевого сервера нужен домен и сертификат, certbot в комплекте есть.
  • При обновлении до 1.18.0 обновляйте образы API, воркеров и агентов вместе, иначе агентные блоки не заработают.

Если вы раньше не собирали агентов, начните с разбора как настроить ИИ-агента: там логика шагов без привязки к конкретной платформе.

Лицензия Dify

Dify распространяется по собственной лицензии на основе Apache 2.0 с дополнительными условиями.

  • Коммерческое использование разрешено, в том числе как платформы внутри компании.
  • Коммерческая лицензия нужна, если вы делаете из Dify сервис для разных клиентов, где у каждого своё рабочее пространство.
  • Коммерческая лицензия нужна, если вы убираете или меняете логотип и копирайт Dify в веб-интерфейсе.

Поставить Dify для своей компании и обслуживать клиентов внутри одного пространства можно бесплатно. Перепродавать его как свой облачный сервис или ставить свой логотип без договора с LangGenius нельзя.

Dify на русском

Русский интерфейс в Dify есть, язык «Русский (Россия)» выбирается в настройках, всего локалей 25. Документация на английском, китайском и японском, русской версии документации нет.

Dify в России

Прямой проверки с российского адреса у меня нет. В условиях Dify Россия поимённо не названа, но пользователь облака подтверждает, что не находится в стране под санкциями США, и соглашается с экспортными ограничениями. Карты российских банков зарубежные сервисы обычно не принимают, для облака нужна зарубежная карта или посредник.

Версия на своём сервере не зависит от облака: её можно поставить на любой сервер, в том числе российский. Отдельно продумайте доступ к моделям, OpenAI и Anthropic требуют своего доступа, а через плагины можно подключить и других провайдеров.

Dify или n8n и другие аналоги

  • n8n сильнее в автоматизации процессов и интеграциях с сервисами, ИИ там один из блоков. Dify сильнее в базах знаний и чат-ботах. Подробно про n8n я писал в обзоре n8n.
  • Flowise был похожим визуальным конструктором агентов, но в августе 2026 года проект закрыли, подробности в статье про Flowise.
  • Langflow тоже визуальный конструктор агентов с открытым кодом.
  • Агент на коде через Claude Code или LangGraph гибче любой платформы, но требует программиста.

Если вы выбираете, какие задачи бизнеса вообще отдавать агентам, посмотрите разбор ИИ-агентов для бизнеса.

Минусы Dify

  • Лицензия с условиями: свой SaaS и смена логотипа требуют договора.
  • Бесплатный Sandbox мал для реального бота: 5 приложений, 50 документов, логи за 30 дней.
  • Своя установка требует администрирования: обновления, резервные копии, сертификат.
  • Документации на русском нет.

Частые вопросы

Dify что это? Open-source платформа от LangGenius, где ИИ-приложения, чат-боты, базы знаний и агентов собирают в визуальном редакторе.

Сколько стоит Dify Cloud? Sandbox бесплатно, Professional $59 в месяц, Team $159 в месяц. При оплате за год примерно на 17% дешевле.

Как установить Dify через Docker? Скачать релиз с GitHub, скопировать .env.example в .env, вписать токен песочницы, запустить docker compose up -d и открыть /install в браузере.

Где найти Dify на GitHub? В репозитории langgenius/dify, актуальная версия 1.18.0 от 23 октября 2026 года.

Как войти в Dify? Облако открывается по адресу cloud.dify.ai. На своём сервере при первом запуске нужно открыть адрес сервера с путём /install.

Можно ли скачать Dify? Отдельного установщика нет, Dify ставится через Docker Compose из репозитория.

Есть ли Dify на русском? Да, русский интерфейс есть, документация только на английском, китайском и японском.
