# Claude Code: что это, как установить и пользоваться в 2026, цены и тарифы

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Claude Code это ИИ-агент от Anthropic, который работает прямо на вашем компьютере или сервере. Вы пишете задачу обычными словами, а он сам читает файлы, пишет и запускает код, правит тексты, ставит программы и доводит работу до результата. Ставится одной командой в терминале, входит в платные тарифы Claude: Pro за 20 долларов в месяц и Max за 100 или 200 долларов.

Я веду на Claude Code целый отдел агентов: они собирают подборки роликов, пишут сценарии и отвечают людям в директе. Начинать можно с одной простой задачи.

## Что умеет Claude Code

| Задача | Что делает агент | Пример |
|---|---|---|
| Работа с файлами | читает, правит, переименовывает | разобрать папку с материалами |
| Код и скрипты | пишет, запускает, чинит ошибки | бот для телеграма, парсер |
| Сайты и лендинги | собирает страницу и выкладывает | посадочная под продукт |
| Тексты | пишет и редактирует по вашим правилам | посты, письма, сценарии |
| Автоматизация | запускает задачи по расписанию | утренняя сводка |
| Подключения | работает с сервисами через MCP | таблицы, календарь, CRM |

## Как установить Claude Code

1. Оформите подписку Claude Pro или Max на claude.ai, бесплатный план Claude Code не включает.
2. Откройте терминал. На Mac это программа «Терминал», на Windows PowerShell.
3. На Mac и Linux вставьте команду `curl -fsSL https://claude.ai/install.sh | bash`.
4. На Windows в PowerShell вставьте `irm https://claude.ai/install.ps1 | iex`.
5. Проверьте установку командой `claude doctor`.
6. Перейдите в папку проекта и наберите `claude`, при первом запуске войдите в свой аккаунт Anthropic.

Есть и другой путь через npm: `npm install -g @anthropic-ai/claude-code`, он требует Node.js 18 или новее и обновляется вручную. Родной установщик обновляется сам.

### Первые задачи для Claude Code

- «Разбери эту папку, сгруппируй файлы по темам и сделай оглавление».
- «Напиши скрипт, который каждое утро собирает новые посты из этого канала в один файл».
- «Сделай одностраничный сайт под мой продукт по этому описанию».
- «Прочитай мои последние 20 постов и опиши мой стиль в файле правил».

### Как не тратить лимиты впустую

- Пишите задачу целиком: цель, контекст, что считается готовым результатом.
- Положите в папку проекта файл CLAUDE.md с правилами: кто вы, как писать, что нельзя трогать. Агент читает его при каждом запуске.
- Большую работу делите на шаги и проверяйте каждый.
- Для простых задач переключайтесь на более лёгкую модель командой `/model`.

## Сколько стоит Claude Code

| План | Цена в месяц | Для кого |
|---|---|---|
| Free | 0 | Claude Code не входит |
| Pro | 20 долларов, при оплате за год около 17 | первые задачи и обучение |
| Max 5x | 100 долларов | ежедневная работа, в 5 раз больше лимита Pro |
| Max 20x | 200 долларов | агенты весь день, в 20 раз больше лимита Pro |
| API | оплата за токены | автоматизация и свои сервисы |

Лимиты считаются окнами по несколько часов и по неделе. Автоматические запуски через GitHub Actions и фоновые команды с 15 июня 2026 года идут из отдельного месячного пула. Тарифы меняются, перед покупкой сверьте их на claude.com.

## Claude Code на русском и из России

Агент понимает задачи на русском и отвечает на нём. Интерфейс терминала на английском, но команд немного. Подписка оплачивается зарубежной картой, из России обычно помогает VPN или удалённый сервер за рубежом. Удобный вариант поставить Claude Code на арендованный сервер: тогда агент работает круглосуточно, даже когда ваш компьютер выключен.

## Частые вопросы

**Claude Code бесплатный?** Нет, он входит в платные тарифы Pro и Max или работает по API с оплатой за токены.

**Нужно ли уметь программировать?** Нет. Задачи пишутся обычными словами, агент сам пишет и запускает код. Понимать, что вы хотите получить, важнее знания языков.

**Чем Claude Code отличается от чата Claude?** Чат отвечает текстом. Claude Code сам работает с файлами, программами и сервисами на компьютере и доводит задачу до результата.

**Можно ли поставить Claude Code на телефон?** Сам агент живёт на компьютере или сервере, а управлять им с телефона можно через телеграм-бота, так работают мои агенты.

**Сколько лимита хватает на Pro?** Для нескольких задач в день хватает. Если агент работает часами каждый день, нужен Max.
