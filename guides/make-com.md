# Make.com: автоматизация без кода, как собрать первый сценарий, кредиты и тарифы 2026

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Make.com, раньше Integromat, это конструктор автоматизаций без кода. Вы собираете сценарий из модулей-приложений на визуальной схеме, например «новая заявка в форме → запись в Google Таблицу → сообщение в Telegram». С августа 2025 года Make считает работу в кредитах вместо операций, старые операции перевели один к одному. Бесплатный план даёт 1 000 кредитов в месяц. В Make есть AI Agents и можно подключить свой ключ нейросети на любом платном тарифе.

Ниже разбираю, как собрать первый сценарий и сколько кредитов он съест.

## Как устроен Make

| Понятие | Что это |
|---|---|
| Сценарий | вся автоматизация целиком, схема из модулей |
| Модуль | одно действие в приложении: получить письмо, создать строку, отправить сообщение |
| Триггер | первый модуль, который запускает сценарий |
| Роутер | развилка, когда данные идут по разным веткам |
| Вебхук | адрес, на который другой сервис присылает данные |
| Кредит | единица оплаты, обычно один кредит за одно действие модуля |

## Как собрать первый сценарий в Make

Пример: заявка из формы на сайте приходит вам в Telegram и сохраняется в таблицу.

1. Зарегистрируйтесь на make.com и нажмите Create a new scenario.
2. Первым модулем поставьте Webhooks, Custom webhook и скопируйте адрес.
3. Вставьте этот адрес в настройки формы на сайте как адрес отправки заявок.
4. Отправьте тестовую заявку, Make увидит поля формы.
5. Добавьте модуль Google Sheets, Add a row и разложите поля по колонкам.
6. Добавьте модуль Telegram Bot, Send a message и соберите текст уведомления из полей.
7. Включите сценарий переключателем и отправьте ещё одну заявку для проверки.

Такой сценарий тратит около трёх кредитов на одну заявку: по одному на каждый модуль.

## Как подключить нейросеть в Make

1. Добавьте после триггера модуль OpenAI, Anthropic Claude или другой AI-модуль.
2. Подключите свой ключ API, с ноября 2025 года своего провайдера можно подключить на любом платном тарифе.
3. В промпте сошлитесь на поля из предыдущего модуля, например на текст заявки.
4. Результат передайте дальше: в таблицу, в письмо или в Telegram.

Так собираются автоответы на заявки, сортировка писем по темам и черновики постов по шаблону. Как писать сам промпт, разобрал в статье [как написать промт](/guides/kak-napisat-promt/).

По сторонним обзорам при 10 000 кредитов в месяц Core стоит около 9-12 долларов, оплата за год дешевле помесячной. Открывайте актуальную цену в кабинете перед оплатой. Дополнительные кредиты покупаются пакетами, с ноября 2025 года докупка дороже на 25%.

## Make или n8n

- **Make** проще для старта: всё в браузере, ничего не нужно ставить на сервер.
- **[n8n](/guides/n8n/)** можно поставить на свой сервер и не платить за каждое действие, но придётся разбираться с установкой.
- Если сценариев мало и они простые, бесплатного плана Make хватает надолго.

## Частые вопросы

**Make.com бесплатный?** Да, есть бесплатный план на 1 000 кредитов в месяц.

**Что такое кредиты в Make?** Единица оплаты, которая заменила операции с августа 2025 года. Обычный модуль тратит один кредит за действие.

**Make и Integromat это одно и то же?** Да, Integromat переименовали в Make.

**Можно ли подключить ChatGPT к Make?** Да, через модуль OpenAI или любой AI-модуль со своим ключом API.

**Работает ли Make с Telegram?** Да, есть модуль Telegram Bot для отправки и получения сообщений.

**Чем Make отличается от n8n?** Make работает в облаке и платится за кредиты, n8n можно поставить на свой сервер.
