Open WebUI: что это и где скачать официально (GitHub, PyPI, Docker, настольное приложение для Windows, macOS и Linux), установка через pip, uv и Docker, обновление с сохранением данных, подключение Ollama и лицензия. Версия 0.13.5, проверено 26 ноября 2026.

Open WebUI это платформа для работы с нейросетями, которую вы разворачиваете у себя: по README проекта, к ней подключаются локальные модели через Ollama или API, совместимые с OpenAI, для локальных и облачных моделей. Установить её можно через pip (pip install open-webui, затем запуск open-webui serve и адрес localhost:8080), через uv или через Docker, обновляется она командой pip install -U open-webui или новым образом Docker, а Ollama подключается переменной OLLAMA_BASE_URL или в настройках администратора.

Ниже разберу установку, выбор образа Docker, обновление, подключение Ollama и условия лицензии.

Что такое Open WebUI

Open WebUI это self-hosted платформа: она работает на вашем компьютере или сервере. В README проект описан как расширяемая платформа, рассчитанная на работу полностью офлайн. Офлайн она работает с локальной моделью, например через Ollama: если выбрать для чата облачную модель, Open WebUI отправит запрос и его контекст её провайдеру. Интерфейс открывается в браузере, а модели вы подключаете сами.

Как установить Open WebUI

Open WebUI можно установить через Python, Docker или настольное приложение. Для pip и uv нужен установленный Python или uv, для Docker установленный Docker.

Через Python pip

  1. Поставьте Python 3.12 или 3.11: по документации, это поддерживаемые версии, а на Python 3.13 установка ломается из-за зависимостей.
  2. В терминале выполните pip install open-webui.
  3. Запустите сервер командой open-webui serve.
  4. Откройте в браузере адрес localhost:8080 и создайте первый аккаунт. По документации, первый аккаунт становится администратором и управляет пользователями и настройками.

Через uv

На macOS и Linux с установленным менеджером uv README предлагает команду:

DATA_DIR=~/.open-webui uvx --python 3.12 open-webui@latest serve

По документации, переменная DATA_DIR задаёт папку, где хранятся данные Open WebUI.

Через Docker

Команда из README:

docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main

После запуска интерфейс открывается по адресу localhost:3000. Документация советует сразу задать постоянный ключ WEBUI_SECRET_KEY (параметр -e WEBUI_SECRET_KEY=ваш-ключ), и использовать то же значение при следующих запусках: если при пересоздании контейнера ключ сменится, сеансы сбросятся и придётся входить заново. Параметр -v open-webui:/app/backend/data подключает том Docker: по документации об обновлении, данные (чаты, пользователи, настройки, загрузки) лежат в томе или локальной базе, отдельно от контейнера.

Какой образ выбрать, по README:

Тег образаЧто внутри
:mainстандартный образ с локальными AI-зависимостями, обновляемая сборка без закреплённой версии
:slimоблегчённый образ, эмбеддинги, извлечение текста из документов и голос через внешние сервисы
:cudaOpen WebUI с ускорением CUDA
:ollamaOpen WebUI вместе с Ollama
:devпоследняя сборка для разработки

По инструкции по обновлению, для личной установки подходит :main, а для общей командной лучше закрепить конкретную версию тегом вида :vX.Y.Z. Для доступа к видеокарте NVIDIA в образах :cuda и :ollama README советует добавить --gpus all, для этого нужен NVIDIA Container Toolkit.

Настольное приложение

В README есть ссылка на настольное приложение Open WebUI для macOS, Windows и Linux, оно лежит в отдельном репозитории open-webui/desktop.

Как обновить Open WebUI

Open WebUI обновляется командой pip install -U open-webui при установке через pip или заменой образа при установке через Docker:

  1. Установка через pip. Выполните pip install -U open-webui и перезапустите open-webui serve.
  2. Установка через Docker. По инструкции по обновлению: остановите и удалите контейнер, скачайте свежий образ с тем же тегом, с которым создан контейнер (для :main это docker pull ghcr.io/open-webui/open-webui:main), и создайте контейнер заново с тем же томом и тем же тегом. Если вы закрепили версию тегом вида :vX.Y.Z, укажите новую версию. Данные в томе при удалении контейнера сохраняются.
  3. Чтобы сеансы не сбрасывались при пересоздании контейнера, документация советует задать постоянную переменную WEBUI_SECRET_KEY и передавать то же значение при каждом запуске.

Перед обновлением документация советует сделать резервную копию данных, особенно перед релизами с миграциями базы, которые трудно откатить.

Как подключить Ollama к Open WebUI

Ollama подключается к Open WebUI по адресу работающего сервера Ollama: его задают переменной OLLAMA_BASE_URL при запуске контейнера или в разделе администратора Settings → Connections. Для Ollama на другом сервере пример из README:

-e OLLAMA_BASE_URL=http://your-ollama-server:11434

Подключение можно задать и после запуска: по документации, адрес Ollama указывается в настройках администратора, раздел Settings → Connections → Manage Ollama API Connections. Как поставить Ollama и выбрать модель, я писал в статье Ollama, есть отдельная статья и про LM Studio.

Облачные модели подключаются через API, совместимые с OpenAI: в README для этого есть, например, переменная OPENAI_API_KEY для ключа OpenAI; для другого совместимого сервиса указывают также его адрес. Отдельно я разбирал OpenRouter.

Лицензия Open WebUI

Open WebUI распространяется под собственной лицензией, на GitHub она не отнесена к стандартным. Главное условие в пункте 4: убирать или менять брендинг Open WebUI (название, логотип и другие опознавательные знаки) запрещено. Исключения три: у установки не больше 50 пользователей (физических лиц с прямым доступом) за любые 30 дней подряд, есть предварительное письменное разрешение правообладателя или корпоративная лицензия, которая прямо разрешает такое изменение. Это главное условие, но не полное описание лицензии: текст целиком лежит в репозитории.

Что учесть перед установкой

Перед установкой Open WebUI я советую проверить четыре вещи:

  • Есть ли у вас компьютер или сервер, где он будет работать, и готовы ли вы запускать команды в терминале для pip и Docker. Настольное приложение README предлагает как отдельный путь.
  • Какая версия Python стоит: по документации Python 3.13 не поддерживается.
  • Где будет резервная копия данных перед обновлениями.
  • Какие модели вы подключите: локальные через Ollama или облачные через API.

Частые вопросы

Коротко: Open WebUI ставится через pip, uv, Docker или настольное приложение, открывается на localhost:8080 или localhost:3000 и работает с Ollama и API, совместимыми с OpenAI.

Что такое Open WebUI?

Платформа для работы с нейросетями, которую вы разворачиваете на своём компьютере или сервере. К ней подключаются локальные модели через Ollama и API, совместимые с OpenAI.

Open WebUI бесплатный?

Код открыт на GitHub под собственной лицензией Open WebUI. Главное ограничение в ней касается смены брендинга: менять его можно на установках до 50 пользователей за 30 дней, с письменного разрешения или по корпоративной лицензии. Стоимость облачных моделей зависит от провайдера и выбранной модели.

Как установить Open WebUI на Windows?

Проще всего через настольное приложение: на странице релизов open-webui/desktop скачайте open-webui-x64-setup.exe и запустите установщик. Установку через Docker и pip README описывает без отдельных шагов для Windows.

Где скачать Open WebUI?

Код и релизы лежат в репозитории open-webui на GitHub, пакет для pip в каталоге PyPI, образы Docker в ghcr.io, настольное приложение для Windows, macOS и Linux в репозитории open-webui/desktop. Таблица со всеми адресами есть в разделе «Где скачать Open WebUI».

Как обновить Open WebUI?

Через pip командой pip install -U open-webui. В Docker удалите контейнер, скачайте свежий образ и создайте контейнер заново с тем же томом. Перед обновлением сделайте резервную копию.

Какая последняя версия Open WebUI?

На 26 ноября 2026 года последний релиз на GitHub v0.13.5, опубликован 25 ноября 2026 года.

На каком адресе открывается Open WebUI?

По README: при установке через pip на localhost:8080, при запуске через Docker командой из README на localhost:3000.

Какой Python нужен для Open WebUI?

По документации поддерживаются Python 3.11 и 3.12, Python 3.13 не поддерживается.

Что делать дальше

Open WebUI устанавливается командой pip install open-webui и запускается командой open-webui serve, если в выбранном окружении установлен Python 3.11 или 3.12, или одной командой docker run, если стоит Docker. Следующий шаг: запустите команду из README, создайте аккаунт администратора и подключите Ollama или ключ своего провайдера.
