Что такое Dify

Dify это конструктор ИИ-приложений: на холсте вы соединяете узлы с моделью, условиями, кодом и поиском по базе знаний, а готовое приложение открываете людям через веб, API или MCP-сервер. Базовые сценарии собираются мышкой на холсте, а для своих правил обработки данных есть узел с кодом.

Dify появился на GitHub в апреле 2023 года, сейчас у репозитория около 161 тысячи звёзд. В марте 2026 года компания привлекла $30 млн и написала, что Dify работает больше чем на 1,4 млн машин в 175 странах и регионах, а пользуются им больше 2000 команд и 280 крупных компаний.

Что умеет Dify

Dify позволяет собрать логику приложения на холсте, подключить к нему документы, опубликовать его и смотреть журналы и статистику использования.

  • Визуальный редактор с блоками: модель, условие, код, HTTP-запрос, агент, база знаний.
  • База знаний (RAG): вы загружаете документы, при вопросе Dify находит в них подходящие фрагменты и передаёт их модели, чтобы ответ опирался на ваши тексты.
  • Подключение моделей и инструментов через плагины: провайдеры моделей ставятся в разделе Integrations, там же подключаются инструменты и источники данных.
  • Триггеры: воркфлоу запускается по событию из плагина, по расписанию или по вебхуку, без сообщения в чате.
  • Публикация: веб-приложение, встраивание на сайт, API или MCP-сервер, плюс OpenAPI и консольная утилита difyctl для управления.
  • Переносимые пакеты .ifpkg: приложение переезжает в другое пространство или на другой сервер вместе с поддерживаемыми ресурсами, если импортёр на той стороне совместим.

Что нового в Dify к ноябрю 2026

К ноябрю 2026 года у Dify вышли релизы 1.18.0 от 23 октября и 1.19.0 от 4 ноября: в первом агент научился сам выбирать ветку воркфлоу, во втором внешняя трассировка стала показывать воркфлоу, вызванные как инструменты, до каждого вызова модели.

Релиз от 23 октября 2026 года под номером 1.18.0 принёс четыре изменения:

  1. Агент сам выбирает ветку воркфлоу через Output Routes: вы задаёте условия, и агент решает, куда пойти дальше.
  2. Приложение переносится одним пакетом .ifpkg вместе с агентами, навыками и файлами.
  3. Расширились OpenAPI и консольная утилита difyctl, которые появились ещё летом: через них теперь удобнее собирать и управлять приложениями из командной строки.
  4. В бета-режиме появилась отдельная база знаний агента, для неё нужен отдельный сервис и его настройка.

Релиз от 4 ноября 2026 года под номером 1.19.0 добавил ещё четыре:

  1. Вложенные воркфлоу видны во внешней трассировке до каждого вызова модели, например в Langfuse. Это работает для новых запусков, старые трассы не дополняются.
  2. Пакеты приложений перешли на формат v2 и забирают с собой воркфлоу, которые вызываются как инструменты.
  3. Навыками рабочего пространства можно управлять из командной строки через difyctl.
  4. Несколько файлов для агента загружаются разом, PDF открывается прямо в превью.

Как пользоваться Dify: первое приложение

Первое приложение в Dify Cloud собирают в разделе Studio: подключают модель, строят воркфлоу, проверяют результат тестовым запуском и публикуют. По официальному быстрому старту шаги такие:

  1. Зарегистрируйтесь на cloud.dify.ai, новый аккаунт сразу получает тариф Sandbox.
  2. Откройте Integrations, затем Model Provider, и установите провайдера, например OpenAI. Для моделей, которые покрывают кредиты, ключ API не нужен.
  3. На той же странице нажмите Default Models и выберите модель по умолчанию.
  4. Перейдите в Studio, нажмите Create from Blank и выберите тип Workflow.
  5. Начните с узла User Input, добавьте поля, которые заполняет человек, и соедините их с узлом модели.
  6. В узле модели напишите промпт и вставьте в него переменные из User Input.
  7. Добавьте узел Output и выберите, какой результат он отдаёт.
  8. Нажмите Test Run и проверьте ответ на своих данных.
  9. Опубликуйте приложение: как веб-приложение, виджет на сайте или через API.

Что даёт бесплатная версия

Бесплатных вариантов у Dify два:

  1. Sandbox в облаке: 200 кредитов разово, 5 приложений, один участник, до 2 триггеров на воркфлоу.

Как поставить Dify на свой сервер

Официальный минимум для установки Dify через Docker Compose: 2 ядра процессора и 4 ГиБ оперативной памяти, Docker с Docker Compose 2.35.0 или новее, Git и OpenSSL. На Windows Dify ставится через Docker Desktop и WSL 2, на macOS виртуальной машине Docker Desktop нужно выделить не меньше 2 ядер и 8 ГиБ памяти.

Шаги по официальной документации:

  1. Выберите версию на странице релизов и скачайте её: git clone --branch <версия> --depth 1 https://github.com/langgenius/dify.git, где вместо <версия> стоит тег релиза.
  2. Перейдите в папку dify/docker и создайте файл настроек: cp .env.example .env. Если сервер будет открыт людям, сразу замените в нём стандартные пароли и секреты.
  3. Сгенерируйте токен командой openssl rand -hex 32 и впишите его в .env в строку DIFY_AGENT_LOCAL_SANDBOX_AUTH_TOKEN. Без этого токена бэкенд агентов и его песочница не стартуют.
  4. Запустите сервисы: docker compose up -d, проверьте статус командой docker compose ps --all.
  5. Откройте в браузере адрес сервера с путём /install и создайте администратора. Дальше вход по адресу сервера.

По умолчанию Docker Compose сам поднимает PostgreSQL и векторную базу Weaviate, отдельно ставить базы не нужно. Другую векторную базу или MySQL можно выбрать в .env до первого запуска: смена настройки после запуска не переносит уже сохранённые данные.

Что учесть при установке

  • 2 ядра и 4 ГиБ это минимум, реальная потребность зависит от нагрузки, объёма данных и выбранных компонентов.
  • По умолчанию Dify открывается по обычному HTTP на порту 80. Перед тем как пускать людей, настройте HTTPS.
  • Свои настройки отдельных сервисов кладите в локальные файлы .env по пути, который указан в комментарии нужного файла .defaults в папке docker/envs, сами .defaults не трогайте.
  • При обновлении на ноябрьский релиз сделайте резервную копию, обновляйте все образы Dify вместе и проверьте версию Compose командой docker compose version, порядок описан в заметках к релизу. Пакет .ifpkg переносит приложение, но не заменяет резервную копию всей установки.

Если вы раньше не собирали агентов, начните с разбора как настроить ИИ-агента: там логика шагов без привязки к конкретной платформе.

Лицензия Dify

Dify распространяется по собственной лицензии на основе Apache 2.0 с дополнительными условиями.

  • Коммерческое использование разрешено, в том числе как бэкенд для других приложений и как платформа разработки внутри компании.
  • Коммерческая лицензия нужна, если вы запускаете сервис с несколькими отдельными рабочими пространствами для разных клиентов: по лицензии один тенант равен одному рабочему пространству.
  • Коммерческая лицензия нужна, если вы убираете или меняете логотип и копирайт Dify в его веб-интерфейсе. Если вы используете Dify только как бэкенд без его фронтенда, это условие не действует.

По лицензии Community не требует платы, если вы соблюдаете её условия. Перепродавать его как свой облачный сервис с отдельными пространствами или ставить свой логотип в интерфейс Dify без договора с LangGenius нельзя.

Dify в России

Dify Cloud и версия на своём сервере отличаются по доступу из России. Прямой проверки облака с российского адреса у меня нет. В условиях использования Dify Россия поимённо не названа, но пользователь облака подтверждает, что не находится в стране под санкциями США, не находится под её контролем и не является её гражданином или резидентом. Кроме того, он соглашается с экспортными ограничениями.

Версия на своём сервере не требует Dify Cloud, технически её можно поставить на сервер в любой стране, если ему хватает ресурсов и доступны нужные образы. Внешние модели и Marketplace плагинов при этом остаются внешними подключениями, а у каждого провайдера моделей свои условия доступа, из России я их не проверял.

Dify или n8n и другие аналоги

Выбор между Dify, n8n и Langflow зависит от задачи: Dify сделан под ИИ-приложения с базой знаний и публикацией, n8n под автоматизацию процессов между сервисами, Langflow под визуальную сборку агентов, а фреймворки вроде LangGraph под агентов, которых пишут кодом.

  • n8n это платформа автоматизации процессов и связок между сервисами, в ней есть ИИ-узлы. Подробно про n8n я писал в обзоре n8n.
  • Flowise был похожим визуальным конструктором агентов, но в 2026 году проект закрыли, репозиторий в архиве, подробности в статье про Flowise.
  • Langflow тоже визуальный конструктор агентов с открытым кодом под лицензией MIT.
  • LangGraph это низкоуровневый фреймворк для оркестрации агентов, логику в нём пишут кодом.

Если вы выбираете, какие задачи бизнеса вообще отдавать агентам, посмотрите разбор ИИ-агентов для бизнеса.

Минусы Dify

Главные минусы Dify это лицензионные ограничения на сервис с отдельными пространствами и смену брендинга, 200 разовых кредитов в бесплатном Sandbox и необходимость администрировать свою установку.

  • Сервис с несколькими отдельными рабочими пространствами и смена логотипа в интерфейсе требуют коммерческой лицензии.
  • Бесплатный Sandbox ограничен: 200 кредитов разово, 5 приложений, 50 документов, журнал за 30 дней.
  • Своя установка требует администрирования: обновления, резервные копии, сертификат.

Частые вопросы

Dify бесплатен в версии Community и в облачном Sandbox, а коротко про цены, установку и язык ниже.

Dify что это? Платформа LangGenius с открытым исходным кодом, где ИИ-приложения, чат-боты, базы знаний и агентов собирают в визуальном редакторе.

Сколько стоит Dify Cloud? Sandbox бесплатно, Professional $59 в месяц, Team $159 в месяц. При оплате за год примерно на 17% дешевле.

Как установить Dify через Docker? Скачать релиз с GitHub, скопировать .env.example в .env, вписать токен песочницы, запустить docker compose up -d и открыть /install в браузере. Docker Compose нужен версии 2.35.0 или новее.

Где найти Dify на GitHub? В репозитории langgenius/dify, там же страница релизов, последний вышел 4 ноября 2026 года.

Как войти в Dify? Облако открывается по адресу cloud.dify.ai. На своём сервере при первом запуске нужно открыть адрес сервера с путём /install.

Можно ли скачать Dify? Основной способ поставить Dify у себя это Docker Compose из репозитория, есть ещё запуск из исходного кода для разработчиков.

Есть ли Dify на русском? Да, русский интерфейс есть, документация на английском, японском и китайском.
