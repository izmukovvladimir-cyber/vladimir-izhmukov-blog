Cline: бесплатный ИИ-агент для кода в VS Code, установка, настройка, Cline CLI и ClinePass в 2026

AI RealshiftВладимир Ижмуков

Cline это открытый ИИ-агент, который сам правит файлы проекта и запускает команды в терминале. Разбираю, как установить Cline в VS Code и JetBrains, как подключить модель, что такое ClinePass за $9,99 и чем Cline отличается от Claude Code и Cursor.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Cline это открытый ИИ-агент для программирования: он сам читает проект, правит сразу несколько файлов, запускает команды в терминале и проверяет ошибки компилятора. Работает как расширение для VS Code, плагин для JetBrains, консольная программа Cline CLI и отдельное приложение для компьютера. Сам Cline бесплатный, код открыт под лицензией Apache-2.0, а платите вы только за модель, которую подключили. Для тех, кто не хочет возиться с ключами, есть подписка ClinePass за $9,99 в месяц с доступом к 14 открытым моделям. Ниже разберу установку, настройку и цены.

В ClinePass входят модели GLM от Z.ai, Kimi от Moonshot, DeepSeek V4, MiniMax M3, MiMo и Qwen 3. Ключ ClinePass можно использовать и в других агентах. Точных цифр квот на странице нет, отменить подписку можно в настройках аккаунта.

Как выбрать модель для Cline

  1. Свой ключ (BYOK): Anthropic, OpenAI, Gemini, DeepSeek, Groq, Cerebras, AWS Bedrock, GCP Vertex, Vercel AI Gateway.
  2. Один ключ ко многим моделям: OpenRouter.
  3. Бесплатно на своём компьютере: локальные модели через Ollama или LM Studio.
  4. Без ключей вообще: ClinePass.

API Anthropic, OpenAI и Gemini официально не обслуживают Россию, поэтому из России на практике чаще выбирают OpenRouter, ClinePass или локальные модели. Доступ и оплату этих вариантов из России я не проверял.

Как установить Cline

В VS Code, Cursor или Windsurf

  1. Откройте панель расширений.
  2. Найдите «Cline» и нажмите Install.
  3. Откройте значок Cline на боковой панели.
  4. Выберите провайдера модели и вставьте ключ либо войдите в ClinePass.

В JetBrains

  1. Откройте Settings, раздел Plugins, вкладку Marketplace.
  2. Найдите «Cline» и установите плагин.
  3. Перезапустите IDE.

Cline CLI

Нужен Node.js версии 20 или новее, рекомендован 22. Установка командой npm install -g cline, затем вход командой cline auth, после этого агент запускается командой cline. В версии CLI 2.0, вышедшей в начале 2026 года, появились параллельные агенты и новый терминальный интерфейс.

Cline Desktop

Отдельное приложение скачивается с cline.bot/desktop для macOS и Windows, версия для Windows в бете. По обзорам приложение умеет импортировать задачи из Claude Code и Codex.

Как настроить Cline под проект

  1. Создайте в корне проекта файл .clinerules и опишите в нём стек, стиль кода и запреты.
  2. Начинайте задачу в режиме Plan: агент покажет, какие файлы тронет и что сделает.
  3. Переключайтесь в Act, когда план вас устраивает.
  4. Автоподтверждение действий включайте только для безопасных операций вроде чтения файлов.
  5. Перед большими правками делайте коммит, чтобы откатиться одной командой.

Как не тратить лишние деньги на токены

  • Давайте агенту конкретную задачу с файлами, где искать.
  • Для простых правок берите дешёвую модель, сильную оставляйте для архитектуры.
  • Длинные сессии начинайте заново: весь контекст переписки оплачивается каждым запросом.

Минусы Cline

  • Расходы на токены сложно предсказать без лимитов у провайдера.
  • Конкретные квоты ClinePass не опубликованы.
  • Десктоп-версия для Windows в бете.
  • Доступ к моделям из России зависит от провайдера, сам я его не проверял.

Частые вопросы

Что такое Cline? Это открытый ИИ-агент для программирования, который правит файлы проекта и запускает команды в терминале.

Cline бесплатный? Да, расширение и CLI бесплатны. Платить нужно только за модель или за подписку ClinePass.

Как скачать Cline? Через магазин расширений VS Code или JetBrains, командой npm install -g cline для CLI или установщиком с cline.bot/desktop.

Что такое ClinePass? Подписка за $9,99 в месяц после промо-периода с доступом к 14 открытым моделям без отдельных ключей.

Как настроить Cline в VS Code? Установите расширение, выберите провайдера модели, вставьте ключ, создайте файл .clinerules с правилами проекта.

Чем Cline отличается от Cursor? Cline работает внутри вашего редактора и подключает любую модель, Cursor это отдельный редактор со своей подпиской.
