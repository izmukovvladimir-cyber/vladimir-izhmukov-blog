Qwen Code устанавливается командой npm install -g @qwen-code/qwen-code@latest (нужен Node.js 22 или новее), запускается командой qwen в папке проекта, а модель подключается внутри сессии командой /auth, затем задачу пишут своими словами. Терминальная программа Qwen Code бесплатна, её исходный код открыт. Для работы к Qwen Code подключают платную подписку, модель провайдера по ключу с платным или бесплатным тарифом либо локальную модель.

Бесплатную квоту Qwen OAuth команда закрыла 15 апреля 2026 года. Ниже три способа установки из README, первый запуск, пять вариантов входа из меню /auth, что осталось бесплатным и сколько стоит Coding Plan. Проверено 21 ноября 2026 года по README репозитория, документации Qwen Code и справке Alibaba Cloud. Последняя версия в npm на эту дату 0.28.3.

Что такое Qwen Code

Qwen Code это открытый ИИ-агент команды Qwen из Alibaba для работы с кодом в терминале. По текстовому заданию он читает файлы проекта, правит их и запускает команды. Код открыт под лицензией Apache-2.0, у репозитория около 30,8 тысячи звёзд на 21 ноября 2026 года. Изначально проект вырос из Gemini CLI версии 0.8.2, с версии 0.1 команда развивает его самостоятельно.

По README агент работает с API OpenAI, Anthropic, Gemini и Qwen, со сторонними провайдерами и с локальными моделями через Ollama или vLLM, модель можно сменить прямо в сессии.

Qwen Code Desktopприложение для macOS, Windows и Linux со страницы релизов на GitHub

Команда Qwen замерила агент на тесте SWE-bench Verified: семь версий Qwen Code проверили с одной моделью Qwen 3.7 Max, средние результаты отдельных версий составили от 76,40% до 77,80% (500 задач, по три прогона на версию). Это их собственный замер, сам я его не повторял.

Как установить Qwen Code

Открыть Telegram-бота →Гайд в Telegram-боте, бесплатно

Установить Qwen Code можно тремя способами из README, установка CLI бесплатная. Если установлены Node.js 22+ и npm, выполните: npm install -g @qwen-code/qwen-code@latest. Два других способа:

  1. Homebrew на macOS и Linux: brew install qwen-code.
  2. Готовый установщик без npm. Для Linux и macOS в README дана однострочная команда, которая скачивает скрипт install-qwen-standalone.sh из хранилища Qwen Code на Alibaba Cloud и запускает его. Для Windows есть такой же скрипт install-qwen-standalone.ps1 для PowerShell. Точные команды копируйте из README репозитория.

После установки перезапустите терминал, чтобы подхватились переменные окружения, так советует сам README. Обновить уже установленный агент можно ещё и изнутри: по журналу обновлений в июле 2026 года в CLI появилась команда /update.

Отдельно существует ветка Qwen Code 1.0 Preview, она собирает возможности агента Qoder и Qwen Code. Инструкция выше относится к основной версии, превью ставится по своей странице в репозитории.

Как пользоваться Qwen Code

Пользоваться Qwen Code начинают с команды qwen в папке проекта: агент видит файлы этой папки и работает с ними. При первом запуске без готовой конфигурации Qwen Code предлагает выбрать способ входа. Порядок по Quick Start из README:

  1. Откройте терминал и перейдите в папку проекта командой cd.
  2. Наберите qwen.
  3. При первом запуске выберите способ входа в меню, позже его открывает команда /auth.
  4. Напишите задачу обычным текстом. README предлагает начать с просьбы объяснить репозиторий и показать, с чего начать.

Дальше пригодятся команды и режимы, которые описаны в README:

  • /model переключает модели, доступные в вашем способе входа;
  • режим планирования Plan Mode сначала только читает проект и составляет план, затем вы выбираете, подтверждать каждую правку или дать агенту править самому;
  • файлы QWEN.md и AGENTS.md в проекте агент подгружает сам, туда удобно записать правила проекта;
  • /resume возвращает прошлый разговор;
  • встроенные навыки вроде /review и /bugfix работают без настройки;
  • qwen -p "задача" запускает агента без интерфейса, для скриптов и CI.

Совет от меня: первую задачу давайте на копии проекта или начните с чистого рабочего дерева git, сохранив свои изменения коммитом. Агент правит файлы, и откатиться к коммиту проще, чем вспоминать, что он поменял. Последствия запущенных команд откат к коммиту не отменяет, поэтому команды я читаю до подтверждения.

Qwen Code бесплатно: что осталось в 2026

Бесплатная дневная квота Qwen OAuth в Qwen Code закрыта 15 апреля 2026 года. Без оплаты за вызовы на 21 ноября 2026 года остаются локальные модели, бесплатные модели внешних провайдеров и пробная квота Alibaba Cloud Model Studio для новых пользователей, а сама программа бесплатна. Подробнее по пунктам:

  • Сам CLI. Код открыт, установка бесплатная.
  • Локальные модели через Ollama или vLLM. В библиотеке Ollama модель qwen3-coder есть в размерах 30b и 480b. При локальном запуске Ollama запрос к модели обрабатывается на вашем компьютере. Скорость зависит от железа, я её не замерял.
  • Бесплатные модели у сторонних провайдеров. У OpenRouter бесплатные варианты моделей помечены суффиксом :free. Набор меняется, поэтому перед подключением я смотрю каталог и проверяю, что выбранная модель поддерживает вызов инструментов: для самостоятельного чтения и правки файлов агенту нужна модель с поддержкой инструментов.
  • Пробная квота Alibaba Cloud Model Studio. По справке Alibaba Cloud при первой активации Model Studio в регионе Сингапур выдаётся бесплатная квота, обычно 1 000 000 токенов на каждую подходящую модель, она действует 90 дней. Подходят только модели с областью обслуживания International. Если продолжать вызовы после исчерпания квоты, оплата идёт по факту, чтобы этого избежать, справка советует заранее включить режим Free Quota Only. Есть ли квота у конкретной модели, проверяйте по списку в справке: для части моделей её нет. Подключается такой ключ в Qwen Code через пункт Alibaba ModelStudio и обычный ключ.

Как закрыли бесплатную квоту. Раньше вход Qwen OAuth давал 1 000 бесплатных запросов в день. 13 апреля 2026 года команда написала в объявлении на GitHub, что квота сразу снижается до 100 запросов в день, а 15 апреля бесплатный вход закрывается. Причина в тексте объявления: корректировка продуктовой стратегии, чтобы управлять бесплатным использованием и затратами. Взамен там же названы OpenRouter, Fireworks AI и Alibaba Cloud ModelStudio.

Сейчас в меню входа есть пункт Qwen Account with Subscription: это вход через Qwen OAuth, который по документации требует активную платную подписку Plus или Pro на chat.qwen.ai. Вход по подписке Qwen в CLI, VS Code и десктопе описан в обзоре обновлений от 12 ноября 2026 года.

Как подключить модель в Qwen Code: API-ключ и подписки

Команда /auth открывает меню подключения модели в Qwen Code: запустите qwen и введите её. API-ключ это секретная строка, которой программа подтверждает право доступа к API провайдера, стоимость вызова зависит от модели, тарифа и оставшейся квоты. В меню /auth по документации пять вариантов, а для запуска без меню подходит готовый файл настроек. Для подписки Qwen Plus или Pro нужен вход через браузер, для провайдера из меню Third-party Providers нужен его API-ключ, а локальный сервер подключается через Custom Provider.

Вариант в /authЧто внутри
Qwen Account with Subscriptionвход через браузер по подписке Plus или Pro с chat.qwen.ai, без ключа
QwenCloudрекомендуемый вариант: Token Plan с месячным запасом кредитов или обычный ключ с оплатой по факту, платформа Китая или международная
Alibaba ModelStudioCoding Plan, Token Plan или обычный ключ ModelStudio
Third-party Providersготовые провайдеры по ключу: DeepSeek, Grok, MiniMax, Z.AI, Kimi, Idealab, ModelScope, OpenRouter, Requesty
Custom Providerсвой сервер, прокси или локальная модель с совместимым API OpenAI, Anthropic или Gemini

Для Coding Plan важна пара «ключ и адрес». По справке Alibaba Cloud ключ Coding Plan начинается с sk-sp- и работает с отдельным адресом Coding Plan, обычный ключ Model Studio начинается с sk- и работает с обычным адресом, и эти пары не взаимозаменяемы. Обычный ключ с обычным адресом расходует квоту и оплату по отдельному биллингу Model Studio, мимо подписки. Чтобы прекратить такие списания, справка советует удалить обычный ключ в консоли и оставить только ключ плана. Перед этим переведите Qwen Code на правильную пару ключа и адреса и убедитесь, что обычный ключ не нужен другим вашим приложениям.

Для серверов и CI без браузера документация советует вход по API-ключу: ключ, адрес и модель задаются переменными окружения или в файле ~/.qwen/settings.json. Ключ для этого нужен от тарифа, который разрешает автоматизацию: Coding Plan такое использование запрещает.

Ограничения Qwen Code

Главные ограничения Qwen Code на 21 ноября 2026 года: вход через аккаунт Qwen требует подписку Plus или Pro, а ключ Coding Plan разрешён только для интерактивной работы. Другие ограничения:

  • бесплатной квоты Qwen OAuth больше нет, вход по аккаунту Qwen требует платную подписку Plus или Pro;
  • места в Coding Plan ограничены, ключ плана нельзя ставить в скрипты и серверы;
  • Web UI, Agent Teams и Agent Arena в README отмечены как экспериментальные;
  • демон qwen serve по README по умолчанию слушает локальный адрес без токена, на общем сервере нужен QWEN_SERVER_TOKEN и флаг --require-auth.

Частые вопросы

Как установить Qwen Code?

Qwen Code можно установить командой npm install -g @qwen-code/qwen-code@latest при Node.js 22 и новее, через Homebrew командой brew install qwen-code или готовым установщиком из README на GitHub. Запуск командой qwen в папке проекта.

Qwen Code бесплатный?

Программа Qwen Code бесплатная и открытая. Бесплатная квота Qwen OAuth закрыта 15 апреля 2026 года. Без оплаты за вызовы остаются локальные модели через Ollama, бесплатные модели сторонних провайдеров и пробная квота Alibaba Cloud Model Studio на 90 дней при первой активации сервиса в регионе Сингапур, если она есть у выбранной модели.

Как пользоваться Qwen Code?

Qwen Code запускают в папке проекта: набрать qwen, выбрать вход в /auth и написать задачу обычным текстом. Модель меняется командой /model, прошлый разговор возвращает /resume.

Где взять API-ключ для Qwen Code?

Ключ для Qwen Code берут в консоли QwenCloud, Alibaba Cloud Model Studio или у стороннего провайдера, например OpenRouter. Для Coding Plan нужен отдельный ключ с префиксом sk-sp-.

Сколько стоит Coding Plan?

Coding Plan Pro стоит $50 в месяц на международном сайте Alibaba Cloud, до 90 000 вызовов модели в месяц, возврата нет.

Какая последняя версия Qwen Code?

На 21 ноября 2026 года в npm последняя версия Qwen Code 0.28.3, опубликована 21 ноября.

Есть ли Qwen Code Desktop?

Да. 6 августа 2026 года команда объявила об официальном запуске Qwen Code Desktop для macOS, Windows и Linux, установщики лежат на странице релизов репозитория на GitHub.
