Qwen Code: ИИ-агент для кода от Alibaba, установка CLI, API-ключ, Coding Plan и что стало с бесплатным доступом в 2026

AI RealshiftВладимир Ижмуков

Qwen Code это открытый ИИ-агент для программирования в терминале от команды Qwen. Разбираю установку Qwen Code CLI, почему закрыли бесплатный вход Qwen OAuth, сколько стоит Coding Plan, как подключить API-ключ и что есть в Qwen Code Desktop.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Qwen Code это открытый ИИ-агент для программирования от команды Qwen из Alibaba: он работает в терминале, читает проект, пишет код и запускает команды. Сам агент бесплатный, код открыт на GitHub, а платить приходится за модель. Бесплатный вход через Qwen OAuth Alibaba закрыла 15 апреля 2026 года, поэтому сейчас нужен свой API-ключ, подписка Coding Plan за $50 в месяц или локальная модель. Ниже разберу установку, способы подключения, тарифы и новую десктоп-версию.

Что такое Qwen Code

Qwen Code выложен на GitHub под лицензией Apache-2.0, у репозитория около 28,7 тысячи звёзд. По идее он близок к Claude Code и Gemini CLI: вы пишете задачу обычным текстом, агент сам ходит по файлам и предлагает правки.

Главное отличие в гибкости. Qwen Code работает с моделями Qwen, а ещё с API OpenAI, Anthropic и Gemini, со сторонними провайдерами и с локальными моделями через Ollama или vLLM.

Что стало с бесплатным Qwen Code

Раньше Qwen Code был популярен из-за щедрой бесплатной квоты: 1 000 запросов в день через вход Qwen OAuth. 13 апреля 2026 года команда объявила на GitHub, что квота сразу снижается до 100 запросов, а 15 апреля вход Qwen OAuth закрывается. Причина в объявлении: корректировка продуктовой стратегии, чтобы управлять бесплатным использованием и затратами.

Сейчас в меню /auth бесплатного входа нет. Сам агент остаётся бесплатным, платными стали модели.

Какие бесплатные пути остались

  • Локальные модели Qwen с открытыми весами через Ollama. Код не уходит с компьютера, но нужна мощная видеокарта.
  • Сторонние провайдеры с бесплатными моделями, например OpenRouter. Набор бесплатных моделей там меняется.

Как установить Qwen Code CLI

Проще всего через npm, нужен Node.js версии 22 и новее: npm install -g @qwen-code/qwen-code@latest. Другие способы:

  1. Homebrew на Mac: brew install qwen-code.
  2. Готовый установщик для Linux, macOS и Windows, команды есть в README репозитория QwenLM/qwen-code на GitHub.

После установки перезапустите терминал, зайдите в папку проекта и наберите qwen. Внутри сессии команда /auth выбирает способ подключения модели.

Как подключить модель: API-ключ и планы

В документации Qwen Code три группы способов входа:

  1. QwenCloud, рекомендуемый вариант: подписка Token Plan или обычный ключ с оплатой по факту.
  2. Alibaba ModelStudio: подписка Coding Plan, Token Plan или обычный ключ.
  3. Сторонние провайдеры: DeepSeek, Grok, Kimi, MiniMax, OpenRouter и другие, плюс свои провайдеры через файл настроек.

Важная тонкость: у ключа Coding Plan префикс sk-sp-, у обычного ключа sk-. Если по ошибке подключить обычный ключ, запросы будут списываться по факту вместо оплаты подпиской.

Агент бесплатный, тарифы относятся к моделям Alibaba Cloud. Данные со справки Alibaba Cloud на 25 октября 2026 года.

Места в Coding Plan ограничены, их раздают по принципу «кто первый». Внутри модели Qwen 3.7 Plus и 3.6 Plus, Kimi K2.5, GLM-5 и MiniMax-M2.5. Возврата нет. План разрешено использовать только для интерактивной работы в поддерживаемых инструментах, скрипты и серверные сервисы на нём запрещены.

Тариф Lite закрыт: новых подписок нет с 20 марта 2026 года, продления прекращены 13 апреля.

Token Plan

Token Plan Personal доступен только в китайском регионе Alibaba Cloud и стоит от ¥39 до ¥499 в месяц, оплата идёт месячными кредитами. С 22 сентября 2026 года недельный лимит в нём отменён. Для пользователя вне Китая основной вариант это Coding Plan на международном сайте или свой ключ.

Qwen Code Desktop и новые функции

За 2026 год агент заметно вырос:

  • в августе вышла десктоп-версия для macOS, Windows и Linux с наглядной схемой плана работы;
  • там же появилось управление сессией с телефона по QR-коду;
  • с сентября подзадачи можно отдавать Claude Code или Codex;
  • в октябре добавились работа в Chrome и совместная работа агентов, когда в диалоге можно позвать Claude Code или Codex.

Qwen Code из России

Регистрацию и оплату Alibaba Cloud из России я не проверял. По справке для международного аккаунта нужен номер телефона за пределами материкового Китая. Способы оплаты зависят от страны. Самый предсказуемый вариант для России это локальная модель через Ollama или провайдер, к которому у вас уже есть доступ.

Минусы Qwen Code

  • Бесплатного входа Qwen OAuth больше нет.
  • Места в Coding Plan ограничены, тариф Lite закрыт.
  • Token Plan доступен только в китайском регионе.
  • На Coding Plan запрещены скрипты и серверное использование.
  • Оплату из России я не проверял.

Частые вопросы

Что такое Qwen Code? Это открытый ИИ-агент для программирования в терминале от команды Qwen из Alibaba, есть также десктоп-версия и расширения для редакторов.

Qwen Code бесплатный? Сам агент бесплатный. Бесплатный вход Qwen OAuth закрыт 15 апреля 2026 года, теперь нужен свой ключ, подписка или локальная модель.

Как установить Qwen Code CLI? Командой npm install -g @qwen-code/qwen-code@latest с Node.js 22 и новее, через Homebrew или готовым установщиком из репозитория на GitHub.

Где взять API-ключ для Qwen Code? В Alibaba Cloud Model Studio или QwenCloud. Для Coding Plan нужен ключ с префиксом sk-sp-.

Сколько стоит Coding Plan? $50 в месяц на международном сайте Alibaba Cloud, ¥200 в месяц на китайском.

Есть ли Qwen Code Desktop? Да, с августа 2026 года есть приложение для macOS, Windows и Linux.
