Warp это терминал со встроенным AI-агентом для macOS, Windows и Linux. Скачать его можно бесплатно на warp.dev или командой менеджера пакетов: brew на Mac, winget на Windows, deb, rpm, pacman или AppImage на Linux. Сам терминал бесплатный и работает даже без регистрации, а агент с включённым использованием моделей стоит от $18 в месяц на тарифе Build.

Warp terminal: что это

Warp делает американская компания Denver Technologies из Нью-Йорка, основатель и CEO Зак Ллойд. Компания называет продукт средой агентной разработки, которая выросла из терминала. В марте 2026 года у Warp был миллион активных пользователей, а в апреле компания открыла исходный код клиента на GitHub под лицензией AGPL-3.0.

Что умеет Warp

  • Блоки команд. Каждая команда и её вывод живут отдельным блоком, их удобно копировать и делиться ими.
  • Нормальный редактор ввода. Курсор, выделение и правка команды как в текстовом редакторе.
  • Warp Agent. Вы пишете задачу обычным языком, агент пишет код, отлаживает и разбирается в проекте.
  • Выбор моделей. Модели крупных лабораторий и открытые модели, на Business можно подключить свои API-ключи.
  • Облачные агенты Oz. Запуск и оркестрация агентов в облаке.
  • Warp Drive. Общие команды, заметки и окружения для команды.
  • Warp Factories. Автоматические циклы разработки с агентами, в том числе с Claude Code и Codex.

Как скачать Warp terminal

Warp для macOS

Подходит для Mac на Intel и Apple Silicon с macOS 10.14 и новее. Скачайте установщик на warp.dev или выполните в терминале команду brew install --cask warp.

Warp для Windows

Нужна Windows 10 версии 1903 и новее или Windows Server 2022, процессор x86_64 или ARM64. Установщик лежит на сайте, а через менеджер пакетов работает команда winget install Warp.Warp.

Warp для Linux

Нужны glibc 2.31 и новее и видеокарта с OpenGL ES 3.0 или Vulkan, поддерживаются x86_64 и ARM64. На сайте есть пакеты .deb для apt, .rpm для dnf и zypper, пакет для pacman в Arch и AppImage. Пакет сам подключает репозиторий, поэтому обновления приходят обычным способом.

Warp terminal на GitHub

Исходники лежат в репозитории warpdotdev/warp, у него больше 65 тысяч звёзд. Собирать из исходников ради бесплатной версии смысла нет: терминал и так бесплатный, проще поставить официальный установщик.

Что дают бесплатно

Терминал бесплатный полностью, регистрацию при первом запуске можно пропустить. Включённых бесплатных кредитов на агента на странице тарифов нет: на Free агент работает либо с вашим собственным инференсом, либо с оплатой по факту.

Работает ли Warp в России

Прямой проверки с российского IP у меня не было, наш сервер находится за пределами России. В условиях использования Warp ссылается на экспортный контроль США, но отдельного запрета для России там нет, сообщений о блокировке терминала я тоже не нашёл. Модели работают через американские серверы, и пользователи из Европы жалуются на задержки.

Оплата идёт через Stripe, и по обзорам российские карты Visa, Mastercard и «Мир» не проходят. Бесплатный терминал оплаты не требует.

Warp на русском

Интерфейс только на английском. Запрос на локализацию открыт с 2022 года, а в октябре 2026-го команда начала первый перевод, на испанский. С русской раскладкой есть открытые ошибки: терминал может подвисать при переключении языка, а сочетания клавиш с Ctrl иногда не срабатывают на нелатинской раскладке. Писать агенту задачи по-русски можно, отвечают модели.

Минусы Warp

  • Включённого использования на Build хватает на $20 по ценам API, дальше докупка. Поставьте лимит трат сразу.
  • Нет русского интерфейса и есть ошибки с русской раскладкой.
  • Оплатить российской картой напрямую не получится.
  • Модели работают через серверы в США, ответы из Европы и России бывают медленнее.

Не путайте с Cloudflare WARP

Запрос «warp скачать» часто ведёт на VPN Cloudflare WARP. Это другой продукт другой компании, и Роскомнадзор вносил его в список блокируемых VPN. Терминал Warp к нему отношения не имеет.

Частые вопросы

Где скачать Warp terminal?

На warp.dev, либо командой brew install --cask warp на macOS, winget install Warp.Warp на Windows и пакетами deb, rpm, pacman или AppImage на Linux.

Есть ли Warp для Linux?

Да, для x86_64 и ARM64, нужен glibc 2.31 и новее.

Есть ли Warp для Windows?

Да, для Windows 10 версии 1903 и новее, в том числе на ARM64.

Warp terminal бесплатный?

Терминал бесплатный. Агент с включённым использованием моделей стоит от $18 в месяц на тарифе Build.

Warp есть на GitHub?

Да, клиент открыт под лицензией AGPL-3.0 в репозитории warpdotdev/warp с апреля 2026 года.

Warp terminal и Warp VPN это одно и то же?

Нет. VPN называется Cloudflare WARP и делается другой компанией.
