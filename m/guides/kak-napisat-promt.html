Как написать промпт: структура запроса, из-за которой нейросеть отвечает по делу

AI RealshiftВладимир Ижмуков

Как написать промпт для нейросети: пять частей рабочего запроса, приёмы для текста и картинок, частые ошибки и готовые шаблоны, которые можно забрать и применить сразу.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Люди жалуются, что нейросеть отвечает общими словами. Открываешь такой диалог и видишь запрос из пяти слов: «напиши пост про здоровое питание». Модель получила тему и не получила ничего больше, поэтому вернула усреднённый текст, который подошёл бы кому угодно.

Хороший запрос отличается от плохого длиной и порядком. Ниже структура, которая работает в любой модели, и шаблоны, которые можно забрать себе прямо сейчас.

Пять частей рабочего запроса

  1. Роль. Кем модель должна быть: маркетологом с опытом запусков, редактором делового издания, методистом курса.
  2. Задача. Что именно сделать, одним предложением и глаголом: написать, разобрать, переписать, сравнить.
  3. Контекст. Для кого, зачем, что уже известно, какие есть ограничения.
  4. Формат. Объём, структура, чем закончить: список из семи пунктов, таблица с тремя колонками, текст на две тысячи знаков.
  5. Запреты. Чего делать нельзя: без вводных оборотов, без восклицаний, без обещаний результата.

Пятая часть даёт самый заметный скачок качества, и её почти никто не пишет.

Как это выглядит на практике

Слабый запрос: «Напиши пост про мой курс».

Рабочий запрос: «Ты редактор, который пишет для предпринимателей простым языком. Напиши пост о курсе по съёмке коротких роликов для владельцев маленьких студий. Люди на курс приходят из ленты, продукт стоит недорого, главная боль в том, что съёмка занимает целый вечер. Объём до двух тысяч знаков, первая строка бьёт в боль, дальше три конкретных приёма, в конце одно действие. Без восклицательных знаков, без обещаний дохода, без слова уникальный».

Второй запрос длиннее раз в двадцать и экономит час правок.

Промпт для картинки устроен иначе

В запросе на изображение порядок слов важнее вежливости. Работает такая последовательность.

  1. Тип кадра. Фотография, иллюстрация, документальный снимок, студийный портрет.
  2. Что в кадре. Главный объект и обстановка вокруг него.
  3. Свет. Дневной из окна, вечерний тёплый, жёсткий студийный.
  4. Детали. Материалы, цвета, мелкие предметы, которые создают жизнь.
  5. Технические слова. Объектив, глубина резкости, реализм.
  6. Запреты. Без текста на картинке, без лишних рук, без пластиковой кожи.

Разбор готовых формулировок под разные задачи собран в статье про промпты для нейросетей.

Пять ошибок, которые портят ответ

  • Несколько задач в одном запросе. Модель выполнит первую и смажет остальные, поэтому задачи разносятся по сообщениям.
  • Вежливость вместо конкретики. «Пожалуйста, сделай хорошо» не несёт информации, эти слова можно убрать целиком.
  • Отсутствие адресата. Текст для подростка и текст для собственника бизнеса пишутся по-разному, и модель должна знать, кто читатель.
  • Молчание о формате. Без указания объёма и структуры ответ придёт в форме, которую модель выберет сама.
  • Работа с первого ответа. Первый вариант это черновик, дальше идут две-три правки уточняющими просьбами.

Три шаблона, которые можно забрать

Для текста: «Ты [роль]. Напиши [что] для [кого]. Известно: [контекст]. Формат: [объём и структура]. Нельзя: [запреты]».

Для разбора: «Вот мой [материал]. Найди пять слабых мест, для каждого скажи, почему это слабо и как переписать. Отвечай списком, без вступления».

Для переписывания: «Перепиши текст ниже, сохранив смысл и факты. Сделай предложения длиннее и живее, убери канцелярит и вводные обороты. Верни только готовый текст».

Частые вопросы

Влияет ли длина запроса на качество ответа? До определённого предела да, потому что модель получает больше опоры. После примерно двух тысяч знаков начинает работать обратный эффект, и важное теряется среди подробностей.

Нужно ли писать промпт на английском? Для текста на русском пишите по-русски, модель работает с языком напрямую. Для картинок английский пока даёт заметно более точный результат.

Почему один и тот же запрос даёт разные ответы? В моделях заложена случайность. Чтобы ответы стали стабильнее, задавайте жёсткий формат и приводите образец.

Можно ли сохранить удачный промпт? Нужно. Заведите файл со своими рабочими запросами и складывайте туда всё, что сработало, с пометкой, для какой задачи.

Что делать, если модель отвечает общими словами? Добавить контекст и запреты. Вода почти всегда появляется там, где модель не знает адресата и не имеет ограничений.

С чего начать дальше

Возьмите свой последний запрос к нейросети, который дал слабый ответ, и перепишите его по пяти частям из начала статьи. Разница будет видна сразу, и этот переписанный запрос станет вашим первым шаблоном.

Когда захотите применять это к своему блогу и получать с роликов заявки, забирайте разбор системы, по которой контент собирается ежедневно: как устроен ежедневный поток роликов.
