Seedream: нейросеть ByteDance для генерации картинок, как пользоваться в 2026

Seedream по шагам: версии 5.0 Pro и 5.0 Lite, где попробовать бесплатно в Dreamina, до 14 референсов, разрешение до 4K через API, текст на картинке и цены.

Владимир Ижмуков · автор системы роста Instagram через короткие ролики

Seedream это линейка моделей ByteDance для генерации и редактирования картинок. Последние версии Seedream 5.0 Pro и 5.0 Lite. Бесплатно попробовать модель можно в Dreamina от CapCut, там дают ежедневные кредиты. Через API Seedream принимает до 14 картинок-референсов и делает изображения в 1K, 2K, а через официальный API ByteDance до 4K.

Для блога Seedream полезен вёрсткой: модель хорошо понимает длинные запросы, композицию и надписи, поэтому подходит для обложек и слайдов каруселей.

Где пользоваться Seedream

  • Dreamina (dreamina.capcut.com): самый простой вход, ежедневные бесплатные кредиты, рядом видео Seedance, Sora 2 и Veo 3.1.
  • BytePlus ModelArk: официальный API, старт бесплатно.
  • OpenRouter: API с выбором разрешения 1K или 2K.
  • Pika: Seedream 5 и 4 доступны внутри Pika.

Как сделать картинку в Seedream по шагам

  1. Откройте dreamina.capcut.com и войдите в аккаунт.
  2. Выберите генерацию изображений и модель Seedream 5.0 Pro.
  3. Напишите запрос: объект, место, свет, ракурс, стиль, формат.
  4. Для обложки рилса сразу задайте вертикаль 9:16, для карусели 4:5.
  5. Загрузите референсы, если нужен ваш стиль, лицо или товар.
  6. Сгенерируйте несколько вариантов и скачайте лучший.

Как писать запрос для Seedream

  • Пишите полными предложениями, модель хорошо держит длинные описания.
  • Указывайте расположение элементов: «заголовок сверху, предмет в нижней трети».
  • Текст для картинки берите в кавычки и держите коротким, латиница выходит надёжнее.
  • Для серии слайдов используйте одни и те же референсы, так стиль не плывёт.

Seedream из России

Поддержку русского языка и оплату из России ByteDance официально не описывает. Запросы на английском дают более предсказуемый результат. Для платного плана нужна зарубежная карта.

Seedream и другие нейросети

Сам сервис Dreamina подробно разобран в статье Dreamina, видео той же компании в материале Seedance. Для сравнения генераторов картинок посмотрите Nano Banana, Midjourney и нейросеть для генерации изображений.

Частые вопросы

Какая последняя версия Seedream? Seedream 5.0 Pro и 5.0 Lite.

Где попробовать Seedream бесплатно? В Dreamina от CapCut, там ежедневные бесплатные кредиты.

Есть ли у Seedream API? Да, через BytePlus ModelArk и OpenRouter.

Сколько референсов можно загрузить? До 14 картинок через API OpenRouter.

В каком разрешении Seedream делает картинки? 1K и 2K через OpenRouter, до 4K через официальный API ByteDance.

Официальные страницы и источники: Dreamina, Seedream в BytePlus, Seedream 5.0 Pro в OpenRouter, ByteDance Seed.
