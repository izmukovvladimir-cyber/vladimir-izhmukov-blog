Upscayl: бесплатная программа для увеличения качества фото нейросетью, как пользоваться

Upscayl по шагам: как скачать, выбрать модель и увеличить разрешение картинки на своём компьютере, требования к видеокарте, Upscayl Cloud и его цены.

Владимир Ижмуков · автор системы роста Instagram через короткие ролики

Upscayl это бесплатная программа с открытым кодом, которая увеличивает разрешение картинок нейросетью Real-ESRGAN прямо на вашем компьютере. Она работает на Windows, macOS и Linux, и в настройках есть русский язык. Лимитов на число картинок нет, ограничение одно: нужна видеокарта с поддержкой Vulkan. Для тех, у кого слабый компьютер, есть платная облачная версия Upscayl Cloud.

Для блогера Upscayl закрывает частую боль: кадр из видео или старое фото для обложки выглядит мыльно, а в ленте каждая лишняя размытость снижает клики.

Что умеет Upscayl

ФункцияЧто делает
Batch Upscaylобрабатывает целую папку картинок
Double Upscaylпрогоняет картинку два раза для большего увеличения
Upscayl Standard, High Fidelityмодели для фотографий
Digital Artмодель для рисунков и иллюстраций
Custom modelsможно подключить свои модели
Custom output widthзадаёт точную ширину результата
Slider View, Lens Viewсравнение до и после

Модели Remacri, Ultramix и Ultrasharp помечены как некоммерческие. Для рекламы и продающих картинок их брать нельзя, используйте Standard или High Fidelity.

Как пользоваться Upscayl по шагам

  1. Скачайте установщик с upscayl.org или со страницы релизов на GitHub. На Windows при предупреждении SmartScreen нажмите More Info, затем Run Anyway.
  2. Откройте программу. Если нужен русский, переключите язык в Settings.
  3. Шаг 1: нажмите Select Image. Для папки включите Batch Upscayl и выберите Select Folder.
  4. Шаг 2: выберите модель. Для фото подходят Upscayl Standard или High Fidelity, для иллюстраций Digital Art.
  5. Шаг 3: нажмите Set Output Folder и выберите, куда сохранить результат.
  6. Шаг 4: выберите масштаб и нажмите Upscayl.
  7. Сравните результат в Slider View и заберите файл из выбранной папки.

Где это пригодится в рилсах

  • Стоп-кадр из видео для обложки: увеличьте его до 1080 по ширине, и лицо перестанет быть мыльным.
  • Старое фото для карусели: модель High Fidelity бережнее работает с кожей и деталями.
  • Иллюстрация из генератора в маленьком разрешении: Digital Art сохраняет чёткие линии.

Чего Upscayl не умеет

  • Убирать размытие и исправлять фокус: в официальном FAQ так и написано, что программа этого не делает.
  • Работать с видео: только картинки.
  • Запускаться без нормальной видеокарты: на большинстве встроенных видеочипов и на одном процессоре программа не работает.

Последняя версия программы вышла в декабре 2024 года, сам проект на GitHub живой и обновлялся в октябре 2026, у него около 50 тысяч звёзд.

Частые вопросы

Upscayl бесплатный? Да, программа для компьютера полностью бесплатна и без лимитов. Платная только облачная версия.

Есть ли Upscayl на русском? Да, русский язык включается в настройках программы.

Почему Upscayl не запускается? Чаще всего не хватает видеокарты с поддержкой Vulkan. На встроенной графике и на процессоре программа обычно не работает.

Увеличивает ли Upscayl видео? Нет, только картинки.

Можно ли использовать результат в рекламе? Можно с моделями Standard, Lite, High Fidelity и Digital Art. Remacri, Ultramix и Ultrasharp помечены как некоммерческие.

Что делать дальше

Найдите обложку своего рилса, которая выглядит мыльной, прогоните её через Upscayl и поставьте рядом с оригиналом. Чёткая обложка делает сетку профиля дороже на вид без единого вложения.
