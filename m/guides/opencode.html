OpenCode: бесплатный ИИ-агент для кода в терминале, как установить OpenCode CLI, что такое Zen и Go в 2026

AI RealshiftВладимир Ижмуков

OpenCode это открытый ИИ-агент для программирования в терминале, на десктопе и в телефоне. Как установить OpenCode CLI, как пользоваться, как добавить MCP и skills, как удалить, бесплатные модели и их условия по данным, цены Zen и подписки Go. Проверено 20 ноября 2026.

OpenCode это открытый ИИ-агент для программирования: он работает с вашим проектом, пишет и правит код, выполняет команды и подключается к моделям разных провайдеров. На macOS и Linux его ставят командой curl -fsSL https://opencode.ai/v2/install | bash и запускают командой opencode в папке проекта. Сам OpenCode бесплатен, в его каталоге есть модели, доступные без оплаты на ограниченное время, платные модели можно оплачивать по расходу с баланса в OpenCode Console (старая ссылка OpenCode Zen ведёт в этот раздел) или подпиской OpenCode Go от $10 в месяц в пределах её лимита, а можно подключить ключ своего провайдера и платить ему по его условиям.

Что такое OpenCode

OpenCode это агент для кода с открытым исходником под лицензией MIT, его делает команда Anomaly. Вы пишете задачу словами, а агент работает с файлами проекта, правит код и выполняет команды. OpenCode при этом подключается к моделям разных компаний: сайт заявляет больше 200 провайдеров моделей через Models.dev, включая локальные модели, а также вход по подписке ChatGPT Plus или Pro и GitHub Copilot.

Встроенные агенты

По документации OpenCode, внутри есть два основных агента и два подагента:

  • Build это агент по умолчанию для работы с кодом, чтение чувствительных файлов окружения он согласует с вами;
  • Plan исследует и планирует без правок обычных файлов проекта, команды оболочки остаются под контролем разрешений;
  • General это подагент для поиска и многошаговой работы с широким доступом к инструментам;
  • Explore это подагент, который ищет и читает код и веб-источники, не меняя файлы.

Как установить OpenCode CLI

Забрать материалы в боте →Гайд в Telegram-боте, бесплатно

OpenCode CLI (интерфейс командной строки) для macOS и Linux можно установить официальным скриптом: откройте терминал и выполните curl -fsSL https://opencode.ai/v2/install | bash. Другие способы с сайта OpenCode:

  1. Через npm: npm install -g @opencode/cli.
  2. Через bun: bun install -g --trust @opencode/cli.
  3. Через Homebrew: brew install anomalyco/tap/opencode-v2.
  4. На Arch Linux через paru: paru -S opencode-beta.
  5. Десктоп: установщики для macOS, Windows и Linux лежат на странице загрузки opencode.ai.

После установки зайдите в папку проекта и наберите opencode. Откроется интерфейс агента, где задача пишется обычным текстом. По журналу изменений, 18 ноября 2026 года вышла версия 2.3.2.

OpenCode Zen и OpenCode Go: в чём разница

OpenCode Console предлагает два способа оплаты моделей: оплату по расходу с баланса (в поиске её знают как OpenCode Zen, в /connect это провайдер OpenCode с оплатой по расходу) и подписку OpenCode Go, месячную подписку на каталог моделей для программирования, в том числе открытых. Можно также подключить своего провайдера или войти по уже оплаченной подписке. Сравнение по документации OpenCode:

Как устроены лимиты Go

Все платные модели в Go тратят один общий месячный лимит. Лимит на 5 часов это 20% месячного, окно начинается с первого использования. Недельный лимит это 50% месячного, он сбрасывается в понедельник в 00:00 UTC. Месячный лимит обновляется с новым оплаченным периодом.

Если лимит кончился, можно перейти на бесплатную модель или включить Extra Usage: тогда дальше расходуются кредиты Console, у Go Teams эта опция включена изначально. Сколько запросов за 5 часов примерно даёт модель, показывает страница Go в консоли OpenCode. По документации, настройки Go по умолчанию разрешают обработку запросов в Европе и США.

Как подключить модель

В терминальном интерфейсе OpenCode команда /connect подключает провайдера, а /models выбирает модель.

  1. Запустите opencode и введите команду /connect.
  2. Выберите провайдера: OpenCode с оплатой по расходу, OpenCode Go или другого.
  3. Если провайдер работает по ключу, вставьте ключ из его консоли.
  4. Командой /models выберите модель для работы.

Подписку ChatGPT Plus, Pro или GitHub Copilot, по данным сайта OpenCode, можно подключить входом вместо отдельного ключа.

Как пользоваться OpenCode: основные команды

Команда opencode открывает интерфейс агента в текущем проекте, а opencode run "…" выполняет разовую задачу без интерфейса. Основные команды по документации OpenCode:

КомандаЧто делает
opencodeОткрывает полноэкранный интерфейс агента в текущей папке
opencode ~/code/my-projectОткрывает агента в другой папке проекта
opencode run "Explain this repository"Выполняет задачу без интерфейса, для скриптов и CI
opencode miniЗапускает упрощённый интерактивный интерфейс
opencode debug pathsПоказывает, где лежат база, конфиг, кэш и логи
opencode uninstall --dry-runПоказывает, что удалится, без удаления

Все локальные клиенты OpenCode по умолчанию подключаются к одному общему фоновому сервису вашей учётной записи. Если нужен отдельный сервер, есть флаг --standalone.

Как добавить MCP в OpenCode

MCP (Model Context Protocol) это протокол, через который MCP-сервер даёт агенту дополнительные инструменты и ресурсы. Удалённый MCP-сервер в OpenCode добавляется одной командой из папки проекта:

  1. Выполните opencode mcp add context7 --url https://mcp.context7.com/mcp, где context7 это имя сервера, а дальше его адрес.
  2. Проверьте подключение командой opencode mcp list: у подключённого сервера стоит отметка connected.
  3. Чтобы сервер работал во всех проектах, добавьте флаг --global.

Вручную сервер прописывается в файле opencode.jsonc в разделе mcp.servers: у локального сервера "type": "local" и обязательное поле "command" с командой запуска, у удалённого "type": "remote" и полный адрес в "url". Во второй версии имена серверов кладутся внутрь servers, прямо в mcp их класть нельзя. Удалённые серверы по умолчанию используют вход через OAuth. Документация предупреждает, что инструменты MCP расходуют контекст модели, поэтому подключайте только нужные серверы.

OpenCode skills

Skills в OpenCode это файлы с инструкциями: агент видит их описание из поля description, а полный текст получает, когда вызывает инструмент skill. По документации, skill кладут файлом SKILL.md в папку с его именем, а OpenCode версии 2 принимает и отдельный файл <имя>.md в папке skills. OpenCode сам ищет skills в папках ~/.config/opencode/skills и .opencode/skills, а для совместимости ещё в ~/.claude/skills и .claude/skills. Значит, skills из этих папок Claude Code OpenCode тоже найдёт, если их формат совместим.

OpenCode из России

Доступность сайта, консоли и оплаты Zen и Go российскими картами я не проверял. По документации Go настройки по умолчанию разрешают обработку запросов в Европе и США, а Beam Free и Inkling 2 Small Free прямо недоступны в России. Сам агент открытый и подключается к провайдеру по вашему выбору.

Как удалить OpenCode

OpenCode удаляется командой opencode uninstall: при установке через менеджер пакетов она удаляет его этим же менеджером, а при установке скриптом через curl сам исполняемый файл не удаляет и печатает команду, чтобы удалить его вручную.

  1. Посмотрите, что удалится: opencode uninstall --dry-run.
  2. Удалите: opencode uninstall, команда попросит подтверждение. Флаг --force пропускает подтверждение.
  3. Если ставили через curl, выполните команду удаления файла, которую покажет opencode uninstall.

По документации CLI, сессии, настройки и состояние при удалении сохраняются.

Минусы OpenCode

  • Бесплатные модели в каталоге OpenCode даются на время, и часть из них хранит ваши данные: например, Iceman Free хранит запросы и использует их для улучшения модели.
  • Лимиты Go общие на все платные модели, а окно на 5 часов это только 20% месячного запаса.
  • Оплату из России я не проверял.

Частые вопросы

Что такое OpenCode? OpenCode это открытый ИИ-агент для программирования, который работает в терминале, на десктопе и в телефоне с моделями многих провайдеров.

OpenCode бесплатный? Сам агент бесплатный, в каталоге есть бесплатные на время модели. Платные модели оплачиваются по расходу с баланса OpenCode Console, подпиской Go от $10 в месяц в пределах лимита или напрямую провайдеру, если подключить свой ключ.

Как установить OpenCode CLI? Одной командой из официального скрипта на opencode.ai или через npm пакетом @opencode/cli, затем команда opencode в папке проекта.

Что такое OpenCode Zen? Это способ платить за модели по факту расхода: пополняете баланс с комиссией 4,6% + $0,31 и тратите его на токены.

Сколько стоит OpenCode Go? $10 в месяц, Go Plus $40, Go Teams $20 за участника при минимуме из двух. Лимит общий на все платные модели.

Работает ли OpenCode с MCP? Да, поддерживаются локальные и удалённые MCP-серверы, для удалённых по умолчанию вход через OAuth.

Как добавить MCP в OpenCode? Командой opencode mcp add <имя> --url <адрес> из папки проекта, с флагом --global для всех проектов. Проверка: opencode mcp list.

Как удалить OpenCode? Командой opencode uninstall, а opencode uninstall --dry-run сначала покажет, что удалится. При установке через curl исполняемый файл удаляется отдельной командой, которую напечатает uninstall. Настройки и сессии сохраняются.

Что делать дальше

Первое действие после установки: запустите opencode в папке своего проекта, переключитесь на агента Plan и попросите объяснить структуру репозитория без изменений. По умолчанию открывается Build, который может править файлы.
