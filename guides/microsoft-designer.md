# Microsoft Designer: бесплатный генератор картинок и редактор, лимиты и Microsoft 365 в 2026

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Microsoft Designer это графический редактор с нейросетью: он рисует картинки по описанию, удаляет и размывает фон, стирает лишние объекты, увеличивает фото до 4K и собирает посты, баннеры, открытки и коллажи до 10 фото. Работает в браузере на designer.microsoft.com и в приложениях для iPhone и Android. По официальной справке Designer бесплатен, а подписка Microsoft 365 нужна тем, кто генерирует часто: она даёт больше ИИ-кредитов. Важное ограничение: лицензия Designer только для личного некоммерческого использования.

Ниже разбираю, что умеет Designer, как устроены кредиты и для чего его можно использовать автору соцсетей.

## Что умеет Microsoft Designer

| Функция | Что делает |
|---|---|
| Генерация картинок | изображение по текстовому описанию |
| Улучшение промпта | дописывает ваш запрос подробнее |
| Удаление и размытие фона | вырезает объект или размывает задний план |
| Генеративное стирание | убирает лишний предмет с фото |
| Увеличение до 4K | повышает разрешение картинки |
| Шаблоны | посты, баннеры, открытки, приглашения, коллажи до 10 фото |
| Фирменный стиль | один набор цветов, шрифтов и логотипа |

У картинок, созданных нейросетью, в файл записываются метаданные о происхождении по стандарту Content Credentials.

## Бесплатно ли Designer и как работают кредиты

Официальная справка Microsoft: Designer бесплатный, подписка может понадобиться тем, кто создаёт картинки часто. Генерация в Designer, Paint, Фотографиях и Copilot списывает общие ИИ-кредиты, которые выдаются на месяц.

| Подписка | Цена в США | ИИ-кредиты |
|---|---|---|
| Без подписки | 0 | базовый объём |
| Microsoft 365 Personal | 9,99 $ в месяц или 99,99 $ в год | стандартный объём |
| Microsoft 365 Family | 12,99 $ в месяц или 129,99 $ в год | стандартный объём, только у владельца |
| Microsoft 365 Premium | 19,99 $ в месяц или 199,99 $ в год | расширенный объём |

Точное число кредитов Microsoft в текущей справке не называет. Цифры из обзоров прошлых лет устарели, поэтому ориентируйтесь на счётчик внутри своего аккаунта.

## Можно ли использовать картинки в рекламе

По условиям Designer картинки предназначены для личного некоммерческого использования. Для рекламы, обложек платных продуктов и карточек товаров берите генераторы с коммерческой лицензией. Варианты собрал в статье [нейросеть для генерации изображений](/guides/neyroset-dlya-generacii-izobrazheniy/).

## Как сделать обложку для поста в Designer

1. Откройте designer.microsoft.com и войдите в личный аккаунт Microsoft.
2. Выберите формат: пост, история или баннер.
3. Опишите картинку: сцена, свет, стиль и место под заголовок.
4. Добавьте заголовок шаблоном редактора, русский текст на самой картинке нейросеть часто пишет с ошибками, справка Microsoft об этом предупреждает.
5. Скачайте готовую картинку.

Про сами обложки для роликов подробнее в статье [нейросеть для обложек](/guides/neyroset-dlya-oblozhek/).

## Designer, Copilot и Bing Image Creator

- **Copilot** это чат Microsoft, он тоже рисует картинки и тратит те же кредиты. В Teams инструменты Designer с февраля 2026 года перенесли в Copilot Chat.
- **Bing Image Creator** это отдельный бесплатный генератор Microsoft со своими лимитами, разбор в статье [про Bing Image Creator](/guides/bing-image-creator/).
- **Designer** удобнее для готового макета: картинка сразу с текстом и шаблоном.

Подробнее про сам Copilot в статье [про Copilot](/guides/copilot/).

## Работает ли Designer в России

Microsoft пишет, что Copilot доступен в 170 с лишним странах, кроме Китая и стран под эмбарго, Россия в списке прямо не названа. Сторонние сайты сообщают об ограничениях Designer в России. Оплатить Microsoft 365 российской картой нельзя. Проверьте доступ сами, открыв сайт.

## Частые вопросы

**Microsoft Designer бесплатный?** Да, по официальной справке. Подписка Microsoft 365 даёт больше ИИ-кредитов.

**Сколько картинок можно сделать бесплатно?** Microsoft не публикует точное число в 2026 году, остаток видно в аккаунте.

**Можно ли использовать картинки из Designer в рекламе?** Лицензия Designer только для личного некоммерческого использования.

**Пишет ли Designer текст по-русски?** Шаблоны редактора поддерживают текст, а нейросеть на самой картинке может ошибиться в буквах.

**Чем Designer отличается от Copilot?** Designer это редактор с шаблонами, Copilot это чат. Кредиты у них общие.

**Работает ли Designer в России?** Официального заявления нет, доступ проверьте сами. Подписку российской картой не оплатить.
