# Ollama: как установить и запустить нейросеть на своём компьютере, модели и команды 2026

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Ollama это бесплатная программа, которая запускает открытые нейросети прямо на вашем компьютере: Llama, Qwen, Gemma, DeepSeek, gpt-oss и десятки других. Интернет нужен только чтобы скачать модель, дальше она работает локально, и ваши тексты никуда не уходят. Ollama ставится на Windows, macOS и Linux, у неё есть приложение с чатом для Windows и Mac, а лицензия MIT разрешает пользоваться ей бесплатно. Для облачных моделей есть тариф Pro за 20 долларов в месяц.

Ниже показываю установку по шагам, как выбрать модель под ваш компьютер и какие команды понадобятся в первый день.

## Что нужно от компьютера

| Система | Требования |
|---|---|
| Windows | Windows 10 22H2 или новее, от 4 ГБ места под программу, для видеокарты NVIDIA драйвер от 551.61 |
| macOS | Sonoma 14 или новее, на Apple M работают процессор и видеочип, на Intel только процессор |
| Linux | для NVIDIA нужна CUDA, для AMD нужен ROCm v7 |

Главное ограничение это память. Модель должна поместиться в видеопамять или в единую память Mac, иначе Ollama возьмёт обычную оперативку и будет отвечать заметно медленнее. Например, для небольшой gemma4:e2b нужно около 7,2 ГБ на диске и рекомендуется 8 ГБ видеопамяти. Официальной таблицы «память под размер модели» у Ollama нет, поэтому ориентируйтесь на размер файла модели в библиотеке: памяти нужно чуть больше, чем весит модель.

## Как установить Ollama

### Windows

1. Скачайте OllamaSetup.exe на ollama.com/download.
2. Запустите установщик, права администратора не нужны.
3. После установки откроется приложение с окном чата. Если хотите хранить модели на другом диске, задайте путь переменной OLLAMA_MODELS.

### macOS

1. Скачайте Ollama.dmg на ollama.com/download.
2. Перетащите Ollama в папку «Программы» и откройте.
3. В строке меню появится значок, а приложение с чатом откроется отдельным окном.

### Linux

1. Установите одной командой из официальной инструкции на ollama.com/download.
2. Ollama запустится как системный сервис.
3. Работа идёт в терминале, приложения с окном на Linux нет.

## Какую модель выбрать

Самые скачиваемые модели в библиотеке Ollama на октябрь 2026 года:

| Модель | Скачиваний | Для чего |
|---|---|---|
| llama3.1 | 120,4 млн | универсальная модель для текстов и чата |
| deepseek-r1 | 93,8 млн | рассуждения, задачи с логикой |
| llama3.2 | 85,6 млн | лёгкие версии для слабых компьютеров |
| qwen2.5 | 42,7 млн | хорошо понимает русский, код |
| gemma3 | 41,2 млн | тексты, картинки на входе |
| qwen3 | 40,4 млн | новое поколение Qwen |
| mistral | 33,9 млн | быстрая модель общего назначения |

Из свежих популярны gemma4 (от E2B до 31B), qwen3.5 (от 0,8B до 122B), gpt-oss в версиях 20B и 120B и qwen3-coder для программирования.

### Как выбирать на практике

1. Ноутбук с 8 ГБ памяти: модели до 3-4 миллиардов параметров, например llama3.2 или gemma4:e2b.
2. Компьютер с видеокартой на 12-16 ГБ: модели 7-14 миллиардов параметров, qwen3 или gemma3.
3. Mac с 32 ГБ и больше или мощная видеокарта: модели 30 миллиардов параметров и выше.
4. Для русских текстов начните с Qwen или Gemma, они заметно лучше пишут по-русски, чем ранние Llama.

## Основные команды

- ollama run qwen3 скачивает модель, если её нет, и открывает чат.
- ollama pull gemma3 только скачивает модель.
- ollama ls показывает скачанные модели.
- ollama ps показывает, какие модели сейчас загружены в память.
- ollama stop qwen3 выгружает модель из памяти.
- ollama rm mistral удаляет модель с диска.
- ollama create создаёт свою модель из файла настроек Modelfile, например с вашим системным промптом.
- ollama serve запускает сервер вручную.

У Ollama есть локальный API по адресу localhost:11434. Через него к модели подключаются другие программы: редакторы кода, чат-интерфейсы, автоматизации вроде [n8n](/guides/n8n/).

## Облако Ollama и тарифы

Модели, которые не помещаются в ваш компьютер, можно запускать в облаке Ollama. Для этого к названию модели добавляется метка cloud, например gemma4:cloud. Промпты на обучение не используются.

| Тариф | Цена | Что входит |
|---|---|---|
| Free | 0 | локально без ограничений, облако с оплатой по факту, 1 запрос одновременно |
| Pro | 20 $ в месяц или 200 $ в год | 60 $ облачных кредитов в месяц, 3 запроса одновременно |
| Max | 100 $ в месяц | 300 $ кредитов, 10 запросов одновременно |
| Team | 500 $ в месяц | 1 000 $ кредитов |

Неиспользованные кредиты на следующий месяц не переносятся.

## Ollama и агенты

С 2026 года Ollama умеет запускать кодинг-агентов на своих моделях командами ollama launch claude, ollama launch codex и ollama launch opencode. Это удобный способ попробовать агента без подписки, но локальные модели слабее облачных лидеров. Чем агент отличается от чат-бота, разобрал в статье [что такое ИИ-агент](/guides/ii-agent-chto-eto/).

## Кому Ollama подходит

- Тем, кто работает с приватными данными: договоры, переписка, внутренние документы.
- Тем, кто хочет нейросеть без подписки и без лимитов.
- Разработчикам, которым нужна модель по API у себя на машине.

Если компьютер слабый и нужен быстрый сильный ответ, проще взять облачного ассистента, например [Claude](/guides/claude-neyroset/) или [ChatGPT](/guides/chat-gpt-na-russkom/).

## Частые вопросы

**Ollama бесплатная?** Да, программа бесплатная, лицензия MIT. Платно только облако: тариф Pro от 20 долларов в месяц.

**Есть ли у Ollama интерфейс?** Да, на Windows и macOS есть приложение с чатом, туда можно перетащить PDF и картинки. На Linux работа идёт в терминале.

**Сколько нужно оперативной памяти?** Чуть больше, чем весит файл модели. Для маленьких моделей хватает 8 ГБ, для моделей 7-14 миллиардов параметров лучше 16 ГБ видеопамяти.

**Какую модель выбрать для русского языка?** Qwen и Gemma пишут по-русски лучше остальных популярных моделей.

**Работает ли Ollama без интернета?** Да, после скачивания модели интернет не нужен.

**Что такое Ollama Cloud?** Запуск больших моделей на серверах Ollama с меткой cloud в названии модели, оплата кредитами.
