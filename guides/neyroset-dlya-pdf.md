# Нейросеть для PDF: краткий пересказ, поиск по документу, таблицы и перевод файла

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Нейросеть для PDF читает длинный файл за вас: делает краткий пересказ, отвечает на вопросы по содержанию, вытаскивает таблицы и переводит текст. Большинство популярных чат-ботов принимают PDF прямо в окне диалога, поэтому отчёт на сто страниц можно разобрать за несколько минут. Ответы с цифрами при этом стоит сверять с исходником по номеру страницы.

Ниже шесть задач с промптами, таблица надёжности, что делать со сканами и большими файлами, правила безопасности и порядок проверки.

## Краткий пересказ

Промпт: «Сделай краткий пересказ этого PDF. Структура: о чём документ в двух предложениях, пять главных выводов, цифры и даты, которые важно запомнить, что от меня требуется. Для каждого пункта укажи номер страницы».

Просьба указывать страницы делает проверку быстрой и заодно снижает риск выдуманных деталей.

## Вопросы по документу

Промпт: «Ответь на вопрос только по этому файлу: [вопрос]. Процитируй фрагмент, на который опираешься, и укажи страницу. Если в документе ответа нет, так и скажи».

Последняя фраза промпта важна. Без неё модель может ответить из общих знаний и выдать это за содержание документа.

## Таблицы из PDF

Промпт: «Перенеси таблицу со страницы 12 в формат, который можно вставить в Excel. Сохрани заголовки колонок. Если какие-то ячейки не читаются, отметь их».

Проверьте итоговые суммы строк и столбцов. На сложных таблицах с объединёнными ячейками модель иногда сдвигает значения.

## Перевод документа

Промпт: «Переведи этот PDF на русский язык по разделам. Сохрани заголовки и нумерацию. Термины оставь в оригинале в скобках при первом упоминании».

Длинные документы переводите частями по 5-10 страниц. Подробнее о переводе в статье про [нейросеть для перевода](/guides/neyroset-dlya-perevoda/).

## Сравнение двух версий

Промпт: «Сравни две версии документа. Перечисли пункты, которые добавлены, удалены и изменены. Для каждого изменения укажи раздел и процитируй старую и новую формулировку».

Для договоров такое сравнение особенно полезно. Разбор условий есть в статье про [нейросеть для договора](/guides/neyroset-dlya-dogovora/).

## Сканы и большие файлы

### Сканированные документы

Если PDF собран из фотографий страниц, модели нужно распознать текст. Чёткий скан читается хорошо, кривой и тёмный даёт ошибки в цифрах. При плохом качестве сначала прогоните файл через программу распознавания текста.

### Большие файлы

У сервисов есть ограничения на размер файла и объём текста за раз. Если документ не загружается или ответы становятся поверхностными, разделите его на части по разделам.

## Порядок работы с новым документом

1. Загрузите файл и попросите краткий пересказ со страницами.
2. Проверьте два-три пункта пересказа по исходнику.
3. Задайте свои вопросы с просьбой цитировать фрагменты.
4. Вытащите нужные таблицы и сверьте итоги.
5. Сохраните пересказ и ответы рядом с файлом.
6. При следующей версии документа запросите сравнение.

## Пять ошибок при работе с PDF

1. Верить цифрам из пересказа без сверки со страницей.
2. Задавать вопросы без требования опираться только на файл.
3. Загружать плохой скан и удивляться ошибкам.
4. Отправлять огромный документ одним куском.
5. Загружать файлы с персональными данными во внешний сервис.

## Правила безопасности

Договоры с реквизитами, медицинские документы, паспортные данные и внутренние отчёты компании во внешние сервисы лучше не загружать. Удалите персональные данные или замените их условными обозначениями перед загрузкой.

## Как использовать нейросеть для PDF: загрузить файл, прочитать и пересказать книгу

Чтобы использовать нейросеть для PDF, хватит трёх действий.

1. Загрузите сам файл кнопкой добавления файла в чате. Скриншот страницы читается хуже: по картинке модель ошибается в числах и мелком шрифте.
2. Спросите, сколько страниц модель видит. Так вы поймёте, что файл загрузился целиком.
3. Поставьте задачу: пересказ, конспект, вопросы по тексту или таблица.

Чтобы пересказать книгу в PDF, не просите всё сразу. Разбейте её на главы, получите краткий пересказ каждой и в конце попросите собрать общий конспект из этих пересказов. Целая книга часто не помещается в память модели, и конец пересказывается хуже начала.

## Частые вопросы

### Какая нейросеть умеет читать PDF

ChatGPT, Клод, Gemini и ряд других сервисов принимают PDF в окне чата. Возможности и лимиты зависят от тарифа, их стоит проверить в справке сервиса.

### Можно ли загрузить PDF бесплатно

У многих сервисов загрузка файлов есть и на бесплатном тарифе, но с ограничениями по числу и размеру.

### Модель видит картинки и графики в PDF

Современные модели умеют разбирать графики и схемы, но точность ниже, чем для текста. Значения с графиков проверяйте вручную.
