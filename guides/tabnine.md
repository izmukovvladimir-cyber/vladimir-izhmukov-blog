# Tabnine: что стало с помощником для кода

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Tabnine это ИИ-помощник для программистов, который дописывает код и отвечает в чате прямо в редакторе. Частному разработчику он больше недоступен: 30 июля 2026 года компанию купила Tricentis, сайт tabnine.com переадресует на её страницы, регистрация не работает, плагины для VS Code и JetBrains помечены «Legacy» и новых пользователей не пускают. Tabnine теперь продаётся только компаниям.

## Что случилось с Tabnine в 2026 году

Tabnine делала израильская компания Tabnine Ltd. Летом 2026 года её купила американская Tricentis, которая делает инструменты для тестирования программ. Сумму сделки не раскрыли, израильская пресса пишет о десятках миллионов долларов. Tricentis покупала технологию для своих агентов тестирования, и в анонсе ничего не сказано о будущем Tabnine как отдельного помощника в редакторе. Пообещали только одно: старые клиенты продолжат получать поддержку.

Что я увидел 30 октября 2026 года:

- **Сайт.** tabnine.com перенаправляет на сайт Tricentis, страница цен открывает форму связи с отделом продаж.
- **Регистрация.** Кабинет и страница регистрации отвечают ошибкой 503.
- **Плагины.** В магазинах VS Code и JetBrains расширение называется «(Legacy) Tabnine» с припиской, что новых пользователей оно не принимает.
- **Консольный клиент.** Старый CLI получает только критические обновления до 31 декабря 2026 года, потом его отключат.

Поэтому статьи «как скачать Tabnine бесплатно» из 2024-2025 годов описывают то, чего больше нет.

## Что умел Tabnine

- **Автодополнение.** Подсказывал следующую строку или целый блок кода прямо при наборе.
- **Чат и агент.** Объяснял код, писал тесты, правил файлы по задаче.
- **Выбор модели.** Сейчас в документации для компаний есть Claude, GPT, Gemini, Qwen Coder и собственные модели Tabnine.
- **Приватность.** Компания обещает не хранить код клиента и не учиться на нём, свои модели обучены на открытом коде с разрешающими лицензиями.
- **Свой сервер.** Tabnine ставят в облако компании или на её серверы, даже полностью без интернета. Ради этого его и выбирают банки и госструктуры.

## Кому Tabnine доступен сейчас

Только компаниям по корпоративному договору через отдел продаж Tricentis. Новые версии для собственных серверов выходят, последняя вышла 21 октября 2026 года. Новый консольный клиент Tabnine построен на открытом агенте OpenCode.

## Сколько стоит Tabnine

Официальной страницы цен больше нет. Последние публичные цены из обзоров:

| План | Цена | Для кого |
|---|---|---|
| Code Assistant Platform | $39 за пользователя в месяц при оплате за год | команды |
| Agentic Platform | $59 за пользователя в месяц при оплате за год | команды |
| Basic, Pro, Dev Preview | сняты | частные пользователи |

Действуют ли эти цены после перехода к Tricentis, проверить нельзя: цену теперь называют только в отделе продаж.

### Есть ли бесплатная версия

Нет. Бесплатный Basic сняли раньше, пробный Dev Preview убрали 2 января 2026 года. Плагин из магазина новый аккаунт не пустит.

## Tabnine на русском

Интерфейс и документация только на английском. Чат понимает вопросы на русском через подключённую модель, например Claude или GPT, но русской версии продукта нет.

## Работает ли Tabnine в России

Для частного пользователя вопрос снят: регистрация не работает ни для кого. В условиях использования Tabnine я не нашёл пунктов о санкциях или запрещённых странах. Корпоративный договор заключается через американскую Tricentis, оплата российской картой не предусмотрена.

## Минусы Tabnine сегодня

- **Закрыт для новых людей.** Ни бесплатно, ни за деньги частному разработчику его не поставить.
- **Плагин Legacy.** Старое расширение из магазина не пустит новый аккаунт.
- **Неясное будущее.** Новый владелец обещал поддержку старым клиентам, о развитии молчит. Раньше Tricentis уже закрывала купленный сервис Flood.io с предупреждением за 20 дней.
- **Старый CLI уходит.** После 31 декабря 2026 года обновлений не будет, логины в новый клиент не переносятся.

## Частые вопросы

**Tabnine что это?**
ИИ-помощник для программистов, который дописывает код и отвечает в чате в редакторе. С июля 2026 года принадлежит Tricentis и продаётся только компаниям.

**Как скачать Tabnine?**
Плагин ещё лежит в магазинах VS Code и JetBrains, но помечен «(Legacy)» и новых пользователей не принимает.

**Tabnine для VS Code работает?**
Для старых аккаунтов расширение ещё работает, новым вход закрыт.

**Сколько стоит Tabnine Pro?**
Плана Pro больше нет. Последние публичные цены были $39 и $59 за пользователя в месяц при оплате за год, только для команд.

**Tabnine бесплатный?**
Нет, бесплатных планов и пробного периода для новых пользователей нет.

**Tabnine это нейросеть?**
Да, он работает на своих языковых моделях и даёт выбрать сторонние: Claude, GPT, Gemini, Qwen.
