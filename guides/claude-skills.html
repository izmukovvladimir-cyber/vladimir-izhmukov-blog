Скиллы Claude (Claude Skills): что это, как установить в Claude Code и claude.ai, как написать свой SKILL.md, 2026

Claude Skills – это папки с файлом SKILL.md, которые Claude может выбрать сам, если задача подходит под описание. Где лежат скиллы в Claude Code, как поставить набор скиллов Anthropic, как включить скиллы в claude.ai, как написать свой скилл и что проверить в чужом.

Скилл Claude (Claude Skill, по-русски «навык») – это папка с файлом SKILL.md: в начале файла записаны имя и описание, дальше инструкции, а рядом могут лежать скрипты, справочники и шаблоны. Для своего скилла создайте такую папку и запишите в SKILL.md шаги задачи; в Claude Code личный скилл лежит по пути ~/.claude/skills/<имя>/SKILL.md, готовый набор Anthropic ставят как плагин командой /plugin install, и Claude может выбрать скилл сам, если задача подходит под описание. В claude.ai при включённом выполнении кода встроенные навыки для PDF, Word, Excel и PowerPoint Claude применяет автоматически, примеры скиллов включают в Customize → Skills, а свой скилл загружают туда же ZIP-файлом.

Ниже по документации Anthropic на 28 ноября 2026 года разобрано, где лежат скиллы в Claude Code, как поставить готовый набор Anthropic и как включить скиллы в claude.ai. Дальше о том, как написать свой скилл и что проверить в чужом до установки. В конце расскажу, по какому правилу я сам превращаю повторяющиеся задачи в скиллы.

Что такое скилл простыми словами

Скилл Claude – это папка с инструкцией SKILL.md для повторяющейся задачи. В обычной сессии Claude Code сначала получает описание доступного скилла, а полную инструкцию читает при вызове. Представьте инструкцию для нового сотрудника, которую он открывает только тогда, когда берётся за конкретную задачу. Когда задача подходит под описание, Claude может выбрать этот скилл, прочитать инструкцию целиком и работать по ней.

Документация Anthropic называет это прогрессивной загрузкой и описывает три уровня:

УровеньЧто загружаетсяКогдаСколько места
1. Метаданныеимя и описание из SKILL.mdпри старте обычной сессии, если скилл доступен моделиориентир Anthropic: около 100 токенов на скилл
2. Инструкцииосновной текст SKILL.mdкогда скилл вызванориентир Anthropic для размера инструкции: менее 5 000 токенов
3. Ресурсыдругие файлы и скрипты папкитолько когда нужныпрочитанный справочник попадает в контекст, а у запущенного скрипта туда попадает только вывод

Благодаря этому до первого вызова в списке доступных скиллов обычно видны только имя и описание. В Claude Code к описанию может добавляться поле when_to_use, а если описания нет, берётся первая непустая строка Markdown-текста скилла. Исключения есть и в другую сторону. У субагента с заранее подключённым скиллом полная инструкция загружается в контекст сразу при старте. У скилла с отключённым автовызовом описание не попадает в список, доступный модели, хотя вручную его вызвать по-прежнему можно. В Claude Code на список по умолчанию отведено около 1% окна контекста, вместо доли можно задать фиксированное число символов переменной SLASH_COMMAND_TOOL_CHAR_BUDGET. Если скиллов слишком много, имена сохраняются, а часть описаний может выпасть.

Чем скилл отличается от CLAUDE.md

В обычной сессии Claude Code подходящие файлы CLAUDE.md загружаются при запуске, а текст SKILL.md загружается, когда скилл вызван. CLAUDE.md – это файл постоянных инструкций проекта или пользователя. Claude Code подхватывает подходящие файлы из текущей папки и папок выше по дереву, поэтому туда кладут то, что нужно в каждой сессии проекта. Длинную процедуру удобно оформить скиллом, потому что в обычной сессии до первого вызова её текст не занимает место в контексте. Исключение составляет субагент с заранее подключённым скиллом: у него полный текст скилла загружается сразу при старте.

После вызова текст скилла остаётся в контексте следующих ходов. У сжатия длинной истории свой предел, и к размеру инструкции он не относится. После сжатия Claude Code заново прикладывает последний вызов каждого скилла, но не больше 5 000 токенов из его начала. Все приложенные скиллы делят общий бюджет 25 000 токенов, поэтому скилл, вызванный давно, может выпасть целиком.

Где лежат скиллы в Claude Code

Личные скиллы Claude Code хранятся в ~/.claude/skills/ и работают во всех ваших локальных проектах, а скиллы проекта лежат в .claude/skills/ внутри репозитория, и эту папку можно закоммитить для команды. Плагины и корпоративные настройки дают ещё два источника.

ГдеПутьДля кого
Личные~/.claude/skills/<имя>/SKILL.mdвсе ваши проекты в локальных сессиях на этом компьютере
Проектные.claude/skills/<имя>/SKILL.mdэтот проект, папку можно закоммитить для команды
Из плагина<плагин>/skills/<имя>/SKILL.mdвызываются как /плагин:скилл

Корпоративные скиллы раздаёт администратор через управляемые настройки. Имя скилла в Claude Code по умолчанию берётся из названия папки и становится командой в меню /.

Как установить готовые скиллы Anthropic в Claude Code

Чтобы поставить готовые скиллы Anthropic в Claude Code, введите в сессии Claude Code команду /plugin marketplace add anthropics/skills, она добавляет маркетплейс (каталог плагинов). Затем откройте карточку набора командой /plugin install document-skills@anthropic-agent-skills и выберите область установки: выбор области и запускает установку. Два набора из этого репозитория ставятся так:

  1. В сессии Claude Code добавьте маркетплейс: /plugin marketplace add anthropics/skills.
  2. Выберите один набор: /plugin install document-skills@anthropic-agent-skills для документов или /plugin install example-skills@anthropic-agent-skills для примеров. Нужны оба набора, выполните обе команды по очереди.
  3. Если открывшаяся карточка показывает список компонентов, посмотрите, что плагин поставит. Карточка плагина из стороннего каталога может вместо списка сообщить, что состав определится при установке, а состав этих двух наборов заранее виден в манифесте репозитория. Затем выберите область установки: для себя, для проекта или только локально. Выбор области запускает установку, после неё Claude Code показывает сводку.

Что полезно знать про установку:

  • /plugin install с именем плагина и маркетплейса открывает в сессии карточку этого плагина, а /plugin без имени открывает каталог плагинов из подключённых маркетплейсов.
  • Если сводка сообщает, что нужна команда /reload-plugins, Claude Code обычно выполняет её сам. Если перезагрузка привела бы к сбросу кэша запросов, он заранее предупредит и оставит плагин в ожидании до /reload-plugins --force.
  • В области проекта настройку включения можно передать команде через Git, а файлы плагина каждый участник скачивает у себя.
  • Из обычного терминала плагин ставит команда claude plugin install <плагин>@<маркетплейс>, которая без параметра --scope устанавливает его для пользователя.
  • Официальный маркетплейс Anthropic claude-plugins-official Claude Code добавляет сам при первом интерактивном запуске в терминале.

В открытом репозитории anthropics/skills на 28 ноября 2026 года 19 скиллов, среди них docx, pdf, pptx, xlsx, skill-creator, mcp-builder и frontend-design. Два набора из инструкции выше вместе дают 16 из 19: в document-skills четыре скилла, в example-skills двенадцать, ещё три лежат отдельными плагинами.

Сам репозиторий предупреждает, что эти скиллы выложены для демонстрации и обучения, поэтому поведение в вашей задаче может отличаться от описания.

Как включить скиллы в claude.ai

Скиллы в личном аккаунте claude.ai работают только при включённом выполнении кода, а дальше путь зависит от вида скилла. Встроенные навыки для PDF, Word, Excel и PowerPoint Claude применяет автоматически, когда задача их требует, отдельно включать их не нужно. Примеры скиллов от Anthropic включают переключателями в Customize → Skills, а собственный скилл загружают туда же ZIP-архивом. Порядок для личного аккаунта:

  1. Откройте Settings, затем Capabilities, и включите выполнение кода (Code execution and file creation, в обновлённых настройках переключатель называется Create and edit files). После этого встроенные навыки для документов уже работают.
  2. Чтобы включить примеры, перейдите в Customize, затем Skills, и включите нужные переключателями.
  3. Чтобы загрузить свой скилл, упакуйте его папку в ZIP, в том же разделе нажмите «+», затем «Create skill» и «Upload a skill».

В командных планах Team и Enterprise доступность скиллов задаёт организация: на Team скиллы по умолчанию включены на уровне организации, а на Enterprise владелец проверяет настройки по пути Organization settings → Plugins & skills → Policy. При разрешающей политике участники сами включают примеры и загружают личные скиллы. На индивидуальных планах Free, Pro, Max и Ultra справка Anthropic разрешает и включать примеры скиллов, и загружать свои. В обзоре платформы Anthropic список планов для загрузки собственных скиллов начинается с Pro, так что источники расходятся.

Как написать свой скилл

Чтобы написать переносимый скилл Claude, создайте папку и положите в неё SKILL.md. YAML-шапка – это блок между двумя строками --- в начале SKILL.md; для переносимого скилла укажите в нём name и description, а ниже запишите шаги задачи. Минимальный пример: папка reels-caption/, а в ней один файл SKILL.md.

Внутри SKILL.md сначала идёт шапка в формате YAML, потом инструкции обычным текстом. Для примера шапка состоит из четырёх строк:

  • ---
  • name: reels-caption
  • description: Пишет подпись к рилсу по транскрипту ролика. Используй, когда просят капшен, подпись или описание к рилсу.
  • ---

Под шапкой записаны шаги:

  1. Прочитай транскрипт и найди главную мысль ролика.
  2. Первая строка подписи повторяет хук ролика.
  3. Дальше две-три строки пользы.
  4. Последняя строка: призыв написать боту кодовое слово.

На что обратить внимание:

  • Описание помогает Claude выбрать скилл. Claude ориентируется на поле description, поэтому там нужно написать и что скилл делает, и когда его применять, словами, которыми вы сами ставите задачу.
  • В Claude Code поля шапки необязательны, документация советует заполнить хотя бы description. Можно добавить, например, allowed-tools или запрет на автоматический вызов.
  • Имя в шапке совпадает с названием папки. Так требует открытый стандарт скиллов, поэтому в примере папка и поле name называются одинаково.
  • В Skills API name и description обязательны: name до 64 символов, только строчные латинские буквы, цифры и дефис, без слов anthropic и claude, description непустое, до 1024 символов; XML-теги в обоих полях запрещены.
  • Описание не оставляйте пустым. Если поле description отсутствует, Claude Code берёт первую непустую строку Markdown-текста, поэтому начните основной текст с фразы о том, что делает скилл.
  • Длинное выносите в отдельные файлы. Справочник или шаблон положите рядом и сошлитесь на него из SKILL.md, тогда файл остаётся за пределами основной инструкции, и Claude может прочитать его по ссылке.

В наборе примеров Anthropic есть скилл skill-creator, с ним свой скилл можно собрать в диалоге.

Скиллы через API

В запросе к Messages API Anthropic укажите до 20 скиллов в параметре container.skills и подключите инструмент выполнения кода. Контейнер – это изолированная среда, в которой выполняется код скиллов.

Готовые скиллы Anthropic для документов называются pptx, xlsx, docx и pdf, свои загружаются запросом POST /v1/skills, общий размер файлов без сжатия меньше 30 МБ. Внутри контейнера API нет доступа в интернет и нельзя ставить пакеты, это стоит учитывать, когда пишете скрипты для скилла.

В API свои скиллы загружаются отдельно, со скиллами claude.ai они не связаны. Про Claude Code источники Anthropic расходятся. Обзор платформы описывает скиллы Claude Code как отдельные и от claude.ai, и от API. Документация самого Claude Code описывает одностороннюю загрузку, и дальше поведение приведено по ней.

Скиллы из claude.ai подтягиваются в сессию в терминале, если войти тем же аккаунтом claude.ai, в их числе готовые pdf и xlsx. Фоновая синхронизация в сессиях терминала работает с версии 2.1.273, при включённой синхронизации и получении флагов функций Anthropic. В более ранних версиях скиллы скачивались только в неинтерактивном запуске -p с переменной CLAUDE_CODE_SYNC_SKILLS=1. Правки локальных файлов обратно в claude.ai не уходят. Встроенные скиллы Claude Code (bundled skills) вроде /code-review и /loop там есть и без этого.

Работают ли скиллы в других нейросетях

Скилл Claude можно перенести в приложение с поддержкой Agent Skills, если там доступны нужные скиллу инструменты и зависимости. Agent Skills – это открытый стандарт папок с SKILL.md: формат разработала Anthropic и выпустила его как открытый стандарт с собственным сайтом agentskills.io, а Claude Code следует этому стандарту.

В каталоге Agent Skills на agentskills.io перечислены клиенты с поддержкой формата. На 28 ноября 2026 года в этом каталоге 46 записей, среди них Cursor, GitHub Copilot, VS Code, Gemini CLI, ChatGPT и Codex от OpenAI (одна общая запись), OpenCode, Goose и Kiro. Общую часть скилла, папку с SKILL.md, именем и описанием, можно перенести в такой инструмент, а дополнительные поля Claude Code там могут не работать. Поддержку в конкретном клиенте стоит проверить по его документации, а скрипту из скилла в другом приложении могут понадобиться свои пакеты, инструменты и доступ к сети.

Как проверить чужой скилл перед установкой

Обзор Agent Skills в документации платформы Anthropic советует ставить скиллы только из доверенных источников, то есть свои или от самой Anthropic. Вредоносный скилл может привести к утечке данных и чужому доступу к системе, поэтому установку скилла документация сравнивает с установкой программы. Перед установкой:

  1. Откройте и прочитайте SKILL.md целиком.
  2. Прочитайте каждый скрипт в папке, особенно места, где он ходит в сеть или читает файлы вне проекта.
  3. Посмотрите поле allowed-tools: на ход, в котором вызван скилл, оно разрешает перечисленные инструменты без отдельного подтверждения, если организационная политика допускает такие правила.
  4. Проверьте остальные файлы: шаблоны, картинки и прочие вложения.
  5. Проверьте, кто автор и есть ли у репозитория история изменений.

Если скилл приходит в составе плагина, проверки одной папки скилла мало. Документация Claude Code предупреждает, что установка плагина добавляет его скиллы, агентов, хуки и MCP-серверы, а хуки и MCP-серверы плагин может запускать. Поэтому перед установкой прочитайте в карточке плагина блок «Will install» со списком компонентов, а у плагина из незнакомого каталога, где вместо списка написано, что состав определится при установке, откройте его файлы в репозитории.

По моему правилу сторонний скилл должен пройти проверку на опасные команды до установки.

Частые вопросы

Короткие ответы на вопросы, которые чаще всего задают про скиллы Claude, с опорой на документацию Anthropic.

Что такое скиллы в Claude?

Скиллы Claude – это папки с файлом SKILL.md, где записаны имя, описание и инструкции. Claude может выбрать скилл сам, если задача подходит под описание. В Claude Code его можно вызвать и командой /имя-скилла, если ручной вызов не отключён полем user-invocable: false.

Как установить скиллы в Claude Code?

Добавьте маркетплейс командой /plugin marketplace add anthropics/skills и поставьте набор командой /plugin install document-skills@anthropic-agent-skills. Свой скилл достаточно положить папкой в ~/.claude/skills/ или .claude/skills/ проекта.

Где хранятся скиллы Claude Code?

Личные в ~/.claude/skills/<имя>/SKILL.md, проектные в .claude/skills/<имя>/SKILL.md, скиллы плагинов внутри папки плагина.

Есть ли скиллы в бесплатном Claude?

По справке claude.ai да: на Free можно включать примеры скиллов и загружать свои, а встроенные навыки для документов Claude применяет автоматически. В обзоре платформы Anthropic список для загрузки своих скиллов начинается с Pro, поэтому при сомнении проверьте раздел Customize → Skills в своём аккаунте. Для работы любых скиллов в claude.ai нужно включить выполнение кода.

Чем скилл отличается от MCP?

Скилл даёт Claude инструкции и файлы для задачи. MCP (Model Context Protocol) – это протокол, через который к Claude подключают внешние сервисы и инструменты. Их можно использовать вместе: скилл описывает, как работать, MCP даёт доступ к данным.

Безопасно ли ставить скиллы из интернета?

Обзор Agent Skills в документации платформы Anthropic советует ставить только свои скиллы или скиллы от Anthropic. Чужой скилл перед установкой нужно прочитать целиком, включая все скрипты, а если он приходит в плагине, проверить и остальные компоненты плагина, в том числе хуки и MCP-серверы.

Что делать дальше

Первый личный скилл Claude Code начните с одной повторяющейся задачи: создайте для неё файл ~/.claude/skills/<имя>/SKILL.md. Три шага:

  1. Выберите задачу, которую вы объясняли Claude уже дважды.
  2. Создайте папку ~/.claude/skills/<имя>/ и положите в неё SKILL.md с описанием, где сказано, что скилл делает и когда его применять.
  3. Вызовите скилл по имени командой /имя-скилла и проверьте, что результат соответствует инструкции.

Если вы только начинаете с Claude, сначала посмотрите, как устроен сам Claude Code.
