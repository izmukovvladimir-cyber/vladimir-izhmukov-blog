OpenCode: бесплатный ИИ-агент для кода в терминале, как установить OpenCode CLI, что такое Zen и Go в 2026

AI RealshiftВладимир Ижмуков

OpenCode это открытый ИИ-агент для программирования в терминале, на десктопе и в браузере. Разбираю установку OpenCode CLI, бесплатные модели, подписки Zen и Go, подключение MCP и skills.

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

OpenCode это бесплатный открытый ИИ-агент для программирования: он читает ваш проект, пишет и правит код, запускает команды и работает с любой моделью, от Claude и GPT до бесплатных моделей и локальных через Ollama. Его ставят одной командой в терминал, а ещё есть десктопное приложение и веб-версия. Платить приходится только за модель: через OpenCode Zen по факту расхода или подпиской OpenCode Go за $10 в месяц. В сентябре 2026 года вышла версия 2.0, в октябре уже 2.1. Ниже разберу установку, тарифы, MCP и skills.

Что такое OpenCode

OpenCode делает команда Anomaly, код открыт на GitHub под лицензией MIT. По сути это та же идея, что у Claude Code и Codex: вы пишете задачу словами, агент сам ходит по файлам проекта, предлагает правки и выполняет команды. Главное отличие в том, что OpenCode не привязан к одной компании. Сайт заявляет больше 75 провайдеров моделей, плюс вход по подписке GitHub Copilot или ChatGPT Plus и Pro.

Два встроенных агента

Внутри OpenCode два режима, они переключаются клавишей Tab:

  • build работает с полным доступом: пишет файлы и запускает команды;
  • plan только читает проект и спрашивает разрешения перед командами в терминале, удобно сначала обсудить план, а потом отдать его в работу.

Есть и подагент @general для поиска и сложных многошаговых задач.

Как установить OpenCode CLI

Самый быстрый путь это официальный скрипт. На macOS и Linux откройте терминал и выполните curl -fsSL https://opencode.ai/v2/install | bash. Остальные способы:

  1. Через npm: npm i -g @opencode/cli@latest (подойдут и bun, pnpm, yarn).
  2. Через Homebrew: brew install anomalyco/tap/opencode-v2, эта формула всегда свежая.
  3. На Arch Linux: sudo pacman -S opencode.
  4. Десктоп на macOS: brew install --cask opencode-desktop, для Windows и Linux установщики лежат на opencode.ai.

После установки зайдите в папку проекта и наберите opencode. Откроется интерфейс агента, где задача пишется обычным текстом.

Важный момент с версиями

Версия 2.0 вышла отдельным npm-пакетом @opencode/cli. По данным обзоров, старый пакет opencode-ai продолжает отдавать ветку 1.x, поэтому если после установки у вас старая версия, проверьте, какой пакет стоит. Плагины от первой версии во второй нужно переносить.

OpenCode бесплатно: какие модели работают без оплаты

Сам агент бесплатный. Бесплатно работают и модели из списка Zen с пометкой Free, часть из них запускается даже без аккаунта. На 25 октября 2026 года в списке есть Big Pickle, GLM-5.3-Flash Free, DeepSeek V4.1 Flash Free, Nemotron и другие. Набор меняется: команда прямо пишет, что бесплатные модели даются на ограниченное время.

Две оговорки, которые стоит знать до начала работы:

  • на бесплатных моделях сайт предупреждает, что данные сохраняются, а модель Beam Free хранит их 30 дней, поэтому коммерческий код туда лучше не отправлять;
  • бесплатные модели можно отключить целиком переменной окружения OPENCODE_DISABLE_FREE_MODELS=1.

Ещё один бесплатный путь это локальные модели через Ollama: тогда код вообще не уходит с вашего компьютера, но нужна мощная видеокарта.

Как устроены лимиты Go

У каждой модели в подписке свой бюджет в долларах на месяц, и он режется на окна: 20% можно потратить за 5 часов, 50% за неделю, 100% за месяц. Например, Kimi K3.1 Pro в Go даёт около 147 запросов за пятичасовое окно, GLM-5.3 около 220. Если лимит кончился, можно включить Extra Usage, тогда дальше списывается баланс Zen. Подписка рассчитана на одного человека, отменить её можно в любой момент, а деньги возвращают, если списание было в последние 14 дней и лимитом вы не пользовались.

Как подключить модель

  1. Запустите opencode и введите команду /connect.
  2. Выберите провайдера: Zen, OpenCode Go, OpenRouter или другой.
  3. Вставьте ключ из консоли провайдера.
  4. Командой /models выберите модель для работы.

Если у вас уже есть подписка ChatGPT Plus или GitHub Copilot, её можно подключить вместо отдельного ключа. Для доступа к сотням моделей через один ключ удобен OpenRouter.

OpenCode MCP и skills

MCP-серверы дают агенту новые инструменты: доступ к базе данных, браузеру, Figma и другим сервисам. В конфиге OpenCode сервер бывает локальным (type local, запускается на вашем компьютере) и удалённым (type remote, по адресу в интернете). Для удалённых серверов вход через OAuth проходит автоматически.

Skills это готовые инструкции под типовые задачи. В документации есть отдельный раздел Agent Skills, а в журнале изменений сказано, что OpenCode находит skills из папки .claude. Значит, наборы, собранные под Claude Code, можно переиспользовать.

OpenCode из России

Доступность сайта, консоли и оплаты Zen и Go российскими картами я не проверял. По документации Go обработка запросов по умолчанию идёт в регионах Европа и США, а модель Beam Free прямо недоступна в ряде стран, в том числе в России. Сам агент открытый и ставится без ограничений, поэтому рабочий вариант для России это локальные модели через Ollama или провайдер, к которому у вас уже есть доступ.

Минусы OpenCode

  • Бесплатные модели меняются, и на них данные сохраняются.
  • Во второй версии по обзорам не работает LSP-диагностика. Плагины первой версии надо переносить.
  • Публичные контракты SDK и плагинов поменялись в версии 2.1 от 20 октября, расширения сторонних авторов могут отставать.
  • Оплату из России я не проверял.

Частые вопросы

Что такое OpenCode? Это открытый бесплатный ИИ-агент для программирования, который работает в терминале, на десктопе и в браузере с любой моделью.

OpenCode бесплатный? Сам агент бесплатный, есть бесплатные модели в Zen. Платные модели оплачиваются по факту через Zen или подпиской Go за $10 в месяц.

Как установить OpenCode CLI? Одной командой из официального скрипта на opencode.ai или через npm пакетом @opencode/cli, затем команда opencode в папке проекта.

Что такое OpenCode Zen? Это способ платить за отобранные модели по факту расхода: пополняете баланс и тратите его на токены.

Сколько стоит OpenCode Go? $10 в месяц, у тарифа Go Plus $40. Лимиты считаются по каждой модели отдельно.

Работает ли OpenCode с MCP? Да, поддерживаются локальные и удалённые MCP-серверы, для удалённых OAuth проходит автоматически.
