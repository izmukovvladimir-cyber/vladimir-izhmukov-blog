# ComfyUI: что это, как установить и пользоваться на русском

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

ComfyUI это бесплатная программа с открытым кодом для генерации картинок и видео нейросетями на своём компьютере: вместо одной кнопки «сгенерировать» вы собираете схему из блоков (нод), которая называется воркфлоу. Проще всего поставить Comfy Desktop для Windows 10 и новее, macOS на чипах Apple или Linux, а русский интерфейс включается в настройках в пункте Language. Если своей видеокарты нет, есть облачная версия Comfy Cloud: 5 бесплатных запусков для новых пользователей, дальше подписка от 20 долларов в месяц.

ComfyUI выбирают, когда нужен контроль над каждым шагом генерации: серия картинок в одном стиле, повторяемый процесс для бренда, локальная генерация без лимитов облачного сервиса.

## Что умеет ComfyUI

Воркфлоу в ComfyUI это схема из блоков: модель, текст запроса, размер, шаги обработки, сохранение. Её можно сохранить и запустить снова, а коллеге для запуска понадобятся те же блоки и модели.

| Задача | Как решается | Где пригодится |
|---|---|---|
| Картинка по тексту | модель плюс запрос | обложки, иллюстрации |
| Картинка по картинке | меняет стиль или детали | серия в одном стиле |
| Видео по картинке | видеомодели, например Wan | анимация обложек |
| Увеличение разрешения | блоки апскейла | крупные форматы |
| Замена фона и деталей | маски и inpainting | товарные фото |
| Несколько запусков подряд | очередь задач | серия вариантов |

## Требования к компьютеру

Официальные требования ComfyUI на 11 ноября 2026 года:

| Что | Требование по документации |
|---|---|
| Comfy Desktop | Windows 10 и новее, macOS на Apple Silicon (чипы M), Linux (AppImage или .deb) |
| Видеокарта | NVIDIA или AMD рекомендуется для хорошей скорости, но не обязательна |
| Место на диске | от 4,85 ГБ на одну установку, без учёта моделей |
| Браузер для интерфейса | для лучшей работы Google Chrome 143 и новее |
| Python для ручной установки | рекомендуется 3.13, запасной вариант 3.12 |

Без видеокарты ComfyUI запускается с параметром `--cpu`, документация прямо предупреждает, что так медленнее. На Mac с чипами M ComfyUI ускоряется через Metal (MPS). Ручная установка по документации подходит для разных систем и видеокарт, включая Intel, со своими ограничениями для каждого железа.

Единой цифры видеопамяти в документации нет. Перед скачиванием тяжёлой модели смотрите требования на её странице.

## Как установить ComfyUI

У ComfyUI три способа установки:

1. **Comfy Desktop** для Windows, macOS на Apple Silicon и Linux. Новичку я советую начать с него, по умолчанию он ставит стабильную версию.
2. **Портативная версия** только для Windows, с видеокартой NVIDIA или на процессоре. Она всегда на самых свежих изменениях.
3. **Ручная установка** из репозитория на GitHub для любых систем и видеокарт.

Порядок для Comfy Desktop:

1. Скачайте установщик с официального сайта comfy.org.
2. Запустите его и пройдите шаги мастера.
3. Настройте установку по подсказкам мастера, место под модели выбирайте на диске с запасом.
4. Дождитесь окончания установки и запустите ComfyUI.

### Как включить русский язык в ComfyUI

Откройте настройки ComfyUI, найдите раздел Locale и в пункте Language выберите «Русский». По документации в списке есть английский, китайский, японский, корейский, русский, испанский и французский, а по умолчанию язык берётся из браузера.

### Как сделать первую картинку

Официальное руководство по первой генерации собирает простой воркфлоу на модели Stable Diffusion 1.5:

1. Скачайте файл модели по ссылке из руководства и положите его в папку моделей ComfyUI.
2. Добавьте на холст блоки загрузки модели, запроса, генерации и сохранения. Если потянуть связь из выхода блока на пустое место, ComfyUI предложит добавить и сразу подключить следующий блок.
3. Напишите описание картинки в блоке запроса.
4. Нажмите Run и дождитесь картинки 512 на 512 в блоке сохранения.

Если ComfyUI пишет, что модели не хватает, в руководстве есть отдельный шаг, как это исправить.

### Как не утонуть в блоках

Мои рекомендации новичку:

- Начинайте с готовых шаблонов воркфлоу.
- Перетащите в окно картинку, сохранённую ComfyUI: если в файле остались данные о воркфлоу, программа его восстановит. После пересохранения в другом редакторе эти данные часто теряются.
- Недостающие пользовательские блоки ставят через [ComfyUI Manager](https://github.com/Comfy-Org/ComfyUI-Manager).
- Меняйте за раз один параметр, так понятно, что на что влияет.

## Сколько стоит ComfyUI

Сама программа ComfyUI бесплатная и с открытым кодом. Платить приходится за своё железо, за облако Comfy Cloud, где генерация идёт на серверах, а вы работаете в браузере, или за платные партнёрские блоки (Partner Nodes), которые обращаются к внешним моделям даже из локальной программы.

| Тариф Comfy Cloud | Цена при помесячной оплате | При оплате за год |

| Бесплатно | 5 запусков на видеокартах для новых пользователей | - |
| Standard | 20 долларов в месяц | 16 долларов в месяц, 192 в год |
| Creator | 35 долларов в месяц | 28 долларов в месяц, 336 в год |
| Pro | 100 долларов в месяц | 80 долларов в месяц, 960 в год |

Кредиты на тарифах можно докупать. Цены сняты со страницы тарифов Comfy Cloud 11 ноября 2026 года, перед покупкой сверьте их там же.

## Частые вопросы

ComfyUI бесплатный, работает на Windows, Mac с чипами M и Linux, остальное ниже.

**ComfyUI бесплатный?** Да, программа ComfyUI бесплатная и с открытым кодом. Платными бывают облако Comfy Cloud и партнёрские блоки Partner Nodes.

**Можно ли запустить ComfyUI без видеокарты?** Да, с параметром `--cpu`, но генерация идёт медленнее. Другой путь это Comfy Cloud, где новым пользователям дают 5 бесплатных запусков.

**Есть ли ComfyUI на русском?** Да. В настройках, в пункте Language, выберите «Русский».

**Чем ComfyUI отличается от Automatic1111?** ComfyUI строится на схемах из блоков, Automatic1111 на привычном интерфейсе с полями и вкладками. Подробно про второй я рассказал в статье [AUTOMATIC1111](/guides/automatic1111/).

**Где брать воркфлоу?** Начните с шаблонов, встроенных в саму программу.
