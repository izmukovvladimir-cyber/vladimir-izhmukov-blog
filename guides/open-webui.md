# Open WebUI: свой ChatGPT на компьютере или сервере

_Владимир Ижмуков · автор системы роста Instagram через короткие ролики_

Open WebUI это бесплатный веб-интерфейс для нейросетей, внешне похожий на ChatGPT, который вы ставите на свой компьютер или сервер. К нему подключаются локальные модели через Ollama и любые сервисы с API, совместимым с OpenAI: OpenRouter, Groq, Mistral, LM Studio и другие. Внутри есть работа с документами (RAG), поиск в интернете, генерация картинок, голосовые звонки, память, агенты и управление пользователями. У проекта около 156 тыс. звёзд на GitHub, последняя версия на момент проверки v0.12.3 от 16 октября 2026 года. Ниже разберу функции, установку и подключение моделей.

## Что умеет Open WebUI

| Функция | Что даёт |
|---|---|
| Любые модели | локальные через Ollama и облачные через API, совместимые с OpenAI |

| Поиск в интернете | десятки поисковых провайдеров, страницы подтягиваются командой # и адресом |
| Агенты | модель плюс инструкции, инструменты и база знаний |

Open WebUI работает и на телефоне как веб-приложение, его можно добавить на главный экран.

## Зачем ставить Open WebUI

- Пользоваться локальными моделями в удобном окне вместо командной строки.
- Собрать в одном интерфейсе несколько провайдеров и сравнивать ответы моделей рядом.
- Дать команде общий чат с нейросетями и контролем расходов.
- Задавать вопросы по своим документам без загрузки их в чужое облако, если модель локальная.

## Как установить Open WebUI

### Через Python pip

1. Поставьте Python 3.11: с другими версиями разработчики предупреждают о проблемах совместимости.
2. В терминале выполните `pip install open-webui`.
3. Запустите сервер командой `open-webui serve`.
4. Откройте в браузере адрес localhost:8080 и создайте первый аккаунт, он станет администратором.

### Через Docker

Основной вариант из README: контейнер `ghcr.io/open-webui/open-webui:main`, который публикуется на порт 3000 с томом `open-webui:/app/backend/data`. Том обязателен: в нём хранятся чаты и настройки, без него данные пропадут при пересоздании контейнера. Для видеокарт NVIDIA есть образ с тегом `:cuda`, а образ с тегом `:ollama` ставит Open WebUI и Ollama вместе одним контейнером.

### Open WebUI на Windows

1. Самый простой путь: установите Docker Desktop и запустите контейнер из README.
2. Второй путь: поставьте Python 3.11, затем установите через pip и запустите `open-webui serve` в PowerShell.
3. Если Ollama уже стоит на Windows, Open WebUI в Docker находит её через адрес host.docker.internal, параметр для этого есть в команде запуска в README.

## Как подключить модели

### Ollama

Если Ollama работает на том же компьютере, Open WebUI подхватит её автоматически. Если Ollama на другом сервере, укажите её адрес в переменной OLLAMA_BASE_URL при запуске. Как поставить Ollama и выбрать модель, я писал в статье [Ollama](/guides/ollama/), а про похожую программу с окном в статье [LM Studio](/guides/lm-studio/).

### Облачные модели

1. Откройте настройки администратора, раздел подключений.
2. Добавьте адрес API и ключ провайдера.
3. Для доступа ко многим моделям по одному ключу удобен [OpenRouter](/guides/openrouter/).
4. Модели появятся в выпадающем списке чата.

## Как работать с документами (RAG)

1. Загрузите файлы в раздел знаний и создайте коллекцию.
2. Привяжите коллекцию к модели или прикрепляйте её в чате через символ #.
3. Задавайте вопросы: ответ строится по фрагментам ваших документов.
4. Для сканов включите один из движков распознавания, например Docling или Mistral OCR.

Качество ответа по документам сильно зависит от модели. Маленькая локальная модель может пропускать детали, поэтому важные выводы проверяйте по первоисточнику.

## Лицензия Open WebUI

Код распространяется под собственной лицензией Open WebUI License. Пользоваться и разворачивать его можно бесплатно, но есть важное условие: убирать или заменять брендинг Open WebUI запрещено, если у вашей установки больше 50 пользователей за 30 дней и нет письменного разрешения или корпоративной лицензии. Для личного использования и небольшой команды это ограничение не мешает.

## Минусы Open WebUI

- Нужен свой компьютер или сервер и базовые навыки работы с терминалом или Docker.
- Локальные модели требуют мощной видеокарты для быстрых ответов.
- Лицензия ограничивает смену брендинга для установок больше 50 пользователей.
- Функций много, и первая настройка занимает время.

## Частые вопросы

**Что такое Open WebUI?**
Это бесплатный веб-интерфейс в стиле ChatGPT для локальных и облачных нейросетей, который ставится на свой компьютер или сервер.

**Open WebUI бесплатный?**
Да, проект бесплатный. Платить нужно только за облачные модели, если вы их подключаете.

**Как установить Open WebUI на Windows?**
Через Docker Desktop командой из README или через Python 3.11 командами `pip install open-webui` и `open-webui serve`.

**Где скачать Open WebUI?**
Код и инструкции лежат в репозитории open-webui на GitHub, образы Docker публикуются в ghcr.io.

**Как подключить Ollama к Open WebUI?**
Если Ollama на том же компьютере, она подключится сама. Для удалённой укажите адрес в переменной OLLAMA_BASE_URL.

**Есть ли в Open WebUI RAG?**
Да, можно загрузить документы в базу знаний и задавать по ним вопросы, поддерживаются 9 векторных баз и гибридный поиск.
