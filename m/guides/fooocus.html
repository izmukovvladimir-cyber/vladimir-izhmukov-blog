Fooocus это бесплатная программа с открытым кодом для генерации картинок на модели SDXL. Она работает на твоём компьютере, ей хватает короткого запроса, а настройки спрятаны. Скачивать Fooocus нужно только с GitHub, официального онлайна нет. Важный факт на 2026 год: проект заморожен, новых функций не будет, только исправления ошибок, последний релиз v2.5.5 вышел 12 августа 2024 года.

Что такое Fooocus

Fooocus сделал разработчик lllyasviel, он же автор ControlNet и Forge. Программа задумывалась как бесплатный офлайн-ответ Midjourney: пишешь запрос, получаешь красивую картинку без десятков ползунков. Код открыт под лицензией GPL-3.0, у репозитория 53,7 тысячи звёзд на GitHub.

Что умеет Fooocus

  • Короткий запрос. Встроенный движок сам дописывает промпт, это стиль Fooocus V2.
  • Inpaint и Outpaint. Перерисовка части картинки и расширение кадра в любую сторону.
  • Image Prompt. Генерация по картинке-образцу.
  • FaceSwap. Перенос лица с фотографии.
  • Пресеты. Обычный, Anime и Realistic.
  • Enhance. Автоматическая доработка лиц и деталей после генерации, с версии 2.5.0.
  • Модели и LoRA. Любые SDXL-модели и LoRA с Civitai.

Как скачать и установить Fooocus

  1. Открой репозиторий Fooocus на GitHub.
  2. Скачай архив Fooocus_win64_2-5-0.7z по ссылке из описания.
  3. Распакуй его в папку с коротким путём.
  4. Запусти run.bat, для аниме run_anime.bat, для реализма run_realistic.bat.
  5. Дождись первой загрузки моделей SDXL, это несколько гигабайт, и программа откроется в браузере.

При запуске Fooocus сам обновится до последней версии 2.5.5.

Fooocus онлайн и в Google Colab

Официального онлайна у Fooocus нет. Авторы прямо называют поддельными сайты с именем fooocus в адресе. Если своей видеокарты нет, есть официальный ноутбук для Google Colab:

  1. Открой ссылку на ноутбук из описания на GitHub.
  2. Запусти ячейку и подожди установки.
  3. Перейди по ссылке gradio.live, которая появится внизу.

Ноутбук рассчитан на бесплатную видеокарту T4. Рефайнер там выключен, а тяжёлые функции вроде Image Prompt могут обрывать сессию.

Как пользоваться Fooocus

  1. Впиши запрос на английском, например «portrait of a woman in a sunny cafe».
  2. Нажми Generate и получи две картинки.
  3. Открой Advanced, выбери стиль, соотношение сторон и режим скорости.
  4. Включи Input Image для inpaint, outpaint или генерации по образцу.
  5. Готовые картинки лежат в папке outputs.

Fooocus на русском

Интерфейс на английском. Официального русского перевода нет, в папке language только английский файл и пример. Можно сделать свой перевод файлом ru.json. Запросы лучше писать по-английски, так модель понимает их точнее.

Работает ли Fooocus в России

Программа работает офлайн, VPN для генерации не нужен. При первом запуске она качает модели с Hugging Face, а его доступность с российского адреса я не проверял. Colab это сервис Google, из России он может не открыться.

Минусы Fooocus

  • Проект заморожен: Flux, SD3 и новые модели не появятся.
  • Только видеокарта с достаточной памятью, иначе очень медленно.
  • Первый запуск долгий из-за загрузки моделей.
  • Интерфейс на английском.
  • Поддельные «онлайн-версии» в поиске.

Для Flux авторы Fooocus сами советуют переходить на Forge или ComfyUI.

Частые вопросы

Fooocus что это? Бесплатная программа для генерации картинок на SDXL, которая работает на твоём компьютере.

Где скачать Fooocus бесплатно? Только на GitHub, архив Fooocus_win64 из описания репозитория.

Есть ли Fooocus онлайн? Официального онлайна нет, сайты с именем fooocus поддельные. Без видеокарты можно запустить Colab.

Как запустить Fooocus в Google Colab? Открыть ноутбук по ссылке из описания на GitHub, запустить ячейку и перейти по ссылке gradio.live.

Fooocus на русском? Официального перевода нет, запросы лучше писать по-английски.

Какая видеокарта нужна для Fooocus? Nvidia от 4 ГБ видеопамяти и 8 ГБ оперативной памяти.

Fooocus ещё обновляется? Только исправления ошибок, последний релиз v2.5.5 от августа 2024 года.
