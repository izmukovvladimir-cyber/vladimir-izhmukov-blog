# Open WebUI: свой интерфейс для нейросетей на компьютере или сервере

Open WebUI это платформа для работы с нейросетями, которую вы разворачиваете у себя: по README проекта, к ней подключаются локальные модели через Ollama или API, совместимые с OpenAI, для локальных и облачных моделей. Установить её можно через pip (`pip install open-webui`, затем запуск `open-webui serve` и адрес localhost:8080), через uv или через Docker, обновляется она командой `pip install -U open-webui` или новым образом Docker, а Ollama подключается переменной OLLAMA_BASE_URL или в настройках администратора.

Ниже разберу установку, выбор образа Docker, обновление, подключение Ollama и условия лицензии.

## Что такое Open WebUI

Open WebUI это self-hosted платформа: она работает на вашем компьютере или сервере. В README проект описан как расширяемая платформа, рассчитанная на работу полностью офлайн. Интерфейс открывается в браузере, а модели вы подключаете сами.

## Как установить Open WebUI

Open WebUI можно установить через Python, Docker или настольное приложение. Для pip и uv нужен установленный Python или uv, для Docker установленный Docker.

### Через Python pip

1. Поставьте Python 3.12 или 3.11: по документации, это поддерживаемые версии, а на Python 3.13 установка ломается из-за зависимостей.
2. В терминале выполните `pip install open-webui`.
3. Запустите сервер командой `open-webui serve`.
4. Откройте в браузере адрес localhost:8080 и создайте первый аккаунт. По документации, первый аккаунт становится администратором и управляет пользователями и настройками.

### Через uv

На macOS и Linux с установленным менеджером uv README предлагает команду:

`DATA_DIR=~/.open-webui uvx --python 3.12 open-webui@latest serve`

По документации, переменная DATA_DIR задаёт папку, где хранятся данные Open WebUI.

### Через Docker

Команда из README:

`docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main`

После запуска интерфейс открывается по адресу localhost:3000. Документация советует сразу задать постоянный ключ WEBUI_SECRET_KEY (параметр `-e WEBUI_SECRET_KEY=ваш-ключ`), иначе после обновлений придётся входить заново. Параметр `-v open-webui:/app/backend/data` подключает том Docker: по документации об обновлении, данные (чаты, пользователи, настройки, загрузки) лежат в томе или локальной базе, отдельно от контейнера.

Какой образ выбрать, по README:

| Тег образа | Что внутри |
|---|---|
| `:main` | стандартный образ с локальными AI-зависимостями, обновляемая сборка без закреплённой версии |
| `:slim` | облегчённый образ, эмбеддинги, извлечение текста из документов и голос через внешние сервисы |
| `:cuda` | Open WebUI с ускорением CUDA |
| `:ollama` | Open WebUI вместе с Ollama |
| `:dev` | последняя сборка для разработки |

По инструкции по обновлению, для личной установки подходит `:main`, а для общей командной лучше закрепить конкретную версию тегом вида `:vX.Y.Z`. Для доступа к видеокарте NVIDIA в образах `:cuda` и `:ollama` README советует добавить `--gpus all`, для этого нужен NVIDIA Container Toolkit.

## Как обновить Open WebUI

Open WebUI обновляется командой `pip install -U open-webui` при установке через pip или заменой образа при установке через Docker:

1. **Установка через pip.** Выполните `pip install -U open-webui` и перезапустите `open-webui serve`.
2. **Установка через Docker.** По [инструкции по обновлению](https://docs.openwebui.com/getting-started/updating/): остановите и удалите контейнер, скачайте свежий образ командой `docker pull ghcr.io/open-webui/open-webui:main` и создайте контейнер заново с тем же томом. Данные в томе при удалении контейнера сохраняются.
3. **Чтобы не разлогинивало после каждого обновления,** документация советует задать переменную WEBUI_SECRET_KEY.

Перед обновлением документация советует сделать резервную копию данных, особенно перед релизами с миграциями базы, которые трудно откатить.

## Как подключить Ollama к Open WebUI

Ollama на другом сервере подключается к Open WebUI переменной OLLAMA_BASE_URL при запуске контейнера, пример из README:

`-e OLLAMA_BASE_URL=http://your-ollama-server:11434`

Подключение можно задать и после запуска: по документации, в настройках администратора есть раздел подключений, где указывается адрес Ollama. Как поставить Ollama и выбрать модель, я писал в статье [Ollama](/guides/ollama/), есть отдельная статья и про [LM Studio](/guides/lm-studio/).

Облачные модели подключаются через API, совместимые с OpenAI: в README для этого есть, например, переменная `OPENAI_API_KEY`. Отдельно я разбирал [OpenRouter](/guides/openrouter/).

## Лицензия Open WebUI

Open WebUI распространяется под собственной лицензией, на GitHub она не отнесена к стандартным. Главное условие в пункте 4: убирать или менять брендинг Open WebUI (название, логотип и другие опознавательные знаки) запрещено. Исключения три: у установки не больше 50 пользователей (физических лиц с прямым доступом) за любые 30 дней подряд, есть предварительное письменное разрешение правообладателя или корпоративная лицензия, которая прямо разрешает такое изменение. Это главное условие, но не полное описание лицензии: текст целиком лежит в репозитории.

## Что учесть перед установкой

Перед установкой Open WebUI я советую проверить четыре вещи:

- Есть ли у вас компьютер или сервер, где он будет работать, и готовы ли вы запускать команды в терминале для pip и Docker. Настольное приложение README предлагает как отдельный путь.
- Какая версия Python стоит: по документации Python 3.13 не поддерживается.
- Где будет резервная копия данных перед обновлениями.
- Какие модели вы подключите: локальные через Ollama или облачные через API.

## Частые вопросы

Коротко: Open WebUI ставится через pip, uv, Docker или настольное приложение, открывается на localhost:8080 или localhost:3000 и работает с Ollama и API, совместимыми с OpenAI.

### Что такое Open WebUI?

Платформа для работы с нейросетями, которую вы разворачиваете на своём компьютере или сервере. К ней подключаются локальные модели через Ollama и API, совместимые с OpenAI.

### Open WebUI бесплатный?

Код открыт на GitHub под собственной лицензией Open WebUI. Главное ограничение в ней касается смены брендинга: менять его можно на установках до 50 пользователей за 30 дней, с письменного разрешения или по корпоративной лицензии. Стоимость облачных моделей зависит от провайдера и выбранной модели.
