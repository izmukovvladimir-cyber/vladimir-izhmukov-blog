## Как сделать картинку в DeepAI

Генератор картинок DeepAI делает изображение по текстовому описанию, бесплатно доступен режим HD с выбором из более чем 100 стилей. Порядок:

1. Откройте [генератор картинок DeepAI](https://deepai.org/machine-learning-model/text2img).
2. Опишите кадр: главный объект, место, свет, стиль.
3. При желании выберите стиль из списка.
4. С подпиской Pro при желании переключите режим на Genius (по документации до 1024×1024 пикселей, горизонтальный, квадратный или вертикальный кадр) или Super Genius (2K).
5. Нажмите Generate и дождитесь картинки.
6. Скачайте результат кнопкой Download или нажмите Edit под картинкой, чтобы поправить её словами в фоторедакторе.

Под полем запроса есть переключатель Magic Rewrite: он автоматически переформулирует ваш запрос, включён по умолчанию и сам выключается, когда запрос длиннее 150 символов. Выключите Magic Rewrite, если не хотите, чтобы сервис переписывал ваш запрос.

### Как писать запрос, чтобы картинка получилась

Это мои правила, я пользуюсь ими в любом генераторе картинок, и в DeepAI тоже:

- Пишу запрос на английском. В документации к генератору я не нашёл сведений о запросах на русском, и русского нет среди языков сайта.
- Начинаю с главного объекта, потом добавляю место, свет и детали.
- Для фотореалистичных картинок указываю тип съёмки, например «film photo» или «studio portrait».
- Если результат не тот, меняю одну деталь за раз, так мне проще сравнивать варианты.

Да, коммерческое использование картинок DeepAI разрешено: в FAQ генератора прямо сказано, что сгенерированные изображения можно использовать в коммерческих и любых законных целях. В условиях использования (редакция от 19 сентября 2025) написано, что весь пользовательский контент, то есть запросы и результаты, принадлежит пользователю и его можно использовать широко, в том числе коммерчески, если соблюдать условия.

Есть расхождение, о котором стоит знать. В том же FAQ генератора написано, что картинки считаются общественным достоянием, у них нет владельца и на них нет авторского права. Если для вашего проекта важны права на картинку, я бы обсудил этот вопрос с юристом до запуска.

Ограничения из условий использования:

- запрещён незаконный, порнографический и откровенно сексуальный контент, травля, мошенничество, спам и нарушение чужих прав;

- DeepAI предупреждает, что ответы нейросети нужно проверять на точность.

## API DeepAI

API DeepAI – это доступ к генераторам из своего кода. По документации API с ключом требует подписки DeepAI Pro: ключ берётся в личном кабинете и передаётся в заголовке `api-key`, генерации через такой API списываются из месячного лимита, а сверх него из кошелька. Через API доступны генерация картинок, фоторедактор, увеличение разрешения, раскрашивание, удаление фона и видео.

Как устроены запросы по документации:

- картинки: POST на адрес вида `https://api.deepai.org/api/text2img`, где в конце стоит название модели;
- видео: POST на `https://api.deepai.org/video-api/text2video` или `/video-api/img2video`, затем GET на `/video-api/status/<id>`, пока ролик не готов.

Для разработчиков без аккаунта и подписки на странице тарифов указана оплата отдельных вызовов через x402/MPP без API-ключа: HD-картинка 1 цент, Genius 8 центов, Super Genius 2K 25 центов.
